# 多层思维导图编辑测量

在当前独立测试项目中实际完成以下操作，只交付思维导图，不需要 Markdown 报告或统计分析。

1. 创建名为 `Harness Mind Measurement` 的思维导图。
2. 一批创建多层主题：根下有“研究”“数据”“结论”“临时”；“研究”下有“问题”和“方法”；“数据”下有“采集”“质量”，其中“质量”下有“缺失值”和“异常值”；“临时”下有“待删除子项”。给“问题”和“方法”分别写一段中文内容。
3. 将“质量”分支移到“结论”下面，保留它的两个子主题。
4. 将剩余的“数据”分支复制到“研究”下面，保留原分支；确认复制产生新的主题身份。
5. 删除“临时”分支，包含其子主题。
6. 显式保存；重新读取局部大纲以及“质量”主题，核对父子关系、复制和删除确实生效。

使用实际工具回执继续定位，按需要读取局部内容。不要为了验收生成另一份文档，也不要打开桌面窗口。完成后用简短中文报告资源路径、保存状态和核对结果。
