# Pareto Chart

Categories takes a Text series, one category occurrence per row. Empty or missing categories are rejected. Supports at most 256 distinct categories.

Bars are sorted by descending frequency, with label order breaking ties. The line shows cumulative frequency share on a right-hand 0–100% axis. Counts and cumulative shares use the complete sample.

Open the result output in a workbench result panel or a separate Plot window.
