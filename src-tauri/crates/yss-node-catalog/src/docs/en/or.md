# Or (||)

Logical disjunction on two booleans:

$$
\text{Result} = A \lor B
$$

| $A$   | $B$   | Result |
| ----- | ----- | ------ |
| false | false | false  |
| false | true  | true   |
| true  | false | true   |
| true  | true  | true   |

## Usage

Accept any of several conditions (e.g. threshold OR flag set). Feed comparison nodes into **A** and **B**.
