# Net promoter score

Connect **ratings**, a numeric column containing integer answers from 0 to 10.
Every row is one respondent. Missing and nonfinite values are rejected.

**result** contains the sample size, counts and percentages of detractors (0–6),
passives (7–8), and promoters (9–10), and the counts at all eleven ratings.
The net promoter score is promoter percentage minus detractor percentage, on
the −100 to 100 scale. Passives remain in the denominator.

This is a descriptive sample score; no population confidence interval or
significance claim is attached. All supplied observations are used.

Reference: [Bain's NPS definition](https://www.netpromotersystem.com/about/measuring-your-net-promoter-score/).
