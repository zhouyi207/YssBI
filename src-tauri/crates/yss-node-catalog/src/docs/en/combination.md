# Combination Chart

Categories is a Text series; Bars and Line are aligned, equally sized Numeric series. Preserves input row order and rejects missing or nonfinite values.

Displays a bar and a line value at each category position. By default the line uses its own right-hand axis; disable Separate line axis to share the left scale. Inputs over 2048 rows are sampled for display, preserving both endpoints.

Open the result output in a workbench result panel or a separate Plot window.
