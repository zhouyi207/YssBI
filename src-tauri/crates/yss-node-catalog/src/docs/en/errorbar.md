# Error Bar Plot

Connect aligned, equally sized Numeric series X, Estimate, Lower and Upper. Bounds are interval endpoints and must satisfy $Lower\le Estimate\le Upper$. Missing and nonfinite values are rejected.

Points show Estimate and vertical bars show the supplied interval. The node does not infer standard deviation, standard error or confidence coverage from the endpoints. Displays at most 2048 systematically sampled observations, including both endpoints.

Open the result output in a workbench result panel or a separate Plot window.
