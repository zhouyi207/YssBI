# KANO requirements

Analyze one requirement per node. Connect aligned **functional** answers
(feature present) and **dysfunctional** answers (feature absent).
Both columns use the same integer coding:
1 = like, 2 = expect, 3 = neutral, 4 = tolerate, 5 = dislike.
Recode reversed scales before connecting. Missing/nonfinite values are rejected.

The classic evaluation table classifies each pair as attractive (A),
one-dimensional (O), must-be (M), indifferent (I), reverse (R), or questionable (Q).
**result** reports all six counts and percentages and every tied dominant category.

Better = (A + O)/(A + O + M + I); Worse = −(M + O)/(A + O + M + I).
R and Q remain in the frequency report but are excluded from these coefficients.
Both coefficients are null if their denominator is zero.

The table follows Berger et al., _Kano's Methods for Understanding
Customer-defined Quality_, CQM Journal 2(4), 1993, Figure 4.
No automatic tie-breaking or product-priority decision is made.
