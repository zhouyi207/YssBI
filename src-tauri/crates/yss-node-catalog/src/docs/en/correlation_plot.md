# Correlation Plot

Add 2–64 aligned, equally sized Numeric series with at least 3 finite observations each. Missing values are rejected. Labels use source column names or series numbers.

Shows Pearson $r$. Two-sided inference tests $H_0:\rho=0$ with $t=r\sqrt{(n-2)/(1-r^2)}$ against a t distribution with $n-2$ degrees of freedom. Correlations involving constant columns are undefined and shown as missing. Open Result in a result panel or Plot window; color represents correlation and hover shows coefficient and P value.
