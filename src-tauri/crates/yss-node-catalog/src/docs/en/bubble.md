# Bubble Chart

Connect aligned, equally sized Numeric X, Y and Size series. Sizes must be nonnegative with at least one positive value. Missing and nonfinite values are rejected.

Positions come from X and Y. Bubble area is proportional to Size; zero-size points have zero area. Displays at most 2048 systematically sampled observations.

Open the result output in a workbench result panel or a separate Plot window.
