# 时序图

连接按时间排列的有限数值 `series`。可选 `time` 输入接受一条对齐的有限数值序列，必须严格递增且无重复坐标；不连接时横坐标为 1、2、…、n。需要显式日历时间轴时，先在上游转换为数值坐标。拒绝缺失值，不静默重排输入行。

输出 `result` 为折线图数据：`data` 包含 x/y 点，`xLabel`、`yLabel` 指定坐标轴，`referenceLines` 为空，`metadata` 记录原始与显示点数。本节点无参数，不拟合模型，也不产生平稳性检验、置信区间或 p 值。

输入行数仅受执行内存预算约束。共享图形显示最多沿顺序均匀抽取 2,048 点，保留首尾并在元数据中记录抽样；这是显示限制，不是统计节点使用的观测数限制。模型拟合应连接原始序列。可先观察趋势、季节、水平突变和异常观测，再选择模型。
