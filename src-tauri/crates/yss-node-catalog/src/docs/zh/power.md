# 幂

计算底数的指定次幂：`结果 = 底数 ^ 指数`。两个输入都可以填写数值或连接数值输出，结果使用 Float64 实数表示。例如 `2 ^ 3 = 8`、`9 ^ 0.5 = 3`、`2 ^ -1 = 0.5`。需要指数函数时，可将底数设为 e。

两个标量返回标量；任一输入为数据序列时逐元素运算，另一侧标量广播。内存数列必须等长；惰性数列必须属于同一关系行域，不能混用没有对齐信息的内存列表。

负底数只接受整数指数；零底数要求指数大于零，`0 ^ 0` 不接受。空值、非有限输入、无法精确提升为 Float64 的整数及溢出结果会报错。惰性数列在实际消费时校验数据，不修改源数据集。
