# 三因素方差分析

输入一个数值 **Response** 和恰好三个 **Factor** 数列；数值因素按类别处理。各列必须逐行对齐；关系数列必须共享行域。不删除缺失值。每个因素有至少两个观测类别，设计矩阵满秩、含截距，观测数大于列数，残差方差为正。

**因素效应** 默认 `full_factorial`：检验所有主效应和各阶交互；`main_effects` 只拟合加性主效应。**平方和类型** 默认 `type_iii`：I 型按主效应的输入顺序、再按交互阶数检验；II 型调整其他项但排除本项的高阶关联项；III 型调整所有其他项。编码使用和为零对比，III 型主效应比较等权类别边际均值。I 型结果依赖顺序；有交互时 II/III 型检验回答不同问题。

对每项，原假设为该项的对比系数均为零，备择为至少一个非零。主效应描述跨其他因素的均值差异；交互描述相关因素作用不能相加。

$$SS_T=SSE_R-SSE_A,\qquad F_T=\frac{SS_T/d_T}{SSE_F/\nu}\sim F_{d_T,\nu}.$$

$R$、$A$ 为所选平方和规则下不含及含检验项的嵌套模型，$F$ 为最终模型，$d_T$ 为该项列数，$\nu=n-p$，$p$ 为最终模型含截距的列数。推断假定独立、近似正态且同方差的误差。完整交互模型需要每个因素组合都被观测。

唯一 **Result** 的 `table` 含各项的平方和、自由度、均方、F、p 值及偏 $\eta^2$；另有 `error`、总平方和、总自由度、$R^2$、选项和原始标签。`factor1`、`factor2` 等按输入顺序编号，交互用冒号连接，如 `factor1:factor2:factor3`。II/III 型项平方和通常不能相加得到模型平方和。

平方和含义参见 [car 的 Anova 文档](https://cran.r-project.org/web/packages/car/car.pdf)。
