# 生存校准曲线

连接逐行对齐的 `time` 与 `event` 数列。时间必须有限且严格大于 0，单位保持一致；`event=1`（或 true）表示事件发生，`0`（或 false）表示右删失。缺失值会导致计算失败，不自动删行。假设在给定模型或分组条件下删失独立于事件过程；输入须等长并按当前位置逐项对应，可混合数据库与内存数列。

连接范围为 [0,1] 的数值 `predicted_risk`，其含义是到 `survival_horizon=1` 为止发生事件的概率；时点必须为正，预测和观测必须对应同一事件定义及预测时点。`calibration_bins=10`，要求至少 2 的整数，按预测值排序后形成大小近似相等的分组；相同预测值不拆分，所以实际组数可能减少，甚至只剩一组。

## 计算与输出

每组 $b$ 的横坐标为平均预测风险，纵坐标为 $\widehat p_b=1-\widehat S_b(t)$，其中 $\widehat S_b$ 为该组在预测时点的 Kaplan–Meier 生存概率。45 度参考线表示完全校准；点之间的连接只是图形插值，并非拟合的校准模型。

`result` 为绘图数据，含坐标标签、点数信息、预测时点及 `bins`。每组记录人数、预测值范围及均值、观测风险和 95% 区间；风险区间由 Kaplan–Meier 的 log-log 生存区间反向变换得到。不计算显著性检验或校准斜率；删失观测仍参与风险集。

若某组仍有非零生存概率、但随访支持未达到预测时点，则拒绝计算；已降至零生存概率的组可支持后续时点。评估模型输出时，从其 `predictions` 表选择 `time`、`event`、`risk` 三列。同一拟合样本上的校准属于表观性能；评估样本外表现应输入外部或留出样本预测。本节点不重新拟合或执行交叉验证。
