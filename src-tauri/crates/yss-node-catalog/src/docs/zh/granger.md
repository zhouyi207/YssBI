# VAR Granger 因果检验

连接 VAR Fit 的 `model`，在既定变量集合和滞后设定下，检验其他变量的过去值是否对某个方程提供额外线性预测信息。无配置参数，沿用拟合模型的滞后、系数和协方差，不重新选阶或拟合。

## 逐变量检验

设 $K$ 维 VAR 为

$$
y_t=c+\sum_{\ell\in\mathcal L}A_\ell y_{t-\ell}+Bz_t+u_t,
$$

$\mathcal L$ 是模型实际包含的滞后集合，$m=|\mathcal L|$，$z_t$ 表示模型中其他已纳入项。对响应方程 $i$ 和其他变量 $j$：

**原假设 $H_0$：** $(A_\ell)_{ij}=0$ 对所有 $\ell\in\mathcal L$ 成立；控制其余已纳入信息后，$j$ 不 Granger 导致 $i$。

**备择假设 $H_1$：** 至少一个上述滞后系数非零。

令 $b=R\hat\beta_i$ 提取该方程中变量 $j$ 的所有已包含滞后系数，$V_i$ 为该方程系数协方差：

$$
W=b'(RV_iR')^{-1}b,\qquad
W\overset{H_0}{\approx}\chi_m^2,\qquad
p=1-F_{\chi_m^2}(W).
$$

若模型只包含滞后 $\{1,3\}$，自由度为 2，而不是最大滞后 3。

## ALL 联合检验

**原假设 $H_0$：** 方程 $i$ 中所有其他变量的全部已包含滞后系数均为零。

**备择假设 $H_1$：** 至少一个其他变量的滞后系数非零。

将 $R$ 改为同时提取所有 $j\ne i$ 的滞后系数，使用同一 Wald 公式，自由度为 $(K-1)m$。这是同一响应方程的联合检验，不是把逐变量 p 值相加。背景见 [statsmodels VAR 的因果检验说明](https://www.statsmodels.org/stable/vector_ar.html#granger-causality)。

## 输出与判读

`result`、`report` 相同，`vargranger` 数组每行含 `eq_name`（响应方程）、`excluded`（被检验的预测变量或 `ALL`）、`chi2`、`df`、`p_value`。单变量 VAR 没有其他变量可检验，数组为空。

例如 `eq_name=消费`、`excluded=收入` 且 $p<0.05$，在预设 5% 水平拒绝“收入过去值无额外预测作用”；不是“消费导致收入”，也不是干预意义上的因果效应。反向检验是另一行。

推断依赖合理的 VAR 设定、样本量、残差条件和适当平稳性处理；直接对单位根/协整序列套用普通 VAR Wald 分布可能失真。矩阵块不可逆或无效模型会失败。多行结果不做多重检验校正，未拒绝只表示在当前信息集和滞后下证据不足。
