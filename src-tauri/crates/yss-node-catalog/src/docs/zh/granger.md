# VAR Granger 因果检验

连接 VAR Fit 的 `model`，检查其他变量的历史值是否增加某个方程的预测信息。无配置参数，沿用模型的变量、滞后、系数和协方差。

## 逐变量检验

- **原假设 $H_0$：** 响应方程中，被检验变量的所有已纳入滞后系数为零。
- **备择假设 $H_1$：** 至少一个上述系数非零。

$$
W=b'V_b^{-1}b,\qquad
W\overset{H_0}{\approx}\chi_m^2.
$$

$b$ 为被检验的滞后系数向量，$V_b$ 为其协方差子矩阵；$m$ 为模型实际纳入的滞后个数，不是最大滞后阶数。

## ALL 联合检验

- **原假设 $H_0$：** 响应方程中，所有其他变量的已纳入滞后系数全为零。
- **备择假设 $H_1$：** 至少一个上述系数非零。

使用同一 Wald 公式，$b$ 包含所有其他变量的滞后系数，自由度为 $(K-1)m$，$K$ 为模型变量数。

## 输出与判读

`result` 为结构化结果，`vargranger` 数组每行含 `eq_name`（响应方程）、`excluded`（被检验变量或 `ALL`）、`chi2`、`df`、`p_value`。

p 值取对应卡方右尾；$p<\alpha$ 表示拒绝该变量或变量组没有额外预测作用。方向为 `excluded` → `eq_name`，不是干预意义上的因果效应。节点不作多重检验校正；单位根或协整序列应先选择适当的建模方式。

方法细节：[VAR Granger 检验](https://www.statsmodels.org/stable/vector_ar.html#granger-causality)。
