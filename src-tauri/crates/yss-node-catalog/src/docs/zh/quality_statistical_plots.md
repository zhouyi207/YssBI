# 统计图（分布概览）

连接一个非空、有限的数值**序列 values**，一次读取供三个已有绘图算法共用，支持常数数据。
缺失值和非有限数值会报错。

- **result**：直方图。**bins** 为 0 时按 Sturges 规则自动分箱，也可指定 1–128 个显示区间；全部观测参与频数计算。
- **ecdf**：经验累积分布函数，合并并列值；全部观测参与计算，绘图元数据标明是否进行了显示抽样。
- **boxplot**：中位数、type-7 四分位数、1.5 倍四分位距须线及离群点；摘要和离群点总数使用全部观测。

复用已有绘图显示预算：最多展示 2048 个 ECDF 点或箱线图离群标记；更大的数据仍完整参与统计。
图形概览不能代替正式的分布检验。需要不同输入或独立配置时，可使用各自的绘图节点。
