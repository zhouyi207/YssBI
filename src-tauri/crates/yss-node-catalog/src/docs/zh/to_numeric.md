# 转数值

将输入标量或数列转换为 Numeric。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

**数值表示**默认为自动：已有数值保留其表示，文本解析为 Float64，二元值按正值映射转为 Int64 的 0/1。选择整数使用 Int64，选择实数使用 Float64。

## 转换规则

空值保持为空值。数值文本允许首尾空白和前导零；实数模式还接受小数和科学记数法。整数模式接受整数文本，拒绝小数截断。溢出、非有限值和精度损失会失败；例如 `9007199254740993` 需要整数模式。

分类、顺序和标识输入按原始值解析，不使用类别编号或等级索引。带正值映射的 Binary 输入按其值域解释。日期时间不会隐式转为数值时间戳。

## 输出与执行

输出语义固定为 Numeric。内存中的输入立即转换；惰性数列消费数据时才逐批校验，其物理表示在转换表达式构建时确定，不随批次变化。本节点生成派生结果，不修改源数据集。
