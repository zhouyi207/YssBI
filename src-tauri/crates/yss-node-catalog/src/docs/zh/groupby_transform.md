# 按组变换 Transform

连接**已分组数据帧**，选择恰有一个 DataFrame 参数、返回 DataFrame 的图函数。传入的组内表包含分组键。
Transform 按原始源行顺序组合函数生成的列，不自动附加源表或分组键列。

返回表必须保留组内全部行及其顺序。在这些行上选择、重命名或计算列可以保留对应关系；筛选、排序、
聚合及独立创建的表不能证明这种关系，即使返回行数碰巧相同也会被拒绝。

每组返回的列名、顺序、精确物理类型及语义配置必须一致。需要增减行数或改变行顺序时，使用**按组调用 Apply**。

空输入会用空源表调用一次函数以确定输出结构，返回零行。各组顺序执行，共用调用方的取消与预算控制。
错误保留组编号和函数位置；上次成功结果继续遵守通常的缓存有效性规则。
