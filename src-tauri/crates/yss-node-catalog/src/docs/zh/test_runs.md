# 游程随机性检验

检验二元序列的排列顺序是否符合随机排列。

## 输入与参数

`series` 输入按所需分析顺序排列的数值 `0/1` 序列，至少 2 个观测，且两种取值均须出现。无配置参数。节点不排序、不自动按中位数二分连续数据，空值会被拒绝。

## 假设与统计量

$H_0$：给定两类数量后，序列顺序随机；$H_1$：出现过多或过少的游程。游程是连续相同取值的一段。令 $R$ 为游程数，$n_0,n_1$ 为两类数量，$n=n_0+n_1$：

$$
E(R)=1+\frac{2n_0n_1}{n},\qquad
V(R)=\frac{2n_0n_1(2n_0n_1-n)}{n^2(n-1)},
$$

$$
Z=\frac{R-E(R)}{\sqrt{V(R)}}\overset{H_0}{\approx}N(0,1).
$$

方差须大于零。当前使用双侧正态近似，无连续性校正或精确法。分析前应明确顺序含义；少量或极不平衡的两类观测可能使近似不可靠。

## 输出与判读

`result`、`report` 相同。`statistic_name` 为 `runs_z`，`statistic` 是 $Z$ 而不是原始游程数，`p_value` 为双侧 p 值，`sample_sizes` 为 `[n]`。自由度为空，估计值和标准误为空。

$p<\alpha$ 表示顺序偏离随机排列；不显著并不能证明序列独立。
