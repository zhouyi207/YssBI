# TURF 组合模型

将已对齐的数值列连接到 **criteria**：每列一个选项，每行一位受访者，
0 表示未触达或不感兴趣，1 表示触达或感兴趣。缺失及非有限数值会报错。
**combination_size** 指定选多少项，须在 1 到连接的选项数之间。

穷举该大小的全部组合，使至少被一个选项触达的人数最大。
**result** 输出选中指标的位置（从 1 开始）及指标名称映射、触达人数与百分比、
选中组合内的总触达次数，以及每位已触达人群的平均触达次数（零触达时为空）。
同时报告已比较的组合数及达到最大触达人数的并列组合数。
并列时按输入列顺序选择字典序最靠前的一组，不按频次另行打破并列。

算法使用位集合精确搜索。复杂组合仍受执行期限、取消和内存预算约束；
中断时返回错误，不把局部搜索结果标为最优。没有固定选项数或观测行数上限。
