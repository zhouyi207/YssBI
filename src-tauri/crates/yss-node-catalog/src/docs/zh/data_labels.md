# 数据标签（取值含义）

将一个数列接到 **input**，选择分类或顺序语义，在“编码与标签”中填写原始编码及其含义。
**output** 仍使用原始编码与空值，标签作为语义元数据传递，不将单元格替换成标签文字。
例如编码 `001` 的含义可以是“实验组”，原始文本 `001` 的前导零会保留。

顺序语义按配置顺序从低到高排列。
空配置继承兼容的已有值域；没有兼容的已有值域时需明确填写。
重复编码、值域配置不合法及不属于声明值域的非空观测会失败，不静默映射成缺失值。

如需将正类/负类原始编码转为布尔值，请使用“类别转换”的二元目标；那属于重新编码。

该节点复用“类别转换”的同一语义转换能力。配置保存在图的节点参数，输出元数据沿数据流传递；不会直接改写源数据库的字段设置。

数列保持惰性关系与行对齐，没有固定行数上限。
这里的标签是取值含义；重命名数据列请使用现有列重命名操作，节点显示名在节点属性中修改。
