# 主成分分析（PCA）

输入 至少两个数值 **Variable** 数列，每行是一条观测，各列必须对齐；数据库与内存数列可混合，按当前位置逐项对应。缺失值不自动删除。**保留维数** 默认 2，范围为 $1\le k\le\min(p,n-1)$，$p$ 为变量数，$n$ 为观测数。

**标准化变量** 默认开启：先中心化，再除以样本标准差（分母 $n-1$）；关闭时对中心化的原单位数据做协方差 PCA。标准化模式不接受常量列，原单位模式允许常量列，但总方差必须为正。

令 $Z$ 为处理后的矩阵，$S=Z^TZ/(n-1)$，$S V=V\Lambda$：

$$T=ZV_k,\qquad r_j=\lambda_j/\sum_\ell\lambda_\ell.$$

$V_k$ 是前 $k$ 个单位特征向量，$T$ 是得分，$r_j$ 是解释方差比例。该节点是描述性降维，不计算假设检验或 p 值。重根时各轴方向不是唯一的；权重正负号不改变解释方差或重构。

**Result** 包含 `means`、`scales`、变量×保留维数的 `weights`、全部特征值、解释/累计比例、保留比例和数值秩。`weights` 是得分系数，不是乘以特征值平方根的相关载荷。关闭标准化时 `scales` 全为 1。

**Scores** 是可分页、可连接的数值数据表，列为 `axis1` 至 `axisK`，行顺序与输入一致；可连接“选列”后继续绘图或分析。它是独立计算表，不凭行数与原始惰性数列建立对齐证明。大批得分不嵌入摘要 JSON。
