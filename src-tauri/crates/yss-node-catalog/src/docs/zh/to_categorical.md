# 转分类

将输入标量或数列转换为 Categorical，保留原始编码。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

**取值与标签**配置不同原始编码及其含义，默认为空配置。空配置继承兼容的源分类、顺序或二元值域；普通文本或数值没有可继承值域时，需要显式填写。

## 转换规则

每个非空输入必须属于声明值域，重复编码和未声明的取值会失败。空值保持为空值。标签作为元数据随输出传递，原始值不会替换为标签，也不会生成类别编号。

分类不表达等级顺序；需要等级时使用“转顺序”。

## 输出与执行

输出语义固定为 Categorical。后续转换可继承其值域与标签。内存中的输入立即转换；惰性数列在消费时校验实际取值。本节点生成派生结果，不修改源数据集。
