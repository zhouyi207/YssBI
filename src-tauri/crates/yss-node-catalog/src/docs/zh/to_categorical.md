# 转分类

将输入标量或数列转换为 Categorical，保留原始编码。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

**取值与标签**可配置不同原始编码及其含义，默认为空配置。留空时优先继承源分类、顺序或二元值域及标签；没有可继承值域时，自动读取全部输入，按非空原值去重并生成同名标签，无需逐个填写。

## 转换规则

自动映射保留空字符串、文本前导零和精确数值编码；空值不生成类别，空输入或全空输入得到空值域。自动生成的映射按编码文本排序，这不表示等级顺序。

手动配置或继承已有值域时，每个非空输入必须属于该值域，重复编码和未声明的取值会失败。空值保持为空值。标签作为元数据随输出传递，原始值不会替换为标签，也不会生成类别编号。

自动或手动配置的映射最多包含 65,536 个类别，编码与标签的 UTF-8 总长度不超过 1 MiB；超出限制会失败，不截断类别。

分类不表达等级顺序；需要等级时使用“转顺序”。

## 输出与执行

输出语义固定为 Categorical。后续转换可继承其值域与标签。自动映射在节点执行时扫描完整输入；已有值域的惰性数列仍在消费时校验实际取值。本节点生成派生结果，不修改源数据集。
