# 逻辑比较

小于、小于等于、大于、大于等于支持数值及文本，两个输入必须具有相同语义。数值比较保留整数精度；文本按大小写敏感的字典顺序比较，不解析为数字，也不使用本地化排序。

两个标量返回二元标量；任意输入为数据序列时逐元素比较，标量广播到另一侧数列，返回二元数据序列。内存数列必须等长；惰性数列必须属于同一关系行域，不能混用无对齐信息的内存数列。

任一元素为空时，该位置返回空值；非有限数值或不支持的表示报错。分类、顺序和标识不隐式按编码排序。日期时间的排序不由这些节点提供。

惰性比较在读取结果时执行，保持来源关系和行对齐，不修改数据集。

Detail 的配置中，`exact`（默认）使用上述精确语义；`tolerance` 仅支持 Numeric，并显示绝对容差（默认 1e-12）和相对容差（默认 1e-9）。容差必须有限且非负，拒绝到 Float64 的有损转换。

容差内，即 `abs(a-b) <= atol + rtol * max(abs(a), abs(b))` 时，两值视为相等：`<`、`>` 返回假，`<=`、`>=` 返回真；容差外按数值大小比较。与等于、不等于节点使用相同配置时，比较结果保持一致。近似相等不具备传递性，不应作为排序或分组的等价关系。
