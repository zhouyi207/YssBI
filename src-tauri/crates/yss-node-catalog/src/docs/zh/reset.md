# Ramsey RESET 设定检验

连接 OLS 或 WLS 的 `model`，检查在原均值方程上加入非线性幂次后是否显著改善拟合。复用拟合样本和 WLS 精度权重，当前不支持 GLS。

## 方法与假设

原设计矩阵为 $X$，列数为 $k$（含已有截距），观测数为 $n$，扩展模型为

$$
y=X\beta+Z\gamma+\varepsilon.
$$

**原假设 $H_0$：** $\gamma=\mathbf0$，本次加入的幂次项没有额外解释作用。

**备择假设 $H_1$：** 至少一个新增系数非零，原模型可能遗漏相关非线性形式。

参数 `rhs` 默认为 `false`，两种设置分别选择以下扩展项，假设均针对各自的 $Z$。

| 设置        | 实际扩展                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------- |
| `rhs=false` | 将拟合值归一化为 $f_i=(\hat y_i-\min\hat y)/(\max\hat y-\min\hat y)$，加入 $f^2,f^3,f^4$，$q=3$    |
| `rhs=true`  | 对每个非常量、非 0/1 解释变量按同样方式归一化，分别加入二、三、四次幂；若有 $m$ 个合格变量，$q=3m$ |

RHS 模式不生成不同变量间的交互项；近似常量和近似 0/1 列按 $10^{-10}$ 容差排除。幂次固定为 2–4，节点没有选择幂次的参数。

## 统计量

令 $\mathrm{RSS}_R$、$\mathrm{RSS}_U$ 为原方程与扩展方程的残差平方和：

$$
F=\frac{(\mathrm{RSS}_R-\mathrm{RSS}_U)/q}
{\mathrm{RSS}_U/(n-k-q)},\qquad
F\overset{H_0}{\sim}F_{q,n-k-q},
\qquad p=1-F_{F_{q,n-k-q}}(F).
$$

OLS 使用 $\sum_i e_i^2$；WLS 在两个方程中均使用 $\sum_iw_i e_i^2$，$w_i$ 为原模型权重。经典 F 标定需要相应尺度下的独立、同方差正态误差及满列秩设计。此节点不会随上游稳健协方差切换为稳健 Wald RESET。RESET 的一般原理见 [statsmodels linear_reset](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.linear_reset.html)；这里的幂次与归一化以上表为准。

## 输出与判读

`result` 与 `report` 相同：`test=reset`，内层 `result` 含 `f_stat`、`df1=q`、`df2=n-k-q`、`p_value`。

例如在 5% 水平得到 $p=0.01$，表示所选幂次联合显著，值得检查函数形式、遗漏变量或其他均值设定。检验不能直接指出应加入哪个变量，也不能把拒绝自动归因于某种具体错误。$p\geq\alpha$ 只表示没有充分证据拒绝这些新增系数为零，并不证明原模型正确。

要求 $n>k+q$、扩展设计满秩，RHS 至少有一个合格解释变量；观测不足、共线扩展、常量拟合值或非有限计算可能失败。扩展方程残差平方和极小（不大于 $10^{-300}$）时当前返回 $F=0$；这类退化结果不具备通常的 F 检验含义。
