# VIKOR

连接已对齐的数值 **criteria**，每列一个指标，每行一个方案，至少两个方案。
**cost_criteria** 指定越小越好的指标位置，从 1 开始。缺失、非有限数值及观测数不一致会报错。

可选的 **criterion_weights** 按指标顺序提供非负有限权重，总和须为正；不连接时等权。
权重使用独立行域，可连接熵权等赋权节点的权重输出。

按指标方向将非常量列转换为最优到最差的损失 $l_{ij}\in[0,1]$，常量列的损失为 0。
使用归一化权重计算：

$$
S_i=\sum_j w_j l_{ij},\quad R_i=\max_j w_j l_{ij},\quad
Q_i=v\frac{S_i-S_{\min}}{S_{\max}-S_{\min}}
 +(1-v)\frac{R_i-R_{\min}}{R_{\max}-R_{\min}}.
$$

**majority_weight** 即 $v$，范围 [0,1]，默认 0.5；极差为 0 的分量按 0 计。
Q 越小越好。**scores** 输出观测序号、Q、S、R 和升序排名，并列用平均名次；
**weights** 返回归一化权重。

**result** 报告两个折中条件：前两名 Q 的差至少为 $1/(n-1)$；第一名也须为 S 或 R 的最优方案。
优势条件不满足时，折中集合包含与第一名 Q 差严格小于该阈值的所有方案；
仅稳定性条件不满足时返回前两名；两者满足时返回第一名。
完全无法区分的方案保留并列，不任意选出唯一最优。这些是相对决策指标，不是显著性检验。
