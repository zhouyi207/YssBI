# 障碍度

连接对齐的数值 **criteria**，可另接独立 **criterion_weights** 权重向量。
权重按指标顺序排列，要求非负且有限，内部归一化为和为 1；不连接时等权。
缺失与非有限观测会报错。

**rescale** 默认开启，使用极差标准化，常量列按 0 计；关闭时输入必须已在 [0,1] 范围内。
**cost_criteria** 指定从 1 开始的负向指标位置，反向处理为正向效用；极差标准化的常量列仍为 0。

对正向效用 $z_{ij}$，偏离度与障碍度为：

$$
d_{ij}=1-z_{ij},\qquad O_{ij}=100\frac{w_jd_{ij}}{\sum_k w_kd_{ik}}.
$$

**scores** 为可分页长表，每个观测、每个指标各一行，包含观测序号、指标序号、偏离度、
加权偏离度和障碍百分比。加权偏离总和为正时，同一观测的障碍百分比合计为 100。
全部加权偏离为 0 时比例无定义，保留为空；**result.undefined_rows** 统计这类观测数量。
**weights** 返回归一化权重，不设置固定行数上限。

这里计算单层指标贡献；存在层次结构时，先明确合成父层与局部权重，再传入全局权重。
较大障碍份额表示较大的加权不足，不证明因果阻碍。
