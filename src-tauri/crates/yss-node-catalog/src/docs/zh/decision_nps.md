# NPS 净推荐值

将推荐意愿评分连接到 **ratings**：每行一位受访者，值必须是 0–10 的整数。
缺失及非有限数值会报错，计算使用全部输入行。

**result** 输出贬损者（0–6）、被动者（7–8）、推荐者（9–10）的数量、百分比，
以及样本量、各评分的频数。净推荐值为推荐者百分比减去贬损者百分比，
范围 −100 到 100；被动者仍计入总人数。

这是样本的描述指标，不附带总体置信区间或显著性结论。

定义参考：[Bain NPS](https://www.netpromotersystem.com/about/measuring-your-net-promoter-score/)。
