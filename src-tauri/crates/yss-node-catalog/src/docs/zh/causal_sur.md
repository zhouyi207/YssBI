# 似不相关回归 SUR

在同一组观测上拟合多个线性方程，允许同一观测的方程误差相关。

## 输入和参数

连接至少两个对齐的数值 `responses`，以及可选的重复数值 `predictors`。各方程使用同一行集合，拒绝缺失或非有限数据。

`constant=true` 在所有方程中加入截距。`equation_predictors` 默认留空，表示每个方程使用全部自变量；也可为每个响应提供一个以分号分隔的列表，其中以逗号分隔从 1 开始的自变量索引。例如 `1,2;1,3` 表示方程 1 使用变量 1、2，方程 2 使用变量 1、3；`-` 表示无自变量的仅截距方程。
列表数量须等于响应数，索引有效且无重复，每个方程均须可识别并具有正残差自由度。取消截距后，每个方程至少需要一个自变量。不设固定输入或方程数量上限，完整系统受执行预算约束。

## 估计与推断

首先由各方程 OLS 残差估计 $\hat\Sigma_{ab}=n^{-1}\sum_i\hat u_{ia}\hat u_{ib}$，再进行一次可行 GLS：

$$
\hat\beta=(X'\hat\Omega^{-1}X)^{-1}X'\hat\Omega^{-1}y,
\qquad \hat\Omega=\hat\Sigma\otimes I_n.
$$

响应按方程堆叠，设计为块对角矩阵；$\hat\Sigma$ 须正定。当前为两阶段 SUR，不是迭代 SUR。

协方差为 $(X'\hat\Omega^{-1}X)^{-1}$，保留跨方程块，不作残差自由度缩放。假设观测独立、同一观测的方程间协方差恒定。系数检验为 $H_0:\beta_j=0$、$H_1:\beta_j\ne0$，使用正态 Wald 统计量、双侧 p 值和 95% 区间；当前不提供异方差或聚类三明治协方差。

## 输出

`equations` 保留各方程自变量索引、系数、拟合值与残差。`error_covariance` 是用于 FGLS 的初始 OLS 误差协方差；`coefficient_covariance` 按方程、再按含截距的系数顺序排列。
当所有方程的自变量相同时，点估计与逐方程 OLS 相同；不同设计可获得效率收益。
