# 调整预测

根据已有 Linear、Logit 或 Probit 拟合计算调整后的结局均值。
连接拟合节点的 **model** 输出，复用估计样本的设计矩阵与系数协方差，无需另接结局列。

## 参数

- **evaluation**：默认 average，先逐行预测再取均值；at_means 在各设计列均值处预测。
- **at**：可选设定，例如 x1=2,x2=0，名称使用拟合系数表中的名称。
  每项设定替换所有待评估行的相应设计列。未知、重名变量及截距设定会报错。
- **confidence_level**：默认 0.95，严格介于 0 和 1。

分类哑变量或手动展开的交互项需由使用者一致设定，节点不会重新生成设计变换。

## 计算与输出

对调整后的行 $x_i$，平均预测及 Delta 法方差为

$$
\widehat m=\frac1N\sum_i h(x_i'\widehat\beta),\qquad
a=\frac1N\sum_i h'(x_i'\widehat\beta)x_i,\qquad
\operatorname{Var}(\widehat m)\approx a'\widehat V a.
$$

结果包含调整均值、标准误、置信区间、模型族、样本量及设定。
区间表达估计均值的不确定性，不是新个体观测值的预测区间。
常规线性协方差使用残差自由度的 t 推断；稳健线性协方差及二元模型使用正态推断。
二元模型在概率尺度使用 Delta 法区间，可能超出 [0,1]，不会静默截断。
平均预测概率通常不同于在协变量均值处的预测概率。
