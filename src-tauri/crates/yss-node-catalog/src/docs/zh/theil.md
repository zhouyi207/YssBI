# 泰尔指数

计算使用自然对数的 **Theil T**。在详细面板选择**数据形式**。

- **个体形式**（默认）：连接个体数值序列，每个观测等权。从分组形式切换回来时，移除 Weights 输入。
- **分组形式**：连接**组均值**序列，在详细面板添加一个 **Weights (group population)** 输入，连接对应的组人数或人口占比。权重自动归一化，人数和同比例的人口占比给出相同结果。数值输入不接受组总量语义。

设数值为 $x_i$，$p_i=w_i/\sum_j w_j$（个体形式为 $p_i=1/n$），加权均值 $\mu=\sum_i p_i x_i$，收入份额 $q_i=p_i x_i/\mu$，则

$$T=\sum_{i:q_i>0} q_i\ln(q_i/p_i).$$

数值和权重必须有限且非负。零值的贡献为零，零权重组不参与计算；权重总和与加权均值必须为正。空输入、缺失值、负值或长度不一致会明确报错。关系数列必须来自已证明对齐的同一行域，内存数列按位置对齐。需要处理缺失值时，应在上游共同筛选样本，不能分别删去两列的不同观测。

唯一输出 **Result** 为结构化数据，包含 `theil_t`、`form` 和 `observations`（输入的个体数或组数，包括零权重组）。正数值全部相等时，指数在浮点误差范围内为零；指数越大，差异越大，其范围不限于 0–1。

仅有组均值时，结果表示**组间差异**。缺少组内信息时，不能恢复完整总体的泰尔指数，也不提供组内/组间分解。例如，组均值 `[1, 3]`、权重 `[3, 1]` 与个体数据 `[1, 1, 1, 3]` 的结果相同，约为 `0.1438410362`。

公式与分解参见：[世界银行研究工作论文 3919](https://documents1.worldbank.org/curated/en/122811468049747658/pdf/wps3919.pdf)。
