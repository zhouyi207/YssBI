# 效度检验（KMO / Bartlett）

连接至少两个对齐的数值**题项（items）**，每行是一位答题者。
完整观测数需大于题项数，题项相关矩阵必须非奇异。常数列、缺失值和非有限数值会报错。

**result** 输出总体 KMO、逐项取样适切性 MSA（`item_msa` 与 `item_names` 同序），
以及 Bartlett 球形检验的卡方统计量、自由度和近似 p 值。
KMO 比较相关系数平方和与偏相关系数平方和，分母为零时为空。

这些统计量检查相关结构是否适合因子分析，不能单独证明内容、聚合或区分效度。
需要因子载荷、共同度和因子得分时，请使用探索性因子分析节点；两个节点共用 KMO/Bartlett 算法。
使用全部观测，不设固定行数上限；执行受内存、取消与期限控制。
