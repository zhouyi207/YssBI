# 聚类稳健标准误

拟合普通最小二乘回归，使用单维聚类的 CR1 三明治协方差。
允许同一聚类内的观测相关，假设不同聚类相互独立。

## 输入

- **response**：有限数值因变量。
- **clusters**：每行一个非空聚类标识，可以是数值、文本或分类值。
- **predictors**：一个或多个有限数值自变量。

各输入必须具有相同的行域和顺序。缺失值直接报错，不静默删行。
不设置固定行数上限。至少需要两个聚类、列满秩的设计，以及多于参数个数的观测。

## 参数

**constant**：默认包含截距。

## 计算与输出

设 $G$ 为聚类数、$N$ 为观测数、$K$ 为参数数，协方差为

$$
\widehat V=\frac{G}{G-1}\frac{N-1}{N-K}
(X'X)^{-1}\left(\sum_g X_g'\widehat u_g\widehat u_g'X_g\right)(X'X)^{-1}.
$$

结果包含系数、协方差、聚类数和观测数、修正系数，以及使用 $G-1$ 自由度的系数
t 检验和 95% 置信区间。回归系数与普通 OLS 一致，变化的是不确定性估计。
聚类很少时该渐近近似可能不准确。当前方法为单维聚类，不包含多维聚类或野生聚类 Bootstrap。
