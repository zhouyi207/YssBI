# RFM 模型

每行一位客户，连接已汇总且对齐的三列：
**recency** 为最近消费距今的天数（非负），
**frequency** 为消费次数（非负整数），
**monetary** 为净消费金额（有限数值，允许退款导致的负值）。
交易明细需先按客户汇总；缺失和非有限数值会报错。

逐列计算平均秩，R 的方向反转，因此距今时间越短评分越高。
设由差到好的名次为 r、客户数为 n，分档为
floor(5 × (r − 0.5)/n) + 1，范围 1–5。
相同数值始终同档；整列相同时均为 3 分。小样本或大量并列时可能有空档。

**result** 说明分档方法并统计各档人数。
**scores** 按原行序输出观测序号、R/F/M 三项评分及总分（3–15），可分页查看。
这些是当前样本内的相对评分，节点不自动套用营销客户标签。
