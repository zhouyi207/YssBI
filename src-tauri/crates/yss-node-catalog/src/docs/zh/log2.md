# Log2（以 2 为底的对数）

逐元素以 2 为底的对数：

$$
\text{Result} = \log_2 x
$$

**定义域：** $x > 0$。接受 `Int64`、`Float64` 或数值 `DataSeries`；输出为 `Float64` 或 `DataSeries<Float64>`。

标量直接计算，内存数列逐元素计算，惰性数列在消费结果时按批执行。空值、非法定义域、非有限输入/结果以及无法精确提升为 Float64 的整数均报错，不自动生成 null；不会修改源数据集。

## 用法

适用于以“翻倍”或比特尺度衡量增长的情形。正数约束与 **Ln** 相同。
