# 协方差分析（ANCOVA）

比较调整连续协变量后的组效应。输入一个数值 **Response**、1–8 个 **Factor** 和 1–32 个数值 **Covariate** 数列。因素有 2–32 个观测类别，数值编码按类别处理。所有输入逐行对齐，关系数列共享行域，拒绝缺失值。含截距的设计矩阵必须满秩、最多 256 列，观测数大于列数且残差方差为正。

**因素效应** 默认 `full_factorial`，包含所有因素交互；`main_effects` 只含因素主效应。协变量按观测均值中心化，始终以线性加性项进入模型，采用各组平行斜率；不加入因素与协变量交互。

**平方和类型** 默认 `type_iii`。I 型先按输入顺序加入协变量，再加入主效应和各阶因素交互；II 型调整其他项但排除本项的高阶关联项；III 型使用和为零对比，调整所有其他项。III 型因素效应是在协变量均值处、等权因素边际均值的比较。

对每个因素或协变量项，$H_0$ 为相关对比系数全为零，$H_1$ 为至少一个非零。统计量为

$$SS_T=SSE_R-SSE_A,\qquad F_T=\frac{SS_T/d_T}{SSE_F/(n-p)}\sim F_{d_T,n-p}.$$

$R$、$A$ 为所选规则下不含及含检验项的模型，$F$ 为最终模型，$d_T$ 为该项列数，$p$ 包含截距。推断要求独立、近似正态且同方差的误差，协变量与响应关系线性，且组间斜率相同。完整交互模型要求因素组合完整；若斜率不同，此节点的平行斜率模型不适用。

唯一 **Result** 返回 `table` 的平方和、自由度、均方、F、p 值与偏 $\eta^2$，以及 `error`、总变异、$R^2$、`covariate_means` 和原始因素标签。`factor1`、`covariate1` 等按各自输入顺序编号。较小的因素 p 值支持控制协变量后仍有组差异，不自动提供调整均值或事后比较。
