# 马尔可夫预测

连接按时间排列的分类、文本、标识、二元或数值状态 `series`，至少两条无缺失观测。数值作为离散标签处理，保留整数的精确身份。状态按首次出现顺序编号，从 0 开始；不设固定行数或状态数上限。

`ts_horizon=10` 为正整数；`ts_pseudocount=0` 为加到每个转移单元格的有限非负伪计数。零表示最大似然转移概率；若某状态没有观测到任何向外转移，其对应行不可识别。可明确设置正伪计数，应用对称平滑。

$$
\widehat P_{ij}=\frac{N_{ij}+a}{\sum_j N_{ij}+Ka},\qquad
\pi_h=e_{s_n}'\widehat P^{\,h}.
$$

$N_{ij}$ 为相邻状态转移次数，$K$ 为观测状态数，$a$ 为伪计数，$s_n$ 为末行状态。模型假定齐次一阶马尔可夫链，不自动离散化连续数值，也不估计隐藏状态。

`state_labels` 保留原始标签；`counts`、`transition_probabilities` 以及 `forecast_probabilities` 的列均使用该顺序。`last_state`、`forecast_states` 为从 0 开始的状态编号。`forecast_labels` 恢复每期概率最大的标签，并列时按首次出现顺序选择。这些标签来自各期完整概率分布的边际众数，不是递归使用预测状态得到的一条路径。首个预测为末行之后一期；不提供转移显著性检验或预测置信区间。
