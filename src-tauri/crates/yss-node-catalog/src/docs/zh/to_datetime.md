# 转日期时间

将输入标量或数列转换为 Datetime 日历语义。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

- **日期时间形式**：默认为自动，保留已有日期、时间或日期时间形式；文本默认解析为日期时间。也可明确选择日期、时间或日期时间。
- **时间精度**：新解析值默认微秒，可选秒、毫秒或纳秒。
- **时间格式**：默认为空，按 ISO 格式解析；自定义格式采用 strftime，例如 `%d/%m/%Y` 或 `%d/%m/%Y %H:%M:%S %z`，最多 256 个字符。

## 转换规则

含时区输入移除时区但保留原日期和钟面字段，不换算为 UTC。精度损失会失败；转换为日期时不能丢弃非零时间部分。普通数值不会被隐式解释为 Unix 时间。空值保持为空值。

## 输出与执行

输出语义固定为 Datetime，确定后的日历形式和精度随输出传递。内存中的输入立即转换；惰性数列在消费时校验实际取值。本节点生成派生结果，不修改源数据集。
