# Kruskal–Wallis 检验

以合并秩比较多个独立组的分布。

## 输入与参数

在 `groups` 添加 至少两个数值输入，每组非空、有限且无空值。当前节点要求各列等长，关系数列须共享行域。无配置参数；数据的组间、组内观测应独立。

## 假设与统计量

$H_0$：各总体分布相同；$H_1$：至少一个分布不同。令 $k$ 为组数，$n_i$ 为各组样本量，$N=\sum_i n_i$，$R_i$ 为合并排序后第 $i$ 组秩和，$t_j$ 为各并列组大小：

$$
H_0^*=\frac{12}{N(N+1)}\sum_{i=1}^{k}\frac{R_i^2}{n_i}-3(N+1),\qquad
C=1-\frac{\sum_j(t_j^3-t_j)}{N^3-N},
$$

$$
H=\frac{H_0^*}{C}\overset{H_0}{\approx}\chi^2_{k-1}.
$$

并列值使用平均秩，$C$ 必须大于零。分布形状相近时可作位置差异解释；小样本下卡方近似可能不准。

## 输出与判读

`result` 为结构化结果。`statistic` 为修正后的 $H$，`degrees_of_freedom` 为 `[k−1]`，`p_value` 为卡方右尾概率，`sample_sizes` 为各组样本量。估计值和标准误为空。

$p<\alpha$ 表示至少一组不同；本节点不指出具体哪两组不同，也不执行事后多重比较。
