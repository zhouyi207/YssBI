# 固定效应 FE

连接等长且按当前位置逐项对应的数值数列：因变量 **Y**、至少一个 **X₁, X₂, …**、实体编号 **entity** 和时间 **time**。全部观测必须有限、无缺失，实体与时间组合必须唯一；执行时按面板键排序。实体需使用数值编号，文本标识请先编码。

**参数**：constant 默认 true；effects 默认 entity，可选 time、two_way；covariance 默认 cluster，可选 nonrobust、HC0、HC1、HC2、HC3。

实体效应模型为 $y_{it}=\alpha_i+x_{it}'\beta+\varepsilon_{it}$，通过组内变换估计共同斜率；time 吸收时间效应，two_way 同时吸收实体和时间效应。被吸收或共线的解释变量记录在 omittedTerms 中。cluster 按实体聚类。

唯一输出 **model** 可连接“面板模型汇总”和“面板估计尺度预测”。模型保留系数、协方差、效应统计，以及估计尺度的响应、设计、拟合值、残差和零起始源行分组。FE 的估计尺度为组内变换；不能将它当作新实体原始尺度的预测。

系数检验以 $H_0:\beta_j=0$ 对 $H_1:\beta_j\ne0$，统计量为估计值除以标准误，使用模型保留的 t 推断和自由度。数据需有足够的组内变化及正残差自由度；稳健标准误不修复内生性。
