# Egger 检验

连接至少三项独立研究的 effects 和正 variances，标准误须存在变化。令 $s_i=\sqrt{v_i}$，以含截距 OLS 拟合 $y_i/s_i=\alpha+\beta(1/s_i)+e_i$，设计须满秩。
不对称性检验为 $H_0:\alpha=0$ 对 $H_1:\alpha\ne0$，截距 t 统计量使用残差方差和 $k-2$ 自由度。confidence_level 默认 0.95，须严格介于 0 和 1。
result 为标准化响应回归摘要，包括名为 asymmetry_intercept、precision 的系数、协方差、残差自由度及区间。Egger 检验应读取截距 P 值。不对称也可能来自异质性或其他小样本研究效应，不能直接证明发表偏倚；研究数少时推断不可靠。

所有连接列必须逐行对齐且为有限值。节点拒绝缺失值，请先清理共同的研究表。效应须使用相同分析尺度和对照方向。新研究表以位置字段保留显式键；做 Meta 回归前可按研究键连接协变量。
