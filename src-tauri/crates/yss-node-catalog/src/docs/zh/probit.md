# Probit

二元 Probit 回归（IRLS）。对 $y_i \in \{0,1\}$：

$$
P(y_i=1 \mid x_i) = \Phi(x_i'\beta)
$$

其中 $\Phi$ 为标准正态 CDF。

连接对齐、有限的因变量及有序自变量，因变量只允许 0 或 1。截距、最大迭代次数（1–10000）和正容差实际控制拟合，默认包含截距、迭代 100 次、容差 1e-8。未收敛会明确报错。

输出 model、拟合概率 fitted 及因变量减拟合概率的 residuals。Summary 读取既有模型；Predict 接收模型及相同定义和顺序的自变量，不重新拟合，输出概率。

IRLS 使用工作响应 η+(y−p)/φ(η)，权重为 φ(η)²/[p(1−p)]。默认系数协方差为 Bernoulli-Probit 观测信息矩阵的逆（OIM）。Probit 系数不是对数胜算，因此不提供胜算比输出。
