# 类型转换

支持数值（Numeric）、分类（Categorical）、顺序（Ordinal）、二元（Binary）、日期时间（Datetime）、文本（Text）和标识（Identifier）七种语义。输入为标量时输出标量，输入为数据序列时输出数据序列；输出语义由“目标语义”参数决定。

## 参数

- **目标语义**：自动（默认）或上述七种语义。自动模式由输出端连接的下游输入 Pin 约束决定目标，不根据输入值猜测。
- **数值表示**：只对数值目标生效。自动保留已有数值表示，文本默认解析为实数，二元值转为整数 0/1；整数使用 Int64，实数使用 Float64。输出物理类型在执行计划构建时确定，不按数据批次变化。
- **值域与等级**：添加原始编码及标签。分类目标可以继承源分类、顺序或二元的已声明值域；从普通文本或数值创建分类时必须显式配置。顺序目标必须配置由低到高的等级，或继承已有顺序值域，不能按出现次序或字母顺序猜测。编辑后点击“应用值域”；二元映射需配置两个不同值及正值。
- **日期时间形式**：自动保留已有日期/时间表示，文本默认解析为日期时间；也可明确选择日期、时间或日期时间。
- **时间精度**：新解析值默认微秒，可选秒、毫秒或纳秒。不能静默舍弃更高精度，日期转换也不能丢弃非零时间部分。
- **时间格式**：留空使用 ISO 格式；自定义格式如 `%d/%m/%Y`、`%d/%m/%Y %H:%M:%S %z`。含时区输入保留原日期和钟面字段，不换算为 UTC。

## 转换规则

自动模式取所有下游输入 Pin 接受类型的交集，并保持输入的标量或数列结构。交集唯一时确定转换目标；未连接下游或仍有多个候选时，目标未确定，必须连接明确类型的下游或手动选择。约束冲突时显示类型冲突并阻止执行。仅连接不限类型的 Pin 不会自动选择输入语义。

例如文本输入连接转换节点，转换输出连接数值输入 Pin，则目标为数值。约束可以穿过重路由及泛型端口；重新连线或下游类型变化会重新推导目标并更新相关缓存。自动选项本身保持不变，不将推导结果写回节点参数。

空值始终保持为空值，不填充 0、false 或字符串。数值文本允许首尾空白、前导零以及实数模式中的小数和科学记数法；整数模式接受整数文本。数值转换拒绝溢出、非有限值、小数截断和不能往返保持数值的精度损失。例如 `001` 可以转为数值 1，`9007199254740993` 必须选择整数模式，不能静默舍入为实数。

未配置显式值域时，转二元接受数值 0/1、文本 `true`/`false`/`0`/`1`（区分大小写）以及已有布尔值；也可配置两个原始值及正值进行映射。Binary 列若声明了正值，则按其两值域和正值映射转换；非布尔物理表示的 Binary 列必须声明正值。转文本保留原始值的文本表示，不用类别标签替换。

分类和顺序转换保留原始值，并校验每个非空值属于配置值域，不生成临时类别编号。未声明的值和重复编码会报错。标签、等级顺序和时间表示会随运行值传递，后续转换可以继承，标量和内存数列也不会丢失这些信息。

标识转换保留前导零、宽整数及空字符串等原始表示，不按内容猜测数值类型，也不自动要求唯一。分类、顺序和标识转数值时解析原始值，不隐式输出类别索引或等级编号；日期时间不隐式转换为数值时间戳，普通数值也不隐式解释为 Unix 时间。

## 执行

数据序列转换保持原快照和行对齐，使用 DataFusion 惰性表达式；读取、预览或下游计算时按 Arrow 批次求值，不在建图时读取整列，也不修改源数据。转换计划构建成功不表示所有行已经校验，后续消费可能报告转换失败。过滤、投影和 LIMIT 可能减少实际求值的数据范围。

本节点生成派生结果，不修改源数据集。数据详情中的语义设置和物理类型修改仍由数据集操作负责。
