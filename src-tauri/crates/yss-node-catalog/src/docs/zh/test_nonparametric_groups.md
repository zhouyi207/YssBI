# 非参数组间检验选择器

通过 `method` 选择一种独立组非参数检验；一次执行只计算所选方法。

## 输入与参数

在 `groups` 添加 2–16 个非空有限数值序列，无空值。当前节点要求各列等长；关系数列须共享行域。`method` 默认为 `mann_whitney`：

| `method`         | 组数与用途                        |
| ---------------- | --------------------------------- |
| `mann_whitney`   | 恰好 2 组，双侧分布／位置比较     |
| `kruskal_wallis` | 2–16 组，总体分布比较             |
| `mood_median`    | 中位数比较；当前可靠构表仅限 2 组 |

本节点没有 `alternative` 参数。独立组不按行作配对差值，组间及组内观测应独立。

## 方法与假设

### Mann–Whitney

$H_0$：两总体分布相同；$H_1$：两者分布不同。合并排序并对并列值取平均秩，第一组秩和为 $R_1$：

$$
U_1=R_1-\frac{n_1(n_1+1)}2,\qquad
Z=\frac{U_1-n_1n_2/2}{\sqrt{V(U_1)}}\overset{H_0}{\approx}N(0,1).
$$

$n_i$ 是组大小；$V(U_1)$ 使用并列秩修正。采用双侧正态近似，无连续性校正或精确法。位置解释需要两组分布形状可比。

### Kruskal–Wallis

$H_0$：所有总体分布相同；$H_1$：至少一个不同。令 $k$ 为组数，$N$ 为总样本量，$R_i$ 为各组秩和：

$$
H=\frac{12\sum_i R_i^2/n_i\,/\,[N(N+1)]-3(N+1)}{C}
\overset{H_0}{\approx}\chi^2_{k-1}.
$$

$C=1-\sum_g(t_g^3-t_g)/(N^3-N)$，$t_g$ 为各并列组大小。全体值相同会使检验无法计算。

### Mood 中位数

$H_0$：总体中位数相同；$H_1$：至少一个不同。以合并中位数为界，对严格高于／低于中位数的计数构造列联表，等于中位数的值不计入：

$$
X^2=\sum_{ij}\frac{(O_{ij}-E_{ij})^2}{E_{ij}}
\overset{H_0}{\approx}\chi^2_{k-1}.
$$

$O_{ij}$ 为观测计数，$E_{ij}$ 为独立性下的期望计数。当前超过两组时构表未正确保持组别边际，不应据此解释多组结果。

## 输出与判读

`result`、`report` 返回同一报告。`method` 标明实际方法；`statistic` 分别为 $U_1$、$H$ 或 $X^2$。`degrees_of_freedom` 在 Mann–Whitney 中为空，其余为 `[k−1]`；`sample_sizes` 为各组输入样本量。Mann–Whitney 的 `details.u_complement` 给出另一组 U；Mood 的 `details.pooled_median` 给出合并中位数。估计值和标准误为空。

对有效的所选方法，`p_value` 小于 $\alpha$ 表示拒绝相应原假设。选择器不自动挑选方法，不作成对事后检验或多重校正。
