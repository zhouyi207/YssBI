# 模糊层次法 FAHP

将模糊互补判断方阵按列连接到 **criteria**，行列均按同一指标顺序。
取值范围 [0,1]，对角线为 0.5，A(i,j) + A(j,i) = 1，
绝对容差 1e−8。缺失及非有限数值会报错。

实现互补矩阵形式的 FAHP：
w(i) = [各行之和 + n/2 − 1]/[n(n − 1)]，再归一化。
单指标时权重为 1。**result** 输出权重及相容性指标
mean_ij |A(i,j) − w(i)/(w(i)+w(j))|，并按 ≤ 0.1 判定相容性。
**weights** 返回可继续连线的归一化权重。

这里使用单值互补偏好矩阵，不是三角模糊数扩展分析。
公式参考：[FAHP 算法](https://pubimage.spssau.com/algo/fahp.pdf)。
