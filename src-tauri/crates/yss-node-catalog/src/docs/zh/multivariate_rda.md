# 冗余分析（RDA）

输入 至少一个数值 **Response** 和 至少一个数值 **Constraint** 数列，所有列逐行对齐、关系输入共享行域，拒绝缺失。设响应数为 $p$，约束数为 $r$，观测数为 $n$；约束不能为常量或秩亏，须满足 $n>r+1$。

**保留维数** 默认 1，须不超过 $\min(p,r)$。**标准化变量** 默认关闭：响应中心化后保留原单位，开启时按样本标准差标准化响应。约束始终中心化并缩放，缩放不改变其张成空间。总响应变异必须为正。

RDA 先做多响应最小二乘，再对拟合响应做 PCA：

$$\widehat Y=X(X^TX)^{-1}X^TY,\qquad E=Y-\widehat Y,\qquad T=\widehat Y V_k.$$

$V_k$ 是拟合响应协方差的前 $k$ 个特征向量。输出采用直接拟合响应得分，未使用绘图软件的其他坐标缩放约定。

**置换次数** 默认 199，范围 0–9999，0 关闭检验；**随机种子** 默认 42。$H_0$ 为约束与多响应无关联，$H_1$ 为存在关联，整体伪 F 为

$$F=\frac{SS_{\mathrm{fit}}/r}{SS_{\mathrm{error}}/(n-r-1)},\qquad p=\frac{1+\#\{F_b\ge F\}}{B+1}.$$

$B$ 为置换次数，$SS$ 为全部响应的平方和。整体交换响应行而保留其变量间结构；推断要求观测在原假设下可交换，不适用于需要区组/序列约束的设计。完美拟合时 F 与置换 p 值为 null。

**Result** 返回总/受约束/残差惯性（平方和除以 $n-1$）、两类特征值、响应权重、$R^2$ 与调整值 $1-(1-R^2)(n-1)/(n-r-1)$、F、自由度及置换信息。调整 $R^2$ 可以为负。

**Scores** 是独立计算的拟合响应得分表，列为 `axis1` 至 `axisK`，保持原行顺序，可继续选列、绘图或分析。模型和检验不会在编辑阶段扫描数据。

方法参考：[vegan RDA](https://vegandevs.github.io/vegan/reference/cca.html)。
