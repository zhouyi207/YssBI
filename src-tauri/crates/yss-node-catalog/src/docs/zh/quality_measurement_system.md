# 测量系统分析（交叉 Gage R&R）

按长表连接对齐的**测量值 measurements**、分类**零件 parts**和**操作者 operators**。
至少两个零件、两名操作者；每个零件 × 操作者组合须有相同的重复次数，至少两次。
缺失值、非有限值、组合缺漏或不均衡设计会报错。报告保留原始分类标签，不限制测量行数。

**include_interaction** 默认开启，使用均衡交叉随机效应 ANOVA，估计重复性、操作者、
零件 × 操作者交互及零件变异。零件和操作者的 F 检验以交互均方为分母，交互检验以重复性均方为分母。
关闭交互时，将其平方和与自由度合并入重复性误差；不会按显著性自动选模型。

**result** 输出 ANOVA 表和方差成分。再现性 = 操作者 + 交互变异，
总量 Gage R&R = 重复性 + 再现性，总变异还包含零件间变异。
负方差估计截为零并列出被截断的成分。研究变异为 6 倍标准差。
方差贡献百分比与研究变异百分比含义不同，不能混用；总变异为零时比例为空，检验分母为零时 F/p 为空。

本节点面向连续测量的均衡交叉设计。嵌套设计、计数一致性、参考值偏倚、线性和稳定性需要不同研究，
不在此节点内推断，也不自动给出验收结论。
