# 按组调用 Apply

连接**已分组数据帧**，选择恰有一个 DataFrame 参数、返回 DataFrame 的图函数。每次调用接收一个组的行，
其中包含分组键列。函数可以改变行数，也可以返回零行。

**分组键前缀**默认为 `group.`，也可以为空。Apply 在每个返回行前附加原分组键。例如按 `industry` 分组，
函数返回 `sales` 列，默认输出为 `group.industry, sales`。若返回列与添加前缀后的键列重名，执行失败；
请修改前缀或返回列名。

结果按组顺序拼接，保留各返回表的行顺序。所有组的返回列名、列顺序、精确物理类型及语义配置必须一致。
Apply 检查每一组，不通过补空列或只读取第一组来推断全部输出。

空输入会用空源表调用一次函数以确定结构，最终输出零行，因此函数需要支持空表。各组顺序执行，
共用运行取消与预算控制。失败信息保留组编号及函数位置，不发布尚未完成的组合结果。
