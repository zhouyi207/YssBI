# 转顺序

将输入标量或数列转换为 Ordinal，保留原始编码并声明等级顺序。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

**等级与标签**按由低到高的顺序配置原始编码及标签，默认为空配置。空配置仅可继承已有顺序值域；其他输入必须明确配置等级。

## 转换规则

不会按出现顺序或字母顺序猜测等级，也不会用等级编号替换原始值。每个非空输入必须属于声明值域；重复编码和未声明的取值会失败。空值保持为空值。

## 输出与执行

输出语义固定为 Ordinal。等级顺序与标签随输出传递，后续转换可继承。内存中的输入立即转换；惰性数列在消费时校验实际取值。本节点生成派生结果，不修改源数据集。
