# 生存决策曲线

连接逐行对齐的 `time` 与 `event` 数列。时间必须有限且严格大于 0，单位保持一致；`event=1`（或 true）表示事件发生，`0`（或 false）表示右删失。缺失值会导致计算失败，不自动删行。假设在给定模型或分组条件下删失独立于事件过程；来自不同表的数列不能仅凭长度相同视为对齐。

连接范围 [0,1] 的 `predicted_risk`，对应与观测事件相同的正时点 `survival_horizon=1`。参数为 `decision_threshold_min=0.01`、`decision_threshold_max=0.99`，满足 $0<\min<\max<1$；`decision_points=99`，至少为 2。阈值按包含两端点的等距网格取值。

## 净获益

在阈值 $p$，选中预测风险不小于 $p$ 的观测。令 $q$ 为选中比例，$r=1-\widehat S_{\rm selected}(t)$ 为选中者的 Kaplan–Meier 事件风险：
$$NB_{\rm model}=q\left[r-(1-r)\frac{p}{1-p}\right].$$
未选中任何观测时，模型净获益为零。“全部处理”使用 $q=1$ 与总体 Kaplan–Meier 风险；“均不处理”净获益为零。假设每个选中子集内删失独立。本实现为未标准化净获益，不包含额外检查或处理代价。

`result` 返回模型曲线、虚线表示的全部处理/均不处理参考线、时点、点数信息，以及 `estimates`（阈值、选中人数及三种策略净获益）。在特定阈值及上述假设下，较大净获益代表较优的策略表现。不输出不确定性区间或 p 值。

非空选中子集需要随访支持达到预测时点，除非其生存概率已降为零。从模型 `predictions` 表选择 `time`、`event`、`risk` 可保持逐行对齐。同一拟合样本的结果属于表观性能，节点不自动交叉验证或重新校准概率。
