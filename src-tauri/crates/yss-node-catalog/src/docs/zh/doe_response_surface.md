# 响应面分析（完整二次模型）

连接对齐的数值 **Y** 和连续 **factors**，每个因素一列。
自动以观测最小值与最大值的中点为中心、半极差为尺度，将各因素编码为 z。
OLS 拟合截距、所有 z、所有 z² 和两两交互项 zᵢzⱼ；报告系数针对编码变量，`centers`、`half_ranges` 用于换算。

p 个因素需要 `(p+1)(p+2)/2` 个参数；观测数必须大于该数，设计矩阵须满秩。
常数因素、共线因素和不足以区分线性与二次项的设计会失败，而不是静默删项。

**result** 包含系数、经典 OLS 标准误与 95% 区间、协方差及拟合指标。
**details** 报告编码坐标下 Hessian 的特征值、驻点类型（最大、最小、鞍点或退化）。
非退化时解出编码与原始因素单位的驻点、预测响应，以及是否在各因素已观测范围内。
退化时驻点为空，不伪造唯一最优点。

**observations** 是完整分页表：观测序号、原始响应、拟合值、残差；不设固定行数上限。

该模型假定独立、同方差误差。没有自动失拟检验、受约束区间优化或多响应优化。
“处于因素范围内”只检查包围盒，并不表示位于试验点凸包内或已经实验验证；驻点需结合模型诊断与确认试验判断。
