# 线性回归汇总

将 **线性回归** 的 **Model** 输出连接到此节点的 **Model** 输入。支持 OLS、WLS 和 GLS；此节点没有拟合配置，也不重新估计。

在节点的 **Parameters → Configure** 中选择报告内容。默认包含模型概览、系数表、回归方程和方差分析；可增加系数图、诊断、残差图、观测表、自相关、序列相关及假设检验。选择检验后配置对应的滞后阶数、BG 选项或假设表达式。

**Result** 与 **Report** 共享上游原生模型，保存本次内容选择和已计算的检验。仅计算选中的附加分析及其必要依赖，相同模型和参数复用已有分析；上游拟合所需的计算不受内容开关影响。表格和图形按需读取。

Report 中的 **添加内容 → 添加并计算** 会将漏选内容加入同一个节点配置并执行当前 Summary。计算期间保留原报告，成功后显示新结果；模型或数据变化时基于当前输入重新计算，避免混用不同执行的结果。节点配置参与撤销、重做和显式保存，补选操作不自动保存图。

WLS/GLS 的平方和及 R² 使用相应变换尺度；拟合值、残差图和观测表保留原始尺度。
