# Equal（==）

判断两值是否相等：

$$
\text{Result} = (A = B)
$$

比较两个语义相同的标量或数据序列。在 Detail 的配置中选择比较模式：

- `exact`（默认）：支持七种基础语义。Numeric 按精确数值比较，整数、无符号整数与浮点表示可相等，不使用 epsilon 或有损浮点提升。文本按大小写敏感的原值比较，不解析数字；分类和顺序比较编码，不比较显示标签。
- `tolerance`：仅用于 Numeric，按对称公式 `abs(a-b) <= atol + rtol * max(abs(a), abs(b))` 比较。此时显示绝对容差（默认 1e-12）和相对容差（默认 1e-9）。容差必须有限且非负；到 Float64 的有损转换被拒绝。将两项设为零可精确比较转换后的数值。

两个标量返回二元标量；任一输入为序列时返回逐元素二元序列，并支持任一侧标量广播。内存数列必须等长，惰性数列必须属于同一关系行域，不能混用未对齐的内存数列。任一元素为空时返回空值；非有限数值或不支持的表示报错。

## 用法

为下游计算生成比较结果。标准化与逆标准化的浮点往返校验可选择容差模式，并按数据尺度调整容差；不会修改输入值。六个比较节点都支持相同配置；配置相同时，“不等于”是非空“等于”结果的取反。
