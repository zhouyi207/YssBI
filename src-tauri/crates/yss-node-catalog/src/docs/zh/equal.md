# Equal（==）

判断两值是否相等：

$$
\text{Result} = (A = B)
$$

比较两个语义相同的标量或数据序列，支持七种基础语义。Numeric 按精确数值比较，整数、无符号整数与浮点表示可相等，不使用 epsilon 或有损浮点提升。文本按大小写敏感的原值比较，不解析数字；分类和顺序比较编码，不比较显示标签。

两个标量返回二元标量；任一输入为序列时返回逐元素二元序列，并支持任一侧标量广播。内存数列必须等长，惰性数列必须属于同一关系行域，不能混用未对齐的内存数列。任一元素为空时返回空值；非有限数值或不支持的表示报错。

## 用法

为下游计算生成比较结果。比较完整列表或记录并返回单个结果时，请使用“整体相等”。
