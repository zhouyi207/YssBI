# 线性回归

拟合因变量 **Response** 与有序自变量 **Predictors**。在 Detail 的**模型参数**组中选择估计方法 **OLS**（默认）、**WLS** 或 **GLS**，并设置是否包含截距。

- **OLS**：连接因变量和至少一个自变量。
- **WLS**：另外添加一个 **Weights (WLS)** 输入，连接与训练样本对齐的精度权重数列。所有权重必须有限且严格大于零；权重表示误差方差的倒数比例，不是调查抽样权重。
- **GLS**：按矩阵列顺序添加 **Covariance column (GLS)** 输入。每个输入是一列数值；n 个观测需要 n 列、每列 n 个值，构成有限、对称正定的相对误差协方差矩阵 Σ，误差方差为估计尺度乘 Σ。矩阵的行列顺序必须对应训练样本。矩阵需要 O(n²) 内存，受执行输入预算限制。

只添加当前方法需要的辅助输入；切换方法后移除不适用的权重或协方差输入。因变量、自变量和 WLS 权重必须来自同一可证明行域；内存数列按位置对应且等长。缺失值和非有限数值被拒绝，需要在上游对共同样本筛选。

**估计方法**与**标准误方法**分别配置。OLS/WLS 支持常规、HC0–HC3、HAC、Newey–West 和固定尺度；GLS 当前仅接受 **nonrobust**，其他选项运行时被拒绝。

**Model** 输出完整、不可变的线性回归模型。将它连接到 **线性回归汇总** 或 **线性预测**；同一次运行复用拟合结果。**Fitted** 和 **Residuals** 输出原始尺度的拟合值与残差（不是加权或白化后的值）。
