# 锐断点回归 RDD

在已知处理断点两侧分别拟合局部线性趋势，估计结果变量的跳跃。

## 输入和参数

连接对齐的数值 `Y` 与 `running` 数列。默认参数为 `rdd_cutoff=0`、`rdd_bandwidth=1`、`rdd_kernel=triangular`。
带宽必须为有限正数，单位与运行变量一致；核函数也可选择 `uniform`。
运行变量等于断点时归入处理侧，不自动选择带宽。

三角核使用 $|r_i-c|<h$ 的观测，权重为 $1-|r_i-c|/h$；均匀核使用 $|r_i-c|\le h$，权重为 1。两侧均须有足够多不同运行值，使设计满秩并可计算 HC3；杠杆值为 1 的观测会导致拒绝计算。输入须完整且有限。

## 模型与推断

令中心化运行值 $x_i=r_i-c$，$D_i=1[r_i\ge c]$，通过加权最小二乘拟合：

$$
y_i=\alpha+\tau D_i+\beta x_i+\gamma D_i x_i+\epsilon_i.
$$

跳跃系数 $\tau$ 表示局部处理效应。HC3 三明治协方差将所选带宽视为固定。系数检验为 $H_0:b_j=0$、$H_1:b_j\ne0$，统计量 $z=\hat b_j/SE_j$ 采用渐近标准正态分布，返回双侧 p 值和 95% 区间。

因果解释要求锐断点分配机制、潜在结果均值在断点处连续，以及运行变量不存在精确操纵。当前不提供模糊断点、自动带宽、偏差校正或稳健偏差校正区间。

## 输出

`coefficients` 依次为 `intercept_left`、`discontinuity`、`slope_left`、`slope_change`。
`result` 还包含协方差、左右观测数、断点、带宽、核函数、从 1 开始的保留行索引 `rows`，以及这些行的拟合值和残差。
右侧斜率为 $\beta+\gamma$；结果是断点局部效应，不是总体 ATE。
