# 合成控制

以未接受干预的供体结果序列的凸组合，在干预前匹配一个处理单位。

## 输入和参数

连接对齐的数值 `response`（处理单位）和至少一个重复端口 `donors`。各行须已按时间顺序排列，并使用含义一致的共同时间网格；节点不排序或聚合。所有输入须完整且有限。

`pre_periods=10` 表示仅使用前十行拟合权重；须为正整数且小于总行数，其余行为干预后。`max_iterations=5000` 须为正，`tolerance=0.0000001` 范围为 [1e-12,0.01]。优化器在缩放后的干预前数据上检查单纯形最优性差距；未收敛会明确失败。

## 估计

令处理单位结果为 $y_t$，供体向量为 $x_t$，求解：

$$
\hat w=\arg\min_{w\ge0,\;\mathbf1'w=1}
\frac1{T_0}\sum_{t=1}^{T_0}(y_t-x_t'w)^2.
$$

不加入截距、负供体权重、协变量重要性搜索或正则惩罚。由均匀权重初始化，对数值上的非唯一解给出可复现结果。干预后数据不参与权重拟合。

合成结果为 $\hat y_t^0=x_t'\hat w$，差距为 $g_t=y_t-\hat y_t^0$。干预后效应是干预后差距的均值；干预前／后 RMSPE 分别为对应时段平均平方差距的平方根。

## 输出与解释

`result` 包含按供体输入顺序排列的 `donor_weights`、保持原行顺序的 `synthetic` 与 `gaps`、`post_effect`、`pre_rmspe`、`post_rmspe`、期数和迭代次数。允许只有一个供体，其权重为 1。

因果解释要求合适的未干预供体、无干扰／预期效应，以及干预后仍可信的反事实关系；干预前拟合较差会削弱比较。此节点不提供安慰剂 p 值、常规置信区间或独立样本 ATE。方法背景见 [合成控制与平衡方法](https://www.nber.org/papers/w22791)。
