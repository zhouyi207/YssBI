# 模糊综合评价

**memberships** 每列一个评语等级，每行一个指标。
输入非负有限隶属度或频数；每行总和须为正，节点逐行归一化。
可选 **criterion_weights** 按行提供指标权重，不连接时等权；
可选 **grade_scores** 按列提供各等级的有限分值。这两个向量可来自独立行域。

**fuzzy_operator** 支持 product_sum（加权求和，默认）、
min_max（最小值取大）、product_max（乘积取大）、
min_sum（最小值求和并截到 1）。合成结果再归一化。

**result** 输出指标权重、原始与归一化隶属度、全部最大隶属度等级
（容许浮点舍入误差），以及提供 grade_scores 后的加权等级分数。
**combined_memberships** 返回归一化隶属度向量，供后续连线使用。
未提供等级分值时不自行假定评分。一个节点评价一个指标体系，
可通过隶属度输出组合多个层级。
