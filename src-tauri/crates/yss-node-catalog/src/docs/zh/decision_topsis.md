# TOPSIS

默认逐列除以欧氏范数，再乘归一化权重，按正负向指标确定理想点与负理想点。计算欧氏距离 $D_i^+$、$D_i^-$，接近度为 $C_i=D_i^-/(D_i^++D_i^-)$。先加权再算距离，因此距离平方中的权重也平方。理想点重合导致总距离为 0 时会报错。

## 输入与参数

通过 **criteria** 按顺序连接已对齐的数值指标列，每行对应一个评价对象。至少需要一行；客观赋权至少需要两行观测。空值、非有限数值或观测数不一致会报错，不设置固定行数上限。

**cost_criteria** 填写越小越好的指标位置，从 1 开始，留空表示全部正向。提供评分标准化选项的节点可选 **minmax**（极差）、**vector**（向量）或 **none**（原值）。极差标准化将常量列置为 0。加法评分中，负向指标使用 1 减极差值（常量仍为 0），或对原值/向量值取负；秩和距离方法直接按指标方向计算。

提供 **weight_method** 的节点默认等权，通用“权重”节点默认熵权。选 **explicit** 时须连接一份 **criterion_weights** 数值向量，按指标端口顺序给出非负有限权重，长度等于指标数且总和为正；权重向量使用独立行域。其他方法不接收外部权重向量。客观赋权始终使用各自定义的预处理，与评分标准化选项分开。

## 输出

**result** 含方法、标准化方式、指标名称与方向、归一化权重和赋权统计量。
**scores** 为可分页的逐行结果表，保留全部观测，包括从 1 开始的观测序号、得分、按得分降序的排名，并列使用平均名次。TOPSIS 还输出理想点与负理想点距离。
**weights** 是可连接到其他节点评分的权重向量。得分越高表示相对更优，得分依赖当前样本，不是概率或显著性检验。
