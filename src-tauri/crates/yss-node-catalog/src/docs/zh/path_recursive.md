# 路径分析（观测变量递归线性模型）

按端口顺序连接至少两个连续变量，方程中分别用 x1、x2……引用。`equations` 默认 `x2 ~ x1; x3 ~ x1 + x2`，该示例需要三个输入。可用分号或换行分隔方程；每个因变量只出现一个方程，右侧用加号列出预测变量。每个方程自动包含截距。变量引用与列名无关。

仅支持无环有向模型。自回归边、循环、同一方程的重复预测变量、重复因变量和越界引用都会报错。不接受潜变量、残差相关、等式约束或完整 lavaan 语法。

每个方程用 OLS 拟合，所有输入须对齐、有限且无缺失；不自动删行。每个方程的设计须满秩，n 必须大于方程参数数目。方程不必按拓扑顺序书写。

**result** 报告输入变量名、方程索引、原始单位系数、经典同方差协方差和各方程拟合指标。系数使用双侧零系数 t 检验，自由度为 n−k，区间为 95%。这是逐方程 OLS，不计算潜变量 SEM 的整体卡方拟合、CFI、TLI 或 RMSEA。

**effects** 分页表报告所有不同变量有序对的 `source, target, direct, indirect, total, standardized_total`，索引从 1 开始。直接效应是边系数，总效应是所有有向路径上系数乘积之和，间接效应为总效应减直接效应；没有路径的变量对为 0。标准化总效应为总效应乘来源变量样本标准差再除以目标变量样本标准差，零方差时留空。合成效应仅给点估计，不附加未经计算的标准误或 p 值。

**observations** 为每个方程保留所有行，列为 `variable, observation, response, fitted, residual`；先按方程书写顺序，再按原始行顺序排列。没有固定观测数或变量数上限，结果规模受执行资源预算约束。

模型解释假定方程误差独立、外生变量适当且线性结构正确。路径分解描述指定模型，不单独证明因果关系。
