# Panel Summary

连接 Panel Fit 产生的 `model`。Configure 中的 `model_summary`、`coefficient_table`、`effects_statistics` 和 `estimator_statistics` 分别控制模型概览、系数、效应及估计器统计，默认全部开启。估计器统计随拟合方法变化，例如 RE 的 Wald 或 MLE 的似然统计。

`result` 只包含所选内容，复用已拟合系数、协方差及分组统计，不重新拟合，不需要原始输入。

面板拟合另外输出估计器实际尺度上的 `fitted` 和 `residuals`：FE 为组内变换，RE/MLE 为准去均值，FD 为一阶差分，Between 为组均值，LSDV 为原始观测。保留的估计样本包含响应、按列设计矩阵、系数及零起始源行分组，不把变换尺度残差伪装为原始尺度预测。残差输出可连接既有正态性、ACF/PACF 和序列诊断节点。

“面板估计尺度预测”接收该模型及按估计设计顺序提供的已变换解释变量列（不要重复输入自动截距），在同一尺度预测；不向新实体外推吸收效应。

“比较面板估计器”接收原始对齐的响应、解释变量、实体和时间，`estimators` 为逗号分隔的估计器（最多六个、不重复）。各模型使用所选效应、截距和协方差；不兼容或失败的模型单独记录，成功模型仍保留。系数行使用原变量标签，并显示省略原因和类别。
