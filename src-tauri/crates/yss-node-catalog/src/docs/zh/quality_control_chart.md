# 质量控制图（I / MR）

连接按过程或时间排序的数值**测量值（measurements）**，至少两行完整观测。
缺失值和非有限数值会报错；节点不会自动重新排序。

**chart_kind** 可选单值 I 图或移动极差 MR 图。
MR 为相邻观测差的绝对值，组内标准差估计为平均 MR / 1.128。
I 图控制限为均值 ± 3 倍组内标准差；MR 图中心为平均 MR，下限为 0，上限为 3.267 × 平均 MR。

**result** 绘制全部点及三条参考线；**summary** 报告控制限、标准差估计和严格越界点数。
**observations** 保留全部绘图值与越界标记（0/1），MR 的首点对应原第 2 行。
图形不抽样，不会因显示抽样遗漏越界点。

控制限使用当前样本估计，属于 Phase-I 分析；只检查单点越界规则，不自动剔除异常并重估，
不包含连续游程规则、子组或计数控制图。常数数据的三个控制限重合。
控制限描述过程波动，不等于工程规格限，也不能单独证明过程稳定。
