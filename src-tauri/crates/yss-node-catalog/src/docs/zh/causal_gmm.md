# 线性工具变量 GMM

使用一阶段或两阶段广义矩估计拟合线性方程。

## 输入和参数

连接对齐的数值 `Y`、至少一个重复端口 `X₁, X₂, …` 和至少一个 `instruments`。
必须提供完整工具集合，包括以自身作为工具的外生自变量。`constant=true`（默认）会在回归与工具矩阵中同时加入截距，请勿重复传入常数列。

`gmm_steps=two_step`（默认）使用异方差矩权重；`one_step` 使用 2SLS 权重。
两个设计矩阵均须满列秩，观测数须大于工具数，工具数须不小于系数数。缺失或非有限数据会被拒绝，不自动删行。

## 估计与推断

令工具向量为 $z_i$，自变量向量为 $x_i$，残差为 $u_i=y_i-x_i'\beta$，且 $\bar g(\beta)=n^{-1}\sum_i z_i u_i$：

$$
\hat\beta=\arg\min_\beta \bar g(\beta)'W\bar g(\beta).
$$

初始权重为 $(Z'Z/n)^{-1}$。两阶段方法再用第一阶段矩贡献的非中心化协方差之逆作为权重。两种方法均以最终残差计算 HC0 三明治协方差，不作小样本校正。

系数检验为 $H_0:\beta_j=0$、$H_1:\beta_j\ne0$，统计量 $z=\hat\beta_j/SE_j$ 使用渐近标准正态参考分布，返回双侧 p 值及 95% 区间。

仅过度识别的两阶段拟合返回 Hansen 检验 $J=n\bar g'W\bar g$。在 $H_0:E[z_i u_i]=0$ 下，参考分布为渐近 $\chi^2_{q-p}$，其中 $q$、$p$ 分别为含截距的工具数与系数数；备择假设为至少一个矩限制不成立。小 p 值拒绝联合限制，大 p 值不能证明工具足够强。

## 输出

`result` 包含 `coefficients`、`covariance`、`fitted`、`residuals`、原单位下的 `moments`、数量、`steps` 和可为空的 `hansen_j`。
数组遵循输入行列顺序。方法要求有效工具、识别条件及独立观测。此节点实现线性工具变量 GMM，不接收非线性矩表达式，不提供聚类推断；动态面板 GMM 属于独立方法。
