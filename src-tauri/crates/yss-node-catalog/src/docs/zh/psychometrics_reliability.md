# 信度（Cronbach α）

连接至少两个对齐的数值**题项（items）**，每行是一位答题者，至少两行。
缺失值和非有限数值会报错。请先统一计分方向、处理反向题，并按预期量表维度连接题项；节点不会自动反向计分。

**result** 输出原始及标准化 Cronbach α、总分均值与样本标准差。
原始 α 使用各题项方差和总分方差计算，保留负值；标准化 α 使用单位方差题项，任何题项为常数时为空。

**item_statistics** 输出题项均值、样本标准差、校正题总相关（总分扣除当前题项）和删除当前题项后的原始 α。
零方差导致相关无定义，或删除后不足两个题项、剩余总分无变异时，相应统计值为空。

α 用于评估其测量假设下的内部一致性，不能据此证明单维性或效度。本节点不估计 omega 或重测信度。
使用全部观测，不设固定行数上限；执行仍受内存、取消与期限控制。
