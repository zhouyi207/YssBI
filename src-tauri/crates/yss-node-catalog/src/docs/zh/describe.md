# 描述

对数据帧或数据序列逐列进行描述统计，输出结构化 Result。在节点的详细信息中展开“结果”，可按列展开查看对应指标。

## 输入

**Data**：一个数据帧，或 Numeric、Categorical、Ordinal、Binary 数据序列。

本节点无需配置参数。数据帧按原列顺序统计全部受支持的列；数据序列直接统计自身，输出一个列摘要。

数据帧中的 Text、Datetime、Identifier 列不参与统计；没有受支持的列时无法计算。分类、顺序和二元数据按其语义统计，不因底层使用整数编码而改作数值统计。

## 输出

`result.columns` 是以原始列名为键的 JSON 对象，直接包含各列的描述统计。每列包含 `position`（受支持列的输入顺序，从 1 开始）、`semantic`（语义类型）、`count`（非空数量）和 `missing`（缺失数量），以及对应的指标：

| 输入语义                     | 指标                                                |
| ---------------------------- | --------------------------------------------------- |
| Numeric                      | `mean`、`std`、`min`、`q25`、`median`、`q75`、`max` |
| Categorical、Ordinal、Binary | `unique`、`categories`                              |

每列只返回对应语义的字段：Numeric 不包含分类指标，Categorical、Ordinal、Binary 不包含均值、标准差或分位数等数值指标。

数值指标忽略缺失值；`std` 是以有效样本数减一为分母的样本标准差。分位数在排序后从零开始的 `(n−1)p` 位置线性插值，其中 `n` 是有效样本数。

类别数排除缺失值，空字符串是有效类别。

`categories` 直接包含已出现的每个非空类别，以从 `"1"` 开始的连续编号作为对象键。Ordinal 按声明的等级顺序排列，其余按原值升序排列。每项包含：

| 字段         | 含义                                                               |
| ------------ | ------------------------------------------------------------------ |
| `value`      | 类别原值；Decimal 和超出 JavaScript 精确整数范围的值以精确文本返回 |
| `label`      | 已声明的类别标签；没有标签时不添加此字段                           |
| `frequency`  | 该类别的频数                                                       |
| `proportion` | 该类别频数占非空数量的比例                                         |

Result 面板直接显示完整的逐列统计及类别频数 JSON；详细信息按 `position` 顺序展示同一份结果，分类列可展开“类别频数”查看每个类别。

适用但未定义的指标为 Null，例如有效数不足两项时的标准差。没有非空类别时，`unique` 为 0，`categories` 为空对象。非有限数值或非有限计算结果会报错。
