# RCS样条分析

连接对齐的有限观测，缺失值会被拒绝。除下述说明外，响应为数值，`X₁, X₂, …` 按端口顺序接收 至少一个数值列，对应 x1、x2……。分类自变量须显式编码；未惩罚模型须设计满秩且残差自由度为正。

## 方法与参数

响应另接单个自变量，构造 x、d1……d(K−2) 基函数，再拟合含截距、尾部线性的 OLS；`(u)+` 表示 max(u,0)。`knot_mode=auto`、`knot_count=4`（3–8）：三个节点采用 0.1/0.5/0.9 分位点，其他数量在 0.05 至 0.95 间均匀取点并线性插值。手动填写 3–8 个有限递增 `knots`。拒绝重复分位点/秩亏基函数；明细按输入顺序保留节点、基函数名称及完整列，x1 为线性项、其后为非线性项。此处为含数值设计的样条回归，不是通用响应分布变换。系数 t 检验采用 n−K 自由度，无联合非线性/节点选择检验。

$$
d_j(x)=\frac{(x-t_j)_+^3-\frac{t_K-t_j}{t_K-t_{K-1}}(x-t_{K-1})_+^3+\frac{t_{K-1}-t_j}{t_K-t_{K-1}}(x-t_K)_+^3}{(t_K-t_1)^2},\quad j=1,\ldots,K-2.
$$

## 输出

唯一输出是结构化 `result`，在 Inspect 中查看数值或报告。模型保留系数、协方差、拟合/残差数组、`statistics`、迭代信息及方法特有 `details`。有定义时，系数推断含标准误、以所报告系数为零作为 H0 的双侧检验及 95% 区间。未定义/不适用推断为 `null`，不适用数组为空；工作流在 `stages` 中保留模型和明确选择信息。不收敛/数值失败会使执行失败。
