# Convert（类型转换）

将**标量**值转换为另一种标量类型。在 **Output** 引脚上设定目标类型（类型推断会约束 **Input**）。

## 支持的标量转换

行 = 源类型，列 = 目标类型。✓ = 支持；— = 请用专用 **DataSeries** 转换节点。

| 源 \ 目标       | Boolean | Int64    | Float64     | String     | Categorical | DataSeries |
| --------------- | ------- | -------- | ----------- | ---------- | ----------- | ---------- |
| **Boolean**     | ✓       | ✓ (0/1)  | ✓ (0.0/1.0) | ✓          | —           | —          |
| **Int64**       | ✓ (≠0)  | ✓        | ✓           | ✓          | —           | —          |
| **Float64**     | ✓ (≠0)  | ✓ (截断) | ✓           | ✓          | —           | —          |
| **String**      | ✓*      | ✓*       | ✓*          | ✓          | —           | —          |
| **Null**        | → false | → 0      | → 0.0       | → `"null"` | —           | —          |
| **Categorical** | —       | —        | —           | —          | —           | —          |
| **DataSeries**  | —       | —        | —           | —          | —           | —          |

\*字符串解析：Boolean 接受 `true`/`false`、`1`/`0`、`yes`/`no`、`on`/`off`（不区分大小写）；无效字符串报错。Int64/Float64 使用标准 parse 规则。

## 用法

将标量源接到 **Input**，设定 **Output** 类型并连到下游。列级转换请用 **String to Float64**、**Int64 to Categorical** 等节点。
