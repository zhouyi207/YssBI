# String Constant

Emits a fixed text value configured on the node (no input pins).

## Inputs

| Pin | Description |
|-----|-------------|
| *(editor)* **Value** | Editable string literal on the node body |

## Outputs

| Pin | Description |
|-----|-------------|
| **Value** | Constant `String` |

## Usage

Provide labels, column names, or parseable literals. Pair with **Convert** or **String to Float64** when a numeric value is needed downstream.
