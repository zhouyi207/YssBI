# VEC (Cointegration)

Johansen vector error-correction model (Stata `vec`).

Estimates cointegrating relationships among I(1) variables in **Variables**, with optional deterministic terms and lag structure.

## Output

**Result** + VEC summary window (eigenvalues, $\alpha$/$\beta$, VECLMAR, stability).

Run **VECRANK (Johansen)** first to choose cointegrating rank.
