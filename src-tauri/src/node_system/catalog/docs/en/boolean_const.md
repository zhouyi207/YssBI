# Boolean Constant

Emits a fixed `Boolean` value configured on the node (no input pins).

## Inputs

| Pin | Description |
|-----|-------------|
| *(editor)* **Value** | Editable `true` / `false` on the node body |

## Outputs

| Pin | Description |
|-----|-------------|
| **Value** | Constant `Boolean` |

## Usage

Supply flags to **Branch**, **And**/**Or**, or **Set Variable**. Change the literal in the node UI without rewiring.
