# Set Variable（写入变量）

当 exec 到达此节点时，将值写入项目**变量**。

## 输入

| Pin | 说明 |
|-----|------|
| **In**（exec） | 执行触发 |
| **Value** | 待写入的数据（`Any`） |
| *（检查器）* **Variable** | 目标变量选择器 |

## 输出

| Pin | 说明 |
|-----|------|
| **Out**（exec） | 写入后继续执行 |
| **Value** | 已写入值的透传输出 |

## 用法

选择变量，将上游数据连到 **Value**，在 exec 链上放置 **In**/**Out**。下游可直接使用 **Value** 输出，无需再 **Get Variable**。
