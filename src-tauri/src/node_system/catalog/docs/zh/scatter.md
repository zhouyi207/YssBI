# Scatter

由 **X** 与 **Y** `DataSeries` 绘制散点图；逐行配对，跳过含 null 的点。

**X** 可为数值或 **Date**；**Y** 须为可转为数值的类型。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | 执行输入 | 控制流入口 |
| **X** | 输入 | `Float64` / `Int64` / `Date` `DataSeries` |
| **Y** | 输入 | 数值 `DataSeries` |
| **Out** | 执行输出 | 控制流出口 |

## 用法

执行后打开 **Plot** 窗口；**Date** 轴按日期格式渲染。须至少一对有效 $(x,y)$。
