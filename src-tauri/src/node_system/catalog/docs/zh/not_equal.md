# Not Equal（!=）

判断两值是否不等：

$$
\text{Result} = (A \neq B)
$$

比较两个标量 `Float64`。输出为单个 `Boolean`。

## 输入

| Pin | 说明 |
|-----|------|
| **A**（可选） | 第一个 `Float64` 操作数 |
| **B**（可选） | 第二个 `Float64` 操作数 |

## 输出

| Pin | 说明 |
|-----|------|
| **Result** | **A** 与 **B** 不等时为 `true` |

## 用法

在控制流中表示“不相等”。与 **Branch** 配合可在值不同时分支。
