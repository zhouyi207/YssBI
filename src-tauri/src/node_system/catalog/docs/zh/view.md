# View

为所连数值打开数据检视子窗口。支持 **DataFrame**、**DataSeries** 及标量类型。只读：检视不会修改项目数据。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | Exec 输入 | 执行到此节点时打开检视窗口 |
| **Data** | 输入（可选） | 待展示的值（`DataFrame`、`DataSeries` 或标量） |
| **Out** | Exec 输出 | 检视源注册完成后触发 |

## 用法

将 **Data** 接到需要查看的流水线输出，并把 **View** 放在 exec 路径上以便在合适时机运行。大表与大序列通过分页 typed API 加载。检视完成后经 **Out** 继续后续执行。
