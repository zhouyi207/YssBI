# Correlation Plot

由一个或多个数值 **DataSeries** 计算 Pearson 相关矩阵与双侧 p 值，绘制热力图。

节点 **+** 可添加更多序列；须至少连接 2 条 **DataSeries**。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | 执行输入 | 控制流入口 |
| **DataSeries** | 输入 | 可重复的数值序列 pin（≥2） |
| **Out** | 执行输出 | 控制流出口 |

## 用法

执行后打开 **Plot** 窗口显示相关热力图。各行按位置配对，成对 null 行剔除；标签默认取序列名。
