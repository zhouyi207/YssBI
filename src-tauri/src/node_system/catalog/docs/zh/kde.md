# KDE

对数值 **Values** 做核密度估计（高斯核、Silverman 带宽 $h = 1.06\,\sigma\, n^{-1/5}$），在 256 点网格上评估密度曲线。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | 执行输入 | 控制流入口 |
| **Values** | 输入 | `Float64` 或 `Int64` `DataSeries` |
| **Out** | 执行输出 | 控制流出口 |

## 用法

执行后打开 **Plot** 窗口显示 KDE 曲线。须至少 2 个有效数值；带宽在样本方差为零时回退为 1.0。
