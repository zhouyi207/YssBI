# Int64 Constant

Emits a fixed 64-bit integer configured on the node (no input pins).

## Inputs

| Pin | Description |
|-----|-------------|
| *(editor)* **Value** | Editable integer literal on the node body |

## Outputs

| Pin | Description |
|-----|-------------|
| **Value** | Constant `Int64` |

## Usage

Provide counts, IDs, or offsets to math and control nodes. Edit the number inline in the graph.
