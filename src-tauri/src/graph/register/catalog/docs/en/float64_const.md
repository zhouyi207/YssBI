# Float64 Constant

Emits a fixed 64-bit floating-point value configured on the node (no input pins).

## Inputs

| Pin | Description |
|-----|-------------|
| *(editor)* **Value** | Editable decimal literal on the node body |

## Outputs

| Pin | Description |
|-----|-------------|
| **Value** | Constant `Float64` |

## Usage

Supply coefficients, thresholds, or seeds to math nodes. Use with **Multiply** / **Add** for quick scaling without a **Get Variable**.
