# Not (!)

Logical negation:

$$
\text{Result} = \lnot A
$$

| $A$ | Result |
|-----|--------|
| false | true |
| true | false |

## Inputs

| Pin | Description |
|-----|-------------|
| **A** (optional) | Input `Boolean` to invert |

## Outputs

| Pin | Description |
|-----|-------------|
| **Result** | Opposite truth value of **A** |

## Usage

Invert a condition for **Branch** (take **False** when predicate holds) or flip flags before storage.
