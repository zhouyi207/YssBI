# Categorical to String

Casts `DataSeries<Categorical>` (or Enum) to `DataSeries<String>` — category labels as text.

## Inputs

| Pin | Description |
|-----|-------------|
| **DataSeries** | Input `DataSeries<Categorical>` or Enum |

## Outputs

| Pin | Description |
|-----|-------------|
| **DataSeries** | Human-readable category labels |

## Usage

Display factor levels or parse labels with **String to Float64** / **String to Int64**. Requires categorical/enum dtype on input.
