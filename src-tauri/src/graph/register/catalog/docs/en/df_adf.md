# DF & ADF

Augmented Dickey–Fuller unit root test (Stata `dfuller`).

Tests $H_0$: unit root in **Y** against stationarity.

## Optional pins

| Pin | Default |
|-----|---------|
| **Lags** | 0 |
| **Constant** | true |
| **Trend** | false |

## Output

**Result** + summary report with test statistic and critical values.
