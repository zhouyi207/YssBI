# Negative Binomial

负二项分布 $\mathrm{NB}(r,p)$ 表示达到第 $r$ 次成功之前所需的失败次数：

$$
P(X=k)=\binom{k+r-1}{k}(1-p)^k p^r,\quad k=0,1,2,\ldots
$$

## Pin

| Pin | 说明 |
|-----|------|
| **R** | 目标成功次数 $r > 0$ |
| **P** | 单次成功概率 $p$ |
| **N** | 样本量 |

## 用法

设置 **R**、**P** 与 **N** 后执行图。**Samples** 输出非负整数的 `DataSeries<Int64>`。适用于过度离散计数数据、多次成功前的等待失败次数等建模。
