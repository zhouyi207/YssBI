# Call Function（调用函数）

调用绑定到此节点的**函数子图**。引脚由**目标函数签名投影**而来（在函数 Detail 面板编辑）：签名中的每一项在此节点上对应一个引脚——**data** 引脚传递类型化数值，**exec** 引脚参与控制流。

## Exec 与纯数据

此节点是否带有 exec 引脚由**函数签名**决定，没有单独的开关：

| 签名 | Call 上的 exec 引脚 | 运行方式 |
|------|---------------------|----------|
| 含 **exec** 入参 | 对应的 exec 入/出引脚（默认名 **In** / **Out**） | 由 exec 入参触发；子图结束后触发 exec 出参。 |
| **仅 data**（签名无 exec） | *无* | 当下游拉取某个 data 输出引脚时按需求值。 |

## 输入

| Pin | 说明 |
|-----|------|
| *(exec)* | 函数签名中每个 **exec** 入参一个引脚（默认：**In**） |
| *(data)* | 每个 data 函数输入一个引脚，传给子图 **Function Entry** |

## 输出

| Pin | 说明 |
|-----|------|
| *(exec)* | 签名中每个 **exec** 出参一个引脚（默认：**Out**） |
| *(data)* | 每个 data 函数输出一个引脚，从 **Function Return** 读取 |

## 用法

从侧栏拖拽函数（或经 palette 选择）创建绑定该函数的 Call 节点。将上游值连到 data 输入；从 data 输出读取结果。

- 签名含 exec 时，将上游控制流连到 exec 入参，exec 出参连到后续步骤。
- 仅 data 的函数只需把输出连到消费者——结果被拉取时自动运行。

支持递归，有固定嵌套深度保护；超过上限会以错误中止。
