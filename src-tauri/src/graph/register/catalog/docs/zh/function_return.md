# Function Return（函数返回）

系统托管的**壳节点**，标记 **Function** 图的终点并收集其**输出**。随每个函数图自动创建，**不可删除、复制或从 palette 添加**——只能移动并连接引脚。

## 引脚

所有引脚均为**函数签名的投影**（在函数 Detail 面板 → *Outputs* / exec 区编辑），并非节点固定：

| Pin | 方向 | 说明 |
|-----|------|------|
| *(exec)* | Exec 输入 | 签名中每个 **exec** 出参一个引脚（默认 **Out** 在返回侧表现为汇合点，如 **In**） |
| *(data)* | 输入 | 每个 data 函数输出一个引脚；在此写入要返回的值 |

签名**无 exec** 时不投影 exec 入参——返回值从这些 data 输入按依赖拉取。

## 用法

为每个 data 输入写入返回值。签名含 exec 时，将函数体最后一步控制流连到 exec 输入。子图运行后，调用方 **Call Function** 节点会把 data 值读回自身输出引脚。可在 Detail 面板增删、改名、改类型、重排签名项；引脚会自动更新，并尽量保留已有连接。
