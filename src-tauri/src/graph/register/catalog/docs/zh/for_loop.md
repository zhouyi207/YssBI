# For Loop

按固定次数重复执行 **Body** 分支。每次迭代在 **Index** 输出当前序号（从 0 起）。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | Exec 输入 | 启动循环；每轮 **Body** 结束后接回此处 |
| **Count** | 输入（可选） | `Int64` 迭代次数；默认 1 |
| **Index** | 输出 | 当前迭代序号（`0` … `Count - 1`） |
| **Body** | Exec 输出 | 尚有剩余次数时执行 |
| **Completed** | Exec 输出 | 全部迭代结束后执行一次 |

## 连线

将 **Body** 链末端接回 **In**（可用 **Do** 透传）。每轮 **Body** 完成后重新进入本节点，递增 **Index**，直至达到 **Count**。

## 示例

`Count = 3` → **Index** 依次为 `0`、`1`、`2`，随后 **Completed** 触发一次。
