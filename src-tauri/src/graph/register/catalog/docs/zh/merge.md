# Merge

将多路执行分支汇合为一路。**任一** **In** pin 触发后，从 **Out** 继续。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** *n* | Exec 输入（可增删） | 任一分支入口；默认 2 个，可按需增加 |
| **Out** | Exec 输出 | 某路 **In** 触发后执行一次 |

## 用法

将 **Branch** 的 **True** / **False** 分别接到不同 **In**，**Out** 接共享下游。仅实际执行过的分支会触发 **Merge**；每次分支完成 **Out** 触发一次。
