# Sleep

在继续执行前等待一段时间。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | Exec 输入 | 开始等待 |
| **Duration** | 输入（可选） | 秒，`Float64`；未连接时默认 1.0 |
| **Out** | Exec 输出 | 等待结束后触发 |

## 限制

单次等待时长限制在 **0–60** 秒。

## 用法

在 **Sequence** 步骤之间插入 **Sleep**，用于分阶段运行、演示或降低日志频率。**Duration** 可接 **Float64** 常量或计算结果。
