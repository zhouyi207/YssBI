# Function Entry（函数入口）

系统托管的**壳节点**，标记 **Function** 图的起点并暴露其**输入**。随每个函数图自动创建，**不可删除、复制或从 palette 添加**——只能移动并连接引脚。

## 引脚

所有引脚均为**函数签名的投影**（在函数 Detail 面板 → *Inputs* / exec 区编辑），并非节点固定：

| Pin | 方向 | 说明 |
|-----|------|------|
| *(exec)* | Exec 输出 | 签名中每个 **exec** 项一个引脚（默认 **In** 在入口侧表现为控制流起点，如 **Then**） |
| *(data)* | 输出 | 每个 data 函数输入一个引脚；在此读取调用方传入的实参 |

签名**无 exec** 时不投影 exec 出参——函数完全按数据依赖求值。

## 用法

将各 data 输出连入函数体。签名含 exec 时，将 exec 输出连到第一个控制流步骤。可在 Detail 面板增删、改名、改类型、重排签名项；此处引脚（以及所有指向该函数的 **Call Function** 节点）会自动更新，并尽量保留已有连接。
