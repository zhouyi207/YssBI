# Sequence

按固定顺序执行多条 exec 分支。**In** 触发后，**Then 0**、**Then 1**、**Then 2** … 依次执行——前一步所连下游链完成后，再启动下一步。

## Pin

| Pin | 方向 | 说明 |
|-----|------|------|
| **In** | Exec 输入 | 启动顺序执行 |
| **Then** *n* | Exec 输出（可增删） | 第 *n* 步 exec pin；默认三步，可按需增加 |
| **Out** | — | *（无 — 仅使用各 Then 输出）* |

## 用法

将 **In** 接到 **Event Begin** 或 **Branch** 某一路径。按所需顺序把副作用节点（如 **Print**、**View**、带 exec pin 的数据节点）接到各 **Then** 步。各步串行而非并行，适合分阶段日志、检视或有序初始化/清理。
