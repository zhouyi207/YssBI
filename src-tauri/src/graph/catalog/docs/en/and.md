# And (&&)

Logical conjunction on two booleans:

$$
\text{Result} = A \land B
$$

| $A$ | $B$ | Result |
|-----|-----|--------|
| false | false | false |
| false | true | false |
| true | false | false |
| true | true | true |

## Usage

Combine multiple conditions before **Branch** or **Set Variable**. Chain comparisons with **Equal** into **A** and **B**.
