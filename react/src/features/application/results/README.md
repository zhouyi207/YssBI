## Results

### 查询与身份

- 参考 `resultProjection` 持有查询缓存，`runtime` 协调请求与失效，Execution 投影保留运行及逐输出事实；展示不另建可写运行模型。
- 当前 Pin 绑定必须匹配图语义、执行会话、有效输出和 ResultId。新图投影立即隐藏失效绑定，不等待缓存清理。
- 显式打开的报告绑定完整结果引用，并保留该不可变快照。图编辑、重跑和当前输出失效不自动把旧报告改绑到新结果。
- 结果身份和精确整数保留无损文本，不转成 JavaScript number。迟到回复按项目、会话、结果及查询代次拒绝。
- 分页缓存按结果、part、offset、limit 隔离；同一不可变查询共享在途请求，不同消费者页码相互独立。
- 未知总数不当作零；依据 `hasMore` 继续分页。空结果仍显示声明的列，不能根据第一行猜测 schema、补列或过滤坏行。

### 生命周期

- 查询、当前输出绑定和消费者持有关系是三个边界。最后一个 payload consumer 释放后清理对应缓存，旧会话的释放句柄不能删除新会话数据。
- 面板移动、隐藏或 React 重新挂载不等于逻辑关闭。取得结果持有关系后若项目或目标已失效，释放本次持有关系，不发布给后继。
- 运行只使其实际重算的输出失效；报告保留的旧结果不能因此恢复为当前输出。失败或取消也不能伪装为当前成功结果。
- “查看上次成功结果”按摘要中的旧结果引用打开，不执行节点，也不改变当前 Pin 绑定。
- 项目结束、图卸载和结果失效的清理遵循各自 owner；清除运行失败摘要不清除 Results。

### 数据与报告

- 表格与数列使用有界页面，宽整数、空值、布尔值和嵌套单元格保持含义；第一页不能冒充完整绘图数据。
- 统计数值、抽样、置信带及报告展示投影由 Rust 提供，React 只格式化和呈现，不重新估计模型或用零填补缺失指标。
- 报告数组以数据引用表示，用户展开后读取分页；概览、图形和已计算分析沿同一结果身份读取，不建立另一份报告存储。
- Summary 的内容选择属于节点参数。显式补选先提交参数并执行，成功取得新结果后替换原报告；失败或迟到结果保留旧快照。
- 读取边界校验身份和结构，视图不在重绘时重新解析相同数据。无效报告显示失败，不静默丢弃坏行。
