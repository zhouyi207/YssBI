# v0.3 roadmap

> Status: Planned
> Scope: v0.3 release line 的完成记录、开放产品与统计能力候选、剩余验收
> Canonical owners: 本文件拥有计划进度与完成摘要；当前行为由源码、测试和架构文档维护

已完成条目只记录明确范围的 Rust 实施摘要，不代表本次重新执行了业务测试或全部桌面验收。当前原生入口为 GPUI，历史界面结果不自动成为原生完成证据；当前契约由对应 Rust owner 与[宿主 README](../../crates/yss-desktop-gpui/README.md)维护。未完成验收继续单列，详细历史由 Git 保留。

## 已完成

- [x] 数据引擎切换为 DataFusion / Arrow，数据集使用 SQLite 目录与 Parquet 不可变代；移除宿主 DuckDB / Polars，Julia 插件使用 DataFusion / Arrow。当前边界见 [Dataset store](../../crates/yss-database-store/README.md) 与 [Database runtime](../../crates/yss-database-runtime/README.md)。
- [x] Graph 当前文档、可逆历史与保存身份统一由 Rust Project 管理，GPUI 使用只读投影与未提交控件输入；GUI 编辑、显式保存与执行各自保留边界，Harness 批次复用 Application 并原子保存。[motion 整体计划](motion.md)仍需完成原生交付与验收。当前契约见 [Graph 与 Execution](../../crates/yss-application/src/graph/README.md)。
- [x] 接入语义快照复用、Schema 增量缓存、编辑批次解析和投影索引，位置等展示修改不触发完整语义重算。局部测量方法与范围见[基准资料](../benchmark/README.md)。
- [x] 删除无生产者的 Graph stdout/stderr 专用链路、执行录制与旧动画队列；图状态使用解析、实际运行和结果缓存事实，保留报告租约。组件重构的阶段及剩余验收见[原计划](COMPONENT_REFACTOR.md)。
- [x] 运行值中的列表、记录与线性回归结果改为不可变共享载体，内存表经统一关系入口参与筛选、投影、统计与结果分页；统计物化接入分配前预算、形状、取消和超时检查。预算仍不是进程内存硬上限，矩阵分解中途取消仍待设计。见 [Node Kernel](../../crates/yss-node-kernel/README.md)。
- [x] 节点内核声明并校验输入顺序、数量、参数和输出载体；注册语义指纹与展示文本分离。见 [Node Kernel 注册契约](../../crates/yss-node-kernel/README.md#注册与扩展)。
- [x] 受控打开/定位意图具有认领和完成回执；原生动作由工作台执行，根 DockArea 保留唯一布局权威。剩余人工验收由 [motion](motion.md) 跟踪，契约见 [UI Contract](../../crates/yss-ui-contract/README.md)。
- [x] 修正精确模式下的 Equal / NotEqual，整数与浮点混合比较避免先将宽整数转为浮点；删除未影响算法的全局近似比较设置。显式近似比较参数与算法判秩、收敛阈值仍由各自契约管理。
- [x] 修复 WLS / GLS / Prais 的变换空间总平方和、OLS / WLS 整体检验和 GLS 估计尺度契约；分解失败、秩不足、未知协方差选项和 Prais 未收敛明确报错。具体边界见 [SCI](../../crates/yss-sci/README.md) 与 [Linalg](../../crates/yss-sci-linalg/README.md)。
- [x] 保存进入同图编辑队列后读取版本，连续参数修改在队列执行时合并当前文档；关闭与丢弃使用后端确认的版本，投影安装拒绝迟到旧修订。桌面竞争场景仍在下方验收。
- [x] 函数重命名统一改写已加载和未加载调用图中的类型化引用、动态端口与可逆历史，保留普通文本和未提交编辑。见 [Project runtime](../../crates/yss-project/README.md)。
- [x] 原生设置窗口复用同一设置实体和未提交草稿，模型保存、发现、默认模型与目录失效交付调用原 Rust 服务；实际并发、关闭/重开和远端服务仍保留人工验收。
- [x] 日志由中立 `yss-logging` 采集、持久化和订阅交付，Rust 生产者使用 tracing；原生宿主呈现 Logs，保留日志与 Graph Problems、运行失败和 Results 的区别。见 [Logging](../../crates/yss-logging/README.md)。
- [x] 文档入口整理为原生 Cargo workspace 与 Rust owner，压缩过时实现日志并保留开放验收；[motion](motion.md)、[GPUI 迁移](GPUI_MIGRATION.md)与 [Harness](STATISTICAL_HARNESS.md)不因文档清理而完成。
- [x] 清理独立草稿传输实验，以及引用已删除 `olsReportSpec` / `parseOls` 的报告对比脚本、旧样本、命令入口和仅用于样本导出的忽略测试；保留当前报告契约测试。
