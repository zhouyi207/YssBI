# v0.3 roadmap

> Status: Planned
> Scope: v0.3 release line 的完成记录、开放产品与统计能力候选、剩余验收
> Canonical owners: 本文件拥有计划进度与完成摘要；当前行为由源码、测试和架构文档维护
> Update when: 条目完成、取消、重写或迁入后续 release line 时

已完成条目从旧分析和实施记录中提取，并按当前源码与维护中文档核对。`- [x]` 只表示条目所述实现或清理已经完成，不代表本次重新执行了业务测试或全部桌面验收。未完成验收继续单列，详细历史由 Git 保留。

## 已完成

- [x] 数据引擎切换为 DataFusion / Arrow，数据集使用 SQLite 目录与 Parquet 不可变代；移除宿主 DuckDB / Polars，Julia 插件使用 DataFusion / Arrow。当前边界见 [Dataset store](../../src-tauri/crates/yss-database-store/README.md) 与 [Database runtime](../../src-tauri/crates/yss-database-runtime/README.md)。
- [x] Graph 当前文档、可逆历史与保存身份统一由 Rust Project 管理，React 使用只读投影；GUI 编辑、显式保存与执行各自保留边界，Harness 批次复用 Application 并原子保存。该项只覆盖当前 Graph 链路，[motion 整体计划](motion.md)仍未完成。当前契约见 [Graph 与 Execution](../architecture/GRAPH_AND_EXECUTION.md)。
- [x] 接入语义快照复用、Schema 增量缓存、编辑批次解析和投影索引，位置等展示修改不触发完整语义重算。局部测量方法与范围见[基准资料](../benchmark/README.md)。
- [x] 删除无生产者的 Graph stdout/stderr 专用链路、执行录制与旧动画队列；图状态使用解析、实际运行和结果缓存事实，保留报告租约。组件重构的阶段及剩余验收见[原计划](COMPONENT_REFACTOR.md)。
- [x] 运行值中的列表、记录与线性回归结果改为不可变共享载体，内存表经统一关系入口参与筛选、投影、统计与结果分页；统计物化接入分配前预算、形状、取消和超时检查。预算仍不是进程内存硬上限，矩阵分解中途取消仍待设计。见 [Node Kernel](../../src-tauri/crates/yss-node-kernel/README.md)。
- [x] 节点内核声明并校验输入顺序、数量、参数和输出载体；注册语义指纹与展示文本分离。见 [Node Kernel 注册契约](../../src-tauri/crates/yss-node-kernel/README.md#注册与扩展)。
- [x] 线性回归报告已有固定章节的顺序、显示状态与 JSON 导入导出，布局绑定当前结果，数值继续来自 ResultStore。该项只表示报告配置已接入，[JSON Driver 页面方案](jsonDriver.md)仍未完成。见[报告契约](../architecture/GRAPH_AND_EXECUTION.md#线性回归语义报告布局)。
- [x] 修正精确模式下的 Equal / NotEqual，整数与浮点混合比较避免先将宽整数转为浮点；删除未影响算法的全局近似比较设置。显式近似比较参数与算法判秩、收敛阈值仍由各自契约管理。
- [x] 修复 WLS / GLS / Prais 的变换空间总平方和、OLS / WLS 整体检验和 GLS 估计尺度契约；分解失败、秩不足、未知协方差选项和 Prais 未收敛明确报错。具体边界见 [SCI](../../src-tauri/crates/yss-sci/README.md) 与 [Linalg](../../src-tauri/crates/yss-sci-linalg/README.md)。
- [x] 保存进入同图编辑队列后读取版本，连续参数修改在队列执行时合并当前文档；关闭与丢弃使用后端确认的版本，投影安装拒绝迟到旧修订。桌面竞争场景仍在下方验收。
- [x] 函数重命名统一改写已加载和未加载调用图中的类型化引用、动态端口与可逆历史，保留普通文本和未提交编辑。见 [Project runtime](../../src-tauri/crates/yss-project/README.md)。
- [x] Settings 跨窗口使用字段补丁，保留本地待提交字段；读取、事件和更新共用类型校验。双窗口并发行为仍保留人工验收。
- [x] 日志默认采集 INFO / WARN / ERROR，捕获阶段限制字段与格式化字节，后台统一整理和脱敏；保留 SQLite 提交后交付的顺序。见 [Runtime Signals](../architecture/RUNTIME_SIGNALS.md)。
- [x] 清理已被正式契约承接的旧分析、历史审查、旧版本记录及混合 TODO 快照；保留规则、重构计划和仍适用的资料。JSON Driver 与 motion 的完整目标尚未完成，另以专项计划保留。
