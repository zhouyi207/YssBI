## 已确认的产品约定

1. 参数与可变 Pin 数量可在未连接时配置，也可随创建一次提交；例如回归的 Y × 1、X × N。
2. 连接存在不代表 Schema 已知。未知、Deferred、已知零列、冲突和资源不可用分别表达。
3. 已知列可提前提供候选，端口值和预览仍来自实际执行；待验证不等于参数非法或已经 Ready。
4. 连接、断开、更换输入和控件切换不清空原值、不选第一项、不把旧候选当当前事实。
5. 手动分析支持算一步看一步；AI 可批量建图与执行后检查，但查看/配置不隐式运行。
6. 显式保留的执行边界形成稳定结果；批量内部不要求每个节点都完整物化。
7. 图表达数据依赖，控制流和副作用归 Workflow。不引入 Python 单元、全局变量环境或平行图草稿。

## 核心数据流与依赖关系

```text
Protocol / 冻结 Registry → 创建前定义 → GPUI 表单 / Harness 定向查询
GPUI 命令 / Harness 领域工具 → Application 捕获图与资源身份
  → Editor 合并参数与端口、构造完整候选 → Analysis 解析
  → Project 原子提交文档与历史 → 类型化投影 / 业务回执
输入变化 → 同一 Analysis 重新解析 → 更新候选与诊断，保留文档参数
显式运行 → 捕获范围和输入版本 → Execution 准备/执行
  → ResultStore 发布稳定结果 → 有版本 Schema 观测 → 原语义解析入口
```

阻塞查询与提交在宿主 worker 完成；UI 只接纳仍匹配项目、图、控件与请求生命周期的回执。
GUI 编辑、Save 与 Execute 独立；Harness 批次遵守其原子保存边界。

## 参数配置契约

列名保持字符串，列列表保持有序数组，筛选保持结构化谓词和显式字面量类型；遵循
`TabularColumnName`，保留有意义空格，不用逗号拼接代替数组。基础输入与候选选择提交同一形式。

| 输入上下文 | 编辑及语义要求 |
| --- | --- |
| 未连接 / Schema 待定或 Deferred | 基础文本、列表和筛选输入；校验自身格式，列存在性待验证 |
| Schema 已知 | 选择候选并校验列语义、操作符及字面量适用性 |
| 已知零列 | 明确没有候选，保留原值和诊断，不退回未知 |
| 冲突或资源不可用 | 保留真实错误并允许修正，不降级成普通未知 |
| 断开或更换输入 | 保留已填值，按新上下文重验；失效值单独可见、可修正 |

多输入参数各自读取声明来源。未知参数、错误类型、非法枚举或固有范围、表达式/谓词格式错误在
提交边界拒绝；缺必填项或未接输入可作为未完成编辑保留，执行范围必须满足真实就绪条件。
条件切换沿用 `Parameters::merge_values` 清理不适用字段，连接变化不能借此清空列引用。

## 携带参数创建与 AI 契约

`CreateNode` 使用 `parameters` 与 `portCounts`。快速创建提交空映射；显式值参与首次参数、端口、
类型和连接检查；未填默认值仍归协议，null 沿用清除显式值的含义。资源绑定参数不能被用户覆盖。
managed 节点保持专用操作边界。一次创建连同可选连接是一个候选补丁及一个撤销单位。

`portCounts` 按查询返回的模板 key 指定初始总数，不是追加次数：

- 固定 Pin 不允许覆盖；用户可变数量必须是协议范围内整数，零只在协议允许时使用。
- 成员组共同扩展，矛盾数量整体拒绝；列或函数签名派生 Pin 不接受数量字段伪造。
- 端口、参数、连接、资源版本任一失败不留半个节点或历史项；回执提供真实稳定地址。
- 批内模板/顺序引用仅用于创建阶段，不作为持久连线身份；不能从显示名猜模板 key。

模型使用当前 `browse_nodes` / `inspect_node_type` / `create_nodes` 等领域工具；内部批量事务、
`clientId` 别名和幂等回执继续复用，不保留通用模型建图入口。公开工具见
[领域工具计划](HARNESS_TOOL_ARCHITECTURE.md)和[Harness Core](../../crates/yss-harness-core/README.md)。
目录搜索有界，定义按需读取；同步版本由 Rust 内部绑定，不要求模型填写。
创建成功不等于可执行。原生创建表单取消不提交、失败保留输入、目标过期不得创建到新图。

## 分阶段实施

| 阶段 | 已完成的 Rust/原功能范围 | GPUI 验收责任 |
| --- | --- | --- |
| P1 参数声明与编辑期验证 | 固有校验与缺必填区分；未知/空/冲突 Schema；定义与语义投影同源 | 无连接编辑、条件字段、无效现存值与诊断 |
| P2 创建操作与事务 | 初始参数与 Pin 数量同批；绑定参数保护；回滚、别名及一次撤销 | 快速/配置创建、失败修正与切换目标 |
| P3 表单与上下文增强 | 原界面的基础/增强表单与创建前配置获用户确认 | 原生完整表单、物理输入/IME、复合字段与生命周期仍开放 |
| P4 AI 查询与完整建图 | 定义读取、多 X Pin 批次、参数/连接/诊断一致与真实 AI 建图确认 | 工具卡、实际产物与原生打开结果另验收 |
| P5 局部执行与稳定结果 | 当前输入、补算依赖、全图范围；稳定结果、Schema 观测、Deferred 连续阶段 | 原生菜单、取消、旧结果及跨会话重跑 |
| P6 通用 DataFrame 图函数 | 未绑定定义、实参 Schema 特化、调用隔离与内部错误位置 | 函数配置、调用反馈与错误导航 |
| P7 分组对象与按组函数 | GroupBy / Aggregate / Apply / Transform、行对齐与错误组 | 分次运行、组合分页、失败定位 |

### P5 局部执行与稳定结果

运行本节点消费当前有效输入；运行至此补算必要依赖；全部运行按当前图依赖执行。
缺失/过时输入返回可定位原因，不能静默使用旧值，无关未完成分支不阻断目标范围。
显式旧结果使用完整身份和租约，与当前结果执行分开。失败/取消不生成成功值，仍存活历史值保持原身份。

运行观测只把带结果身份的实际 Schema 交回 Analysis，不改共享函数定义、图文档或保存展示元数据。
消失列保留引用并提示修复；新会话无结果时不能伪造已知值。遇 Deferred 边界先求值必要阶段，再按
实际结构继续；同一 RunId、取消和资源授权贯穿各阶段，后续失败仍保留已完成边界及真实失败终态。

### P6 通用 DataFrame 图函数

函数定义有效、实参未绑定和本次调用可执行分别判断，不必在定义时放入真实表。
列约束延后到调用绑定，缺列保留函数和内部节点位置。每次调用独立参数/中间结果并按输入特化；
Execution 编排，Kernel 保持图无关，函数依赖参与结果失效、预算与取消，现有递归限制不放宽。

### P7 分组对象与按组函数

| 项目 | 保持的契约 |
| --- | --- |
| 分组与顺序 | GroupBy 持有源关系及键，不为每组复制整表；键确定排序，Null 作为普通组，组内保留源行顺序 |
| 固定聚合 | Aggregate 继续使用原查询计划，不强制改为函数调用 |
| 函数输入 | Apply/Transform 使用接受并返回 DataFrame 的图函数，组内表含分组键 |
| Apply | 可改变行数；前置带可配置 `group.` 前缀的来源键，名称冲突报错 |
| 输出一致性 | 核对每组列顺序、名称、物理类型及语义，失败带组编号和函数位置，不取第一组猜全部 |
| Transform | 必须保留组内行身份与顺序；行数相同不足以证明对齐，组合后恢复源顺序，返回函数生成列 |
| 空输入 | 以空表调用一次纯函数取得结构，返回零行；函数不能处理则明确失败 |
| 资源控制 | 顺序组调用、复用帧与控制、临时 Arrow 分批存储；失败/取消回收未发布文件，不无限展开并行 |

## 首批人工验收场景

以下是 2026-10-04 已确认的原功能场景，保留为原生验收基准，不把其历史通过转换成新宿主勾选：

1. 未连接聚合节点填写 keys/mean，保存待输入状态；直接创建首次即含这些显式值。
2. 创建回归 X × 4、Y × 1，一次提交/撤销；越界、固定/派生端口或成员组矛盾整体拒绝并保留表单。
3. AI 单批创建多个 X Pin 并连接，临时引用解析为真实 ID；重试不重复，撤销一次撤回整批。
4. 接入 industry/sales 后增强候选；换成缺 sales 的表保留原值及定位诊断，不自动换列。
5. Deferred 与零列区别可见；断开重连和类型变化保留意图；筛选谓词保留原结构/字面量类型。
6. 多输入节点左右候选隔离；非法参数或资源绑定冲突不留部分节点、连接或历史。
7. 创建取消、失败修正、切换目标图均保持正确身份；保存重开、撤销重做重新解析，不恢复伪结果。
