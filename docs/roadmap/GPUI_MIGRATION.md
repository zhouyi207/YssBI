## 当前架构与实施边界

根 Cargo workspace 的成员为 `crates/*`，默认入口为 `crates/yss-desktop-gpui`。
宿主通过 `ApplicationServices::initialize` 组装平台中立服务，直接调用类型化 Application 用例。
后续阻塞业务在 worker 执行；UI 接纳带原身份的投影、事件与回执，不通过字符串命令或 JSON 往返。

Project 拥有当前图文档、历史和保存身份；Graph 拥有语义；Execution 拥有计划、运行和结果；
Harness 拥有对话与工具账本。GPUI 只拥有展示、未提交输入和交互，根 DockArea 唯一拥有布局拓扑。
控件复用 `gpui_kit`；不建立新的基础控件库或平行业务模型。`react/` 保留为不参与原生构建的参考源码，
参考中的能力和人工确认不能直接标记为原生完成，本计划不以删除参考源码代替功能交付。
