  - Execution：按照编译产物执行计算，管理运行和结果。

  因此，DocumentNode、节点位置、连线归图文档；连接后解析出的类型、schema 和血缘仍由 GraphSemanticSnapshot 统一管理。yss-
  graph-type-mapping 可以暂留 Graph，承担数据类型与图类型的转换。
