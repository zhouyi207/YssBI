# Log Text Selection and Worksheet Chart Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make worksheet chart-rendered text non-selectable while making every visible log field selectable without breaking log-row click selection.

**Architecture:** Apply Tailwind selection utilities only at the owning presentation boundaries. `WorksheetChartPreview` owns a chart-only `select-none` wrapper, `LogItemRow` owns selectable row text plus browser-selection-aware click suppression, and `LogDetailPanel` locally overrides the Detail sidebar's inherited `select-none` without changing shared Detail components.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, Vitest, happy-dom, D3-backed existing plot components.

## Global Constraints

- Do not add global CSS selectors for worksheet or log selection behavior.
- Do not add Clipboard API calls, Tauri clipboard commands, copy buttons, context-menu actions, shortcuts, or toast messages.
- Do not change log payloads, persistence, filtering, virtualization, or application selection state.
- Do not disable pointer events or alter worksheet chart tooltip, zoom, pan, hover, or rendering behavior.
- Worksheet error messages, loading state, and empty-state text remain outside the chart `select-none` boundary.
- All visible log fields are selectable: timestamp, level, type, source, and message.
- A non-collapsed browser selection anchored or focused inside a log row suppresses only the click generated by that pointer gesture.
- Ordinary pointer clicks and keyboard-generated button clicks continue to select the log.
- Keep the override local to `LogDetailPanel`; other Detail panels retain existing behavior.
- Run all commands from the repository root through `pnpm` scripts.
- Preserve all unrelated dirty-tree changes.
- Do not commit, stage, branch, create a worktree, tag, merge, push, or modify `TODO.md`.

- [ ] **Step 3: Implement browser-selection-aware row clicks**

Import `useRef` and add:

```tsx
const rowRef = useRef<HTMLButtonElement>(null);
const suppressNextClickRef = useRef(false);

const handlePointerDown = () => {
  suppressNextClickRef.current = false;
};

const handlePointerUp = () => {
  const row = rowRef.current;
  const selection = window.getSelection();
  suppressNextClickRef.current = Boolean(
    row
      && selection
      && !selection.isCollapsed
      && (
        (selection.anchorNode && row.contains(selection.anchorNode))
        || (selection.focusNode && row.contains(selection.focusNode))
      ),
  );
};

const handleClick = () => {
  if (suppressNextClickRef.current) {
    suppressNextClickRef.current = false;
    return;
  }
  onClick();
};
```

Wire the button as:

```tsx
<button
  ref={rowRef}
  type="button"
  onPointerDown={handlePointerDown}
  onPointerUp={handlePointerUp}
  onClick={handleClick}
  className={[
    'group flex w-full cursor-text select-text items-center gap-2.5 border-b border-border/30 px-3 py-1.5 text-left transition-colors',
    'border-l-2',
    LEVEL_ACCENT[log.level] ?? 'border-l-border/50',
    isSelected ? 'bg-[var(--accent-color)]/8' : 'hover:bg-muted/30',
  ].join(' ')}
>
```

Do not prevent default pointer behavior, clear the user's selection, or change virtualization APIs.
