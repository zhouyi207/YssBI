is 0.3054/0.3525/0.3553 ms for equal/name-only/nested change, respectively (about
9.1%/10.4%/10.5%). This narrow default Immer adoption preserves the required behavior
without the large cost or reserved-key limitation of the full recursive reference.
It does not prove a universal speed ratio or infer individual operation costs.
The hybrid still uses the same opaque branch helper as manual; it is an executable
comparison of typed-shell copying, NOT a default no-handwritten-recursion reference
for opaque values. Neither its measurements nor the incomplete reference authorize
a rule exception for constants' opaque leaves, parameter values or the remaining
Graph projection recursion. Those narrower boundaries remain explicitly open.
