# Quadrant Plot

Connect aligned, equally sized Numeric X and Y series. X split and Y split default to 0 and accept finite cut points. Missing and nonfinite observations are rejected.

Shows quadrant counts from the complete sample in upper-right, upper-left, lower-left and lower-right order. Points on a boundary go right or up. At most 2048 points are drawn; counts use all observations.

Open the result output in a workbench result panel or a separate Plot window.
