# KANO 模型

每个节点分析一个需求。**functional** 连接“具备该功能时”的回答，
**dysfunctional** 连接“不具备该功能时”的回答；同一行须为同一位受访者。
两列均按整数编码：1 喜欢、2 理应如此、3 无所谓、4 可以忍受、5 不喜欢。
问卷若编码相反，请先重编码。缺失、非有限数值和未对齐的行会报错。

采用经典 KANO 判别表，将配对回答归为魅力型 A、期望型 O、必备型 M、
无差异型 I、反向型 R 或可疑回答 Q。**result** 输出六类频数、百分比和全部并列最多的类别。

满意系数 Better = (A + O)/(A + O + M + I)，
不满意系数 Worse = −(M + O)/(A + O + M + I)。
R、Q 保留在频数报告中，但不进入这两个系数的分母；分母为零时系数为空。

判别表依据 Berger 等（1993）CQM Journal 2(4) 的图 4。
结果不会在并列类别中任意挑选一个，也不直接决定产品开发优先级。
