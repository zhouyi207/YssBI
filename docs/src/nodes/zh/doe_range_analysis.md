# 极差分析（因素水平效应）

连接数值**响应 Y**和对齐的分类**因素 factors**，每个输入一个因素，每行一次试验。
缺失分类、缺失或非有限响应会报错；数字因素编码视为类别，不当作回归斜率。

**levels** 报告每个观测水平的试验次数、响应总和 K 与均值。
**result** 报告各因素原始极差 R（最大水平均值减最小水平均值）及所有最优水平。
**maximize** 默认开启，选均值最大的水平；关闭时选均值最小的水平。
浮点精度内无法区分的均值视为并列。因素、水平序号从 1 开始，分别对应保留原始标签的 `factor_names` 和 `level_labels`。

报告检查各因素水平重复数是否均衡、因素之间水平数是否相同，以及按精确列联计数判断的两两正交性。
只有一个因素时正交性为空。不均衡或非正交数据仍输出描述均值，但因素比较可能受到混杂影响。
输出的是原始极差，不含混合水平的极差偏差校正，也不提供显著性检验。

各因素最优水平组合不一定在已做试验中出现，更不能当作已验证的最优方案；交互作用和确认试验需另行分析。
全部试验行参与计算，不设固定行数上限。
