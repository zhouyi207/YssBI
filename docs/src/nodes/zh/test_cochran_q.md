# Cochran Q 重复比例检验

比较同一批对象在三个及以上条件下的二元成功概率。

## 输入与参数

在 `conditions` 添加 至少三个数值 `0/1` 序列，至少 2 个对象。各列必须等长、按对象对齐，`1` 的含义一致；数据库与内存数列可混合，须等长并按当前位置逐项对应。缺失值与其他编码会被拒绝。无配置参数。

## 假设与统计量

$H_0$：所有条件的边际成功概率相等；$H_1$：至少一个不同。令 $k$ 为条件数，$C_j$ 为条件 $j$ 的成功数，$R_i$ 为对象 $i$ 的成功条件数，$T=\sum_j C_j$：

$$
Q=\frac{(k-1)\left(k\sum_j C_j^2-T^2\right)}
{kT-\sum_i R_i^2}
\overset{H_0}{\approx}\chi^2_{k-1}.
$$

分母须大于零，即对象内需要有条件间变化。不同对象应独立；同一对象的重复测量应保持配对。当前使用渐近卡方近似，小样本需谨慎。

## 输出与判读

`result` 为结构化结果。`statistic` 为 $Q$，`degrees_of_freedom` 为 `[k−1]`，`p_value` 为卡方右尾概率，`sample_sizes` 为各条件的对象数。估计值和标准误为空。

$p<\alpha$ 时拒绝所有条件成功概率相等；不自动确定具体有差异的条件对。
