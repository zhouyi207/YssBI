# Gini 基尼系数

将个体数值列连接到 **Values**。每个观测等权，计算不做小样本修正的经验基尼系数：

$$G=\frac{\sum_{i=1}^{n}\sum_{j=1}^{n}|x_i-x_j|}{2n^2\bar x}.$$

其中 $n$ 为观测数，$\bar x$ 为均值。输入必须非空、有限、非负且均值为正；允许零值，缺失值、负值和全零数据会报错。单个正值的结果为 0。此口径的上界为 $(n-1)/n$，不乘 $n/(n-1)$；值越大表示差异越大。

唯一输出 `result` 包含 `gini`、`mean` 和 `observations`。例如 `[1, 2, 3, 4]` 的 Gini 为 `0.25`。Inspect 可在数值和报告视图之间切换。

输入应是同一尺度上的个体观测。直接用组均值代替个体值会遗漏组内差异；本节点不接收频数或抽样权重，也不计算置信区间。需要组内、组间和重叠分解时，使用 Dagum 节点并提供逐观测的分组标签。

口径参考：[ineq 的 Gini 定义与修正选项](https://stat.ethz.ch/CRAN/web/packages/ineq/refman/ineq.html)。
