# DEMATEL

将直接影响方阵按列连接到 **criteria**。A(i,j) 表示行 i 对列 j 的影响，
行列使用相同指标顺序；数值须非负且有限，对角线为 0。缺失数据会报错。

**influence_normalization** 默认 max_sum：除以最大行和或列和；
none 使用输入尺度。之后显式乘以 **attenuation**，范围 (0,1]，默认 1。
所得 X 的谱半径须在数值上小于 1；不收敛或数值奇异时会报错，
不自动加入衰减来改变问题。

总影响 T = (I − X)⁻¹X，包括直接和全部间接影响。
**result** 报告标准化、衰减及谱半径。
**indices** 输出影响度 D（行和）、被影响度 C（列和）、中心度 D+C、
原因度 D−C 及归一化中心度权重；全部影响为零时权重为空。
**relations** 按来源、目标位置输出每个单元格的 X 与 T，可分页查看。

“原因度”是输入判断网络中的方向指标，不是从观测数据识别出的因果效应。
