# 指数生存回归

连接逐行对齐的 `time` 与 `event` 数列。时间必须有限且严格大于 0，单位保持一致；`event=1`（或 true）表示事件发生，`0`（或 false）表示右删失。缺失值会导致计算失败，不自动删行。假设在给定模型或分组条件下删失独立于事件过程；输入须等长并按当前位置逐项对应，可混合数据库与内存数列。

`X₁, X₂, …` 可以连接零个或多个数值自变量，始终拟合截距。指数分布，$S(t\mid x)=\exp[-t/\exp(\eta)]$，固定 $\sigma=1$。
`survival_horizon=1` 是严格为正的预测时点。`max_iterations=500`，要求正整数；`tolerance=0.0000001`，范围为 1e-12 至 0.01。未收敛或信息矩阵奇异时返回错误。自变量必须有限且模型可识别；分类自变量须预先编码为哑变量。

## 模型与推断

令 $\eta=\beta_0+x^\top\beta$，加速失效时间模型为 $\log T=\eta+\sigma\varepsilon$。最大似然同时考虑事件与删失：
$$\ell=\sum_i\{\delta_i\log f(t_i\mid x_i)+(1-\delta_i)\log S(t_i\mid x_i)\}.$$
除指数分布固定尺度外，尺度与回归系数联合估计。协方差取完整观测信息矩阵的逆，保留系数与尺度之间的关联。对系数 $j$，检验 $H_0:\beta_j=0$ 对 $H_1:\beta_j\ne0$，使用 $z=\widehat\beta_j/SE$、标准正态参考分布及双侧 p 值，95% 区间为 $\widehat\beta_j\pm1.96SE$。

`result` 返回系数、指数化系数 `time_ratios`、协方差、尺度及标准误、对数似然、AIC、BIC、迭代数、样本/事件数、预测时点，以及逐行中位生存时间和事件概率。协方差顺序为原单位回归系数，随后是需要估计时的 log(scale)；指数尺度标准误为空。斜率取指数表示生存时间的倍数，而非危险比；截距取指数为基准时间尺度。Weibull/指数的中位数为 $\exp(\eta)(\log2)^\sigma$，其他两种为 $\exp(\eta)$。

`predictions` 输出按输入原行序排列的 DataFrame，包含 `time`、`event`、`risk`。从该输出选取三个列后连接校准曲线或决策曲线节点，各节点使用相同的 `survival_horizon`。这里预测的是参与拟合的观测，对这些行进行评估属于样本内的表观表现。
至少需要一个事件，设计矩阵须满秩且观测数多于回归系数数目。不含延迟入组、区间删失、脆弱性或加权估计。允许超出观测随访范围进行参数预测，其有效性依赖所选分布。
