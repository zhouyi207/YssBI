# 过程能力分析

连接数值**测量值（measurements）**，设置有限的**规格下限 lower_limit**、
**规格上限 upper_limit**和**目标 target**；上限须大于下限，目标值仅影响 Cpm。
至少需要两行完整有限测量值。

不连接 **subgroups** 时，组内标准差为相邻移动极差均值 / 1.128，因此输入顺序有意义。
连接对齐的子组标识后，改用合并子组样本标准差：
sqrt(各子组离均差平方和之和 / 各子组(n−1)之和)。每组至少两行，允许组大小不同；不进行 c4 偏差校正。

**result** 中 Cp/Cpk 使用组内标准差，Pp/Ppk 使用总体样本标准差。
Cpm 使用总体方差与均值偏离目标的平方和。保留负的 Cpk/Ppk；分母为零时为空，不输出无穷大。
同时报告严格超出规格的实际数量、百分比，以及两种标准差下按正态分布估计的超差 PPM；相应标准差为零时，估计 PPM 为空。

解释正态能力指标时需结合分布适用性和过程稳定性证据。节点不推断工程规格，也不自动判定过程稳定或合格。
使用全部测量值，执行受内存、取消与期限控制。
