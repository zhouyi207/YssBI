# 竞争风险：Aalen–Johansen

连接对齐的 `time` 与 `status` 数列。时间必须有限且为正；状态必须为非负整数，0 表示删失，每个不同的正整数代表一种事件原因。至少须有一次事件。原因代码不必连续，会按升序保留原值；缺失、负数或非整数状态会报错。此节点无参数，不使用协变量或分组。

## 估计方法

令 $d_{kj}$ 为时点 $t_j$ 的第 $k$ 类事件数，$r_j$ 为风险集人数，$S(t_j-)$ 为该时点之前尚未发生任何事件的概率：

$$
\widehat F_k(t)=\sum_{t_j\le t}\widehat S(t_j-)\frac{d_{kj}}{r_j},\qquad
\widehat S(t_j)=\widehat S(t_j-)\left(1-\frac{\sum_kd_{kj}}{r_j}\right).
$$

同一时点先统计所有原因的事件，后移除删失。在累积发生率计算中，其他原因事件不会被当作独立删失处理。

`result.causes` 给出事件计数和累积发生率向量各位置对应的原原因代码。`points` 覆盖所有观测时点，含风险集人数、删失数、按原因的事件数、无事件生存概率与各原因累积发生率。无事件生存概率加各原因累积发生率之和为 1。本实现为非参数点估计，并非 Fine–Gray 亚分布风险或原因特异 Cox 回归，不输出回归效应、标准误、置信区间或 p 值。适用于独立个体及独立右删失，不含延迟入组和复发事件。
