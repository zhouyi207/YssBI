# Bland–Altman 一致性

将两种方法的配对 Numeric 测量值连接到 **X / method A**、**Y / method B**，至少两个完整对齐的观测。差值定义为 $d_i=X_i-Y_i$，横坐标为 $(X_i+Y_i)/2$。

$$\text{bias}=\bar d,\qquad LoA=\bar d\pm z_{(1+c)/2}s_d.$$

$s_d$ 为以 n-1 为分母的样本标准差，c 为一致性界限覆盖率，默认 0.95。置信水平独立控制不确定性区间，也默认 0.95；两者须严格在 0 与 1 之间。

偏倚区间为 $\bar d\pm t_{1-\alpha/2,n-1}s_d/\sqrt n$，界限区间近似采用标准误 $s_d\sqrt{1/n+z^2/[2(n-1)]}$。要求配对观测独立，差值近似正态且方差稳定；重复测量或明显比例偏倚需采用相应扩展模型。

`result` 含偏倚、标准差、一致性界限、各区间和带零基行索引的观测点。统计量始终使用完整样本；展示点最多 2000 个，跨全样本系统抽样并保留首末端点，`sampled` 标明是否抽样。观测点用于检查和图形组合。

界限刻画方法间差异，是否可接受应依据应用预先设定的标准。高相关不等于一致。

参考：[Bland、Altman（1986）](https://pubmed.ncbi.nlm.nih.gov/2868172/)。
