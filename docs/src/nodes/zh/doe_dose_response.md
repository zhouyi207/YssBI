# 剂量反应（四参数对数逻辑曲线）

连接对齐的非负数值 **dose** 与连续数值 **Y**。每行一个独立观测；零剂量通过曲线的连续极限计算。
拟合等权非线性最小二乘模型 `c + (d−c)/(1+(dose/ED50)^Hill)`：

- c 为无穷大剂量处渐近值（`asymptote_infinite`）；d 为零剂量处渐近值（`asymptote_zero`）。
- Hill > 0，控制曲线陡峭程度；c、d 的相对大小决定递增或递减，不预先限制方向。
- ED50 > 0，为两个渐近值中点对应的剂量，不是观测最大响应的一半。

内部拟合 log(Hill) 与 log(ED50)，以保证正值；报告的对数剂量参数及 ED50 均使用输入剂量单位。
`max_iterations` 默认 500，`tolerance` 默认 1e-7。自动初值来自剂量端点和正剂量中位数。
需超过 4 个观测且最终四参数 Jacobian 满秩；恒定响应、剂量信息不足、不收敛或非有限结果会失败。

**result** 提供四个拟合参数、局部 Jacobian 协方差、t 近似 95% 区间、RSS/RMSE 和似然指标。
log(Hill) 与 log(ED50) 不报告任意零值检验。**details** 的 Hill 与 ED50 标准误用 delta 法，区间通过对数参数区间取指数；区间无法有限表示时为空。
同时标记曲线方向及 ED50 是否在已观测剂量范围内。
**observations** 完整输出观测序号、原始响应、拟合值、残差，不截断超过 512 行的数据。

适用于单条连续响应曲线、独立同方差误差；不等同于二项响应 Logistic 回归、毒性风险预测或 Meta 剂量反应。
未覆盖两侧平台的数据可能无法稳定识别 ED50；本实现不提供轮廓似然区间、加权拟合或多曲线共享参数。
