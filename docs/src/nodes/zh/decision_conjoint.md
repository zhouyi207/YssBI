# 联合分析（评分型）

**ratings** 连接方案评分，**factors** 连接对齐的分类属性，每行是一条方案评价。
数值属性编码也按类别处理，不视为线性斜率；水平按首次出现顺序排列，
保留原始标签。缺失类别、缺失或非有限评分会报错。

采用含截距的加性最小二乘模型，每个属性 L 个水平对应 L−1 个指示变量。
设计须满秩，观测数至少等于参数数。各属性的水平效用之和中心化为零，
并相应调整截距。属性重要性为其效用极差占全部属性极差之和的百分比；
全部极差为零时重要性为空。

**result** 输出水平效用、独立同方差 OLS 标准误、重要性百分比、
中心化截距、R² 与剩余自由度。没有剩余自由度时标准误为空；
评分全部相同时 R² 为空。**predictions** 保留全部行的评分、拟合值与残差。

本节点为评分型加性模型，不估计选择概率、属性交互或受访者个体效应。
同一受访者重复评分时，解释标准误前须另行处理其依赖结构。
