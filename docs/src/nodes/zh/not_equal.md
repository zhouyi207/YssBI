# Not Equal（!=）

判断两值是否不等：

$$
\text{Result} = (A \neq B)
$$

使用与“等于”相同的逐元素比较和广播规则。两个标量返回二元标量；任一输入为序列时返回二元序列。对非空比较结果取反，空值仍为空值。数值表示按精确数值比较，文本不隐式转为数字。所有数列须等长并按当前位置逐项比较，支持不同数据库来源及数据库与内存数列混合；需要时先将数据库数列加载到内存，不自动按键匹配行。

## 用法

在值不同时生成布尔掩码，供过滤或下游数据转换使用。

Detail 的配置默认 `exact`，使用上述精确语义。选择 `tolerance` 后仅支持 Numeric，显示绝对容差（默认 1e-12）和相对容差（默认 1e-9）；两项必须有限且非负，拒绝到 Float64 的有损转换。当 `abs(a-b) <= atol + rtol * max(abs(a), abs(b))` 时返回假，否则返回真；空值仍为空值。与“等于”使用相同配置即可获得互补的非空结果。
