# 分组 GroupBy

将 DataFrame 连接到 **Source**，设置一个或多个不重复的**分组键**。未连接时可以先输入列名；
输入结构已知后，表单提供候选并检查这些名称。

运行后得到保存源表和分组键的**已分组数据帧**。查看结果可以检查分组键及源列名；将该输出连接到
**按组调用 Apply** 或 **按组变换 Transform**，再调用图函数。创建或连接节点不会执行计算。

Null 键也参与分组。组按键升序排列，Null 在前；组内保留源行顺序，传入函数的表包含分组键列。
显式运行 GroupBy 会保留源结果，后续手动执行步骤可以复用它。

固定的计数、求和、均值等汇总可以使用**分组聚合**，直接对输入 DataFrame 计算指标。
