# Node Reference

Use the node reference to understand inputs, parameters, outputs and how to interpret results. These pages also provide the application's built-in node help.

Choose [English](./nodes/en.md) or [简体中文](./nodes/zh.md), then expand that language in the sidebar to find a node. The two sections cover the same documents.

Use English node names or technical terms, such as `Hausman`, in the book's search. The default English search index does not support Chinese-only queries; browse Chinese titles through the sidebar.

A help page does not guarantee that a node can execute. Use the node's availability in your current application session as the authority; unavailable nodes cannot be created.
