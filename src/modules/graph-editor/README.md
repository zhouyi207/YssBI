# Graph editor

> Status: Current
> Scope: React Flow 画布呈现、输入手势与编辑器投影消费
> Canonical owners: 本 module 的画布组件；应用操作和共享 viewport 由 features/application/editor 与 Core 提供
> Update when: 本模块的公开入口、状态归属、生命周期或契约改变时

## Canvas presentation and input

每个图面板只订阅自身的加载状态。Graph、Resource 等 owner 以不可变更新提交记录，在发布边界冻结并直接共享只读引用；读取端不再深拷贝或维护克隆缓存。React 统一通过选择器订阅实际使用的数据，打开另一张图或更新其他资源不重新构建当前画布模型。调用方不能原地修改已发布对象。
编辑器外壳只读取文档可用/冲突状态，执行工具栏只读取状态及取消/清理能力，不订阅未消费的文档或失败字段。
`useEditorCanvas` 的图身份只随路径与类型变化，选择变化保留该引用；覆盖层通过 memo 边界
复用目录和执行操作，同时保留各控件自身的结果、运行和语言订阅。
Pin 结果搜索按图读取 Results owner 的共享搜索投影，同图分屏复用条目。节点位置、无关诊断及
其他图结果变化保留未变搜索引用，标签更新或当前结果失效由同一读取入口交付。

可见性负责调用唯一的 `loadGraph` 用例，项目恢复复用同一入口确保可见图就绪。活动标签只同步焦点和 Details，不触发加载、重试或卸载。需要等待数据的显式用例（例如 Assistant 定位节点）直接等待该加载入口，然后执行定位。

节点画布使用 React Flow，每个 FlexLayout panel/group/resource 挂载独立 provider。
鼠标选择、平移、缩放和原生键盘配置与 Mind 共用 `shared/ui/flowCanvasInteraction.ts`；
基础快捷键映射共用 `features/core/keyboard/canvasShortcut.ts`，文档修改仍由各自的应用操作负责。
节点、连线及稳定 handle ID 单向派生自现有 editor projection；React Flow 的测量、
临时坐标和连接手势只是 UI 状态，不参与 Graph document 序列化，不创建第二套草稿或历史。
节点标题、端口、参数输入、执行状态和诊断仍由项目自己的 React 组件展示。
节点 CSS 类、状态背景和 Reroute 尺寸由 `internal/ui/Nodes/nodeAppearance.ts` 拥有，布局与控制器共用；这些呈现规则不属于 Domain。
Pin 输入直接使用后端投影中的 JSON 字面量和协议默认值，不再解码旧枚举包装。分组身份由画布和节点操作入口持有，不向不消费它的 Pin 布局传递。
可编辑标量输入由 `scalarPinInputKey` 的封闭返回类型统一判定，不再另设重复白名单或重复检查容器类型。
节点视图保留 React Flow 返回的 measured 尺寸和 dragging 标记；未变化节点复用对象引用，
避免拖动或选择时丢失 handle 测量并反复隐藏节点。测量回调在只读预览面板中也被接收，
零尺寸观察不覆盖已知有效尺寸；这些数据只属于渲染器，不提交到草稿。

React Flow 适配器共享只读 Pin 和连接投影，按实际布局字段复用未变化的节点与边；选择、拖动和测量叠加保留其他元素引用。稳定面板操作与临时连线反馈分别通过 Context 传递，模型和执行状态不再整图广播到每个组件。连线反馈按当前手势及目标端口复用计算，边只订阅自己的替换标记。
`createGraphFlowModelProjector` 归单个画布面板所有，直接用于现有 Graph 读取 selector。
它按不可变节点表及顺序、端口表、连线表分别判断失效，保留按 ID 索引的渲染对象；成员删除时
清理索引，面板卸载时释放整个缓存。节点实体未变化时跳过布局字段计算，端口顺序未变化时
复用 handle 布局键。连线拓扑直接消费连接记录中已校验的结构化端点与端口 ID，仅在连线表
或节点成员变化时核对；移动节点、端口标题、输入值和类型变化不扫描连线。端点存在性及归属
由 Core 发布入口统一校验，画布保留节点成员检查；连线外观继续通过自身 selector 更新。
渲染模型未变化时保留整体引用，避免通过
图投影订阅唤醒画布适配层；节点和端口的正文仍由自身 selector 接收更新。
节点正文只订阅展示字段和自身端口：坐标提交保留正文视图引用，避免布局移动连带重建标题、
参数及 Pin 组件；动态端口变更仍按投影顺序更新对应节点。缓存与读取契约由
[Core 节点视图](../../features/README.md)拥有。
默认节点布局用独立的 memo 边界渲染参数摘要与两侧端口列表，直接消费 Core 共享的参数组、输入和输出引用。
端口变化不重新筛选或序列化未变化的参数摘要，标题和参数变化不重新创建端口元素；单侧端口变化只核对该侧列表，
其中未变化的 Pin 继续由自身 memo 边界复用。图路径、菜单操作和 handle 渲染入口变化仍更新列表，
Pin 自身的输入、主题、结果和连接反馈订阅保持独立；布局不复制状态或增加发布入口。
实时平移与缩放由 React Flow 自身的 transform 更新；`useCanvasViewport` 只提供稳定的现有
group/graph session 访问接口，不通过 React 订阅逐帧坐标。适配器在 `onMove` 中将有效手势
同步到共享 session；session 订阅只在坐标不同步时写入画布 transform，用于导航和取消恢复，
不把实时坐标作为受控 viewport 属性送回 React 渲染/effect。画布适配层、上层编辑器命令和
工具栏不因每次平移而重渲染，也不增加第二份可写 viewport 状态。
恢复 transform 和 D3 坐标的 `synchronizeFlowViewport` 由共享画布适配层拥有，Mind 复用同一入口；
Graph 的共享 session、手势 lease 和提交策略继续留在原 owner。
鼠标平移复用 React Flow 的 `.react-flow__pane.dragging` 状态，仅为直属 viewport 容器
启用 `will-change: transform` 合成提示，让浏览器复用整个移动场景的栅格结果。
提示随原生平移状态在松键、取消或面板手势失效时解除，后续缩放可重新栅格化以保持清晰；
生命周期由既有手势和 React Flow 管理，无需额外 React 状态或逐节点图层。
传给 React Flow 的视口、节点和连线事件回调保持稳定，避免指针移动时反复发布 store 配置、
重新绑定平移处理器或重建节点/连线列表。共享的 `createFlowNodeViewProjector` 复用面板内
节点视图 Map，并在同一条目中保存节点数组位置。位置预览或选择变化时，仅遍历发生变化的
输入的新旧 ID 集合，按预览条目或选择成员差异更新相关视图；同一节点的位置、dragging 和
selected 一起派生，两者同批变化也只替换一次视图。取消预览时同样按 ID 恢复投影。
需要遍历的预览与选择条目总数达到节点总数时改用完整顺序遍历，仍复用视图中的尺寸和
交互能力；未变化的选择或预览直接沿用原字段，不扫描对应集合。图节点、顺序或交互能力变化时
完整核对，未变化节点保持引用；无实际视图变化时共享整个节点数组。只读面板忽略选择
变化，恢复可交互时依据当前选择完整核对。
该投影器也供 Mind 使用，只负责 React Flow 的选择、尺寸与位置叠加；Graph 基础投影、Mind
树布局和各自的文档命令继续归原模块所有。
`useGraphFlowNodes` 统一管理单个面板的节点尺寸、位置预览、拖动 lease 和节点视图发布；
画布适配器仍负责选择、连线、平移及菜单。位置预览由该面板的 ref 持有只读 Map，每批回调仅在首次实际变化时复制一次，
按 Map.size 选择视图更新路径，不枚举完整键数组。预览仍按原手势 owner 提交、清理和取消；
重复位置回调不发布新状态。节点移除时清理视图缓存，面板卸载时释放；选择 Set 只随选择
变化重建。这些暂态和缓存不形成另一份 Graph 文档或历史。
节点视图统一通过所属 React Flow store 的 `setNodes` action 发布，沿用库的节点索引与
handle 测量维护，不经过面板 React state、`nodes` 属性和库的被动 effect 回传。
首次有效移动立即发布；同一帧继续到达的移动仅覆盖最新预览，在下一次 animation frame
发布一次。持续密集输入期间每帧只消费最新值，不排队历史位置；没有额外输入时停止调度，
普通逐帧输入保持即时发布。帧回调复核当前拖动 owner 和 lease；松键同步发布最终位置并
提交一次，取消、图投影更新和卸载清理待执行帧。旧 mutation 完成只能清除自己的预览，
不能覆盖较新的拖动。节点和连线消费同一次发布，不各自增加节流器。
尺寸由节点视图缓存中的 `measured` 字段持有，不再维护另一张尺寸表。`updateMeasurements` 按 ID
校验回调并替换对应视图，只在首次有效变化时复制一次节点数组；重复、无效和已删除节点的尺寸不发布。
视图投影的 `project` 与尺寸更新共用同一份 Map 和数组，坐标、选择、只读切换及模型更新保留已有测量；
节点删除同时释放对应尺寸，重新加入时等待新测量。尺寸与位置同批到达时，先完成局部更新再通过同一入口发布一次。
纯拖动不分配空尺寸或选择数组，尺寸变化也不重渲染画布适配器。图投影、选择与交互能力变化在 layout effect
中安装最新派生依据，再通过同一入口同步；取消或异步提交完成也读取这一当前依据，
不能把较早 render 的模型重新安装到画布。相同数组不重复发布。
不传 `defaultNodes`，以免库在回调校验前自动应用已取消手势的迟到移动；位置仍先检查
手势 lease、节点可拖动能力与有限坐标，再发布该面板的临时视图。松键提交与 owner 清理
继续使用原应用命令，不增加坐标 store 或前端历史。
连线选择由同一面板的 `createGraphFlowEdgeViewProjector` 叠加，复用按 ID 缓存的视图及
数组位置，不在每次选择变化时重建完整 Map。少量选择变化只更新新旧选择集合的差集；
集合条目总数达到连线总数时改用顺序遍历。拓扑、顺序或交互能力变化时完整核对，保留
未变化视图；无实际变化时共享整个连线数组。选择 Set 仅随原选择数组变化重建，节点拖动
不重算该叠加层。初始化直接填充空缓存，删除连线时清理对应条目，面板卸载后释放。
选择事实仍由原面板状态拥有，画布库继续接收受控 selected 标记。
连接目标反馈直接由 React Flow handle 消费；节点拖拽及连线的选择、菜单和双击操作由 React Flow 画布适配器处理，展示组件不另行接管这些手势。
每个画布实例持有自己的连线反馈 store，Context 只传稳定的 store 引用。节点外观、Pin 外观和连线分别按节点 ID、Pin ID 或连线 ID 订阅淡化、高亮、目标和替换反馈；节点正文及参数控件不订阅全局 active Pin。开始手势时查询 Rust 的连接候选投影，在 layout effect 中发布呈现反馈；鼠标移动只查当前候选结果，不推导类型、容量或被替换连接，也不发起 IPC。图编辑版本、语义身份或资源发布变化会清除旧候选并重新查询；取消手势后忽略迟到响应。等待或查询失败时反馈保持中性，快速松键仍可提交到 Rust 做最终校验。选择及拖拽预览继续归所属物理面板所有。
目标端口由无 DOM 的 `GraphFlowFeedback` 单独订阅 React Flow 的 handle ID，并在 layout effect 中
一次发布目标与替换连线集合。跨端口移动只更新这层反馈及实际变化的订阅者，不重渲染画布适配器，
也不重新创建画布配置和 JSX。该组件复用面板的反馈 store，节点/候选投影与连接命令仍由原入口管理；
源端口、候选结果变化及取消会通过同一发布入口更新，面板卸载时随 React 释放订阅。
正式连线的统一淡化由画布根元素的 `data-connection-active` 和 CSS 管理，直接复用已校验的
反馈源端口；边不再各自订阅全局连线标记。选择器只作用于当前根元素直属 viewport 的正式
连线层，每条边仍独立合成透明度，临时预览线与 viewport portal 不受影响。空白处创建节点
菜单等待期间沿用原源端口，取消或清理源端口后解除淡化；替换高亮仍由每条边按自身 ID 订阅。
反馈 store 直接共享现有只读端口表和候选决策表，仅派生节点淡化集合。Pin 外观 selector
按 ID 返回 active、highlighted、dimmed 或 neutral 原始值；目标 handle 与预览线直接读取
该端口决策，等待态复用一个常量。无需逐端口复制展示对象或递归深比较，候选理由变化但
外观不变时也不重渲染 Pin 外观。整体反馈只依赖端口表、节点成员、起点和候选表，节点位置
变化不重算反馈；替换连线 Set 只随当前决策的 displacedConnectionIds 引用变化重建。
节点只读取自身能力、连接存在性和运行展示；端口的关联连接查询仅在[查看菜单](internal/ui/Pins/README.md)打开和调用时执行。节点内容插槽独立于状态徽标，徽标更新不重建端口布局；运行展示的按图派生与元素 selector 由 [Results application](../../features/application/results/README.md) 提供。
节点控制器按不可变诊断数组引用复用首要诊断，阻断判断与诊断徽标共用同一结果；运行订阅
只读取该诊断的 blocking 标记，不随每次执行发布扫描列表。诊断文字按诊断、语言及可见状态
复用，提示与无障碍标签共用一次格式化结果。菜单专用的端口连接检查只在菜单打开时执行。
连线的阻断状态按 ID 订阅 Core 实体桶的 `blockedConnectionIds`；索引与实体由[图投影 Store](../../features/README.md)一并发布，组件不扫描完整诊断集合。
`createGraphFlowEdgeAppearanceSelector` 将连线的两个端口及阻断索引合并为一次图订阅，
只交付颜色键、端点存在性和合并 orphan 的阻断标记。未变化端口直接复用读取结果；
端口参数、标签或连接数量变化但这些字段未变时也保留视图引用，不唤醒连线。
selector 随图、连线或端点 ID 变化而替换，卸载后释放；节点坐标变化不重算端口外观。
颜色复用 `pinTypeColorKey`，与完整 Pin 视觉使用同一规则，不为连线计算类型标签、形状或容器标记。
主题、结果有效性、运行状态和连接手势继续由原有订阅更新，端点缺失仍显示未运行缓存与原回退颜色。
`GraphFlowEdge` 将坐标几何与业务外观分离：坐标变化只计算一次曲线，
`GraphFlowEdgeAppearance` 通过 memo 隔离主题、结果、诊断和连接反馈订阅。普通线条、
选中/悬停高亮、运行动画及命中区域使用直接的 SVG path，避免共享定义变化触发额外的
`use` 实例样式计算；不需要全局路径 ID 或跨面板 SVG 引用。
固定 SVG 结构按连线身份及外观输入缓存，坐标变化不重新分配对应 JSX 元素或核对其子树。
正式连线与临时连线预览共用 `useEdgePath`：每个实例仅持有自身已挂载路径的 Set 和最近提交的曲线字符串；稳定 callback ref 在挂载时
同步几何，并通过 React 的 ref cleanup 移除元素。新出现的悬停高亮和运行动画无需等待
下一次坐标变化，卸载也不会遗留路径。几何由当前 React Flow 坐标计算，在 layout effect
中仅写入这些 path 的 `d` 属性；React 继续管理元素和外观，避免两条路径同时写入 `d`。
更新随本次 React commit 在绘制前完成，不增加逐帧调度或延后一帧；选中、端点或业务
数据变化仍核对结构，外观组件的主题、诊断和运行订阅独立生效。
`GraphFlowConnection` 的坐标变化同样只计算并发布曲线，缓存的外观组件只订阅目标端口的候选反馈；
指针在同一目标或空白区域移动时不重建外观 JSX。目标或候选结果变化仍更新颜色、无效理由等提示，
源端口、缩放和坐标变化继续由 React Flow 提供，路径更新与本次 commit 同步。
曲线方向分别复用 React Flow 测量的 `sourcePosition`、`fromPosition`；`FlowHandle` 已按 Pin
方向设置左右位置，反馈 store 不再镜像源端口方向。反向拉线与受损反向连接沿用相同规则。
待创建节点的菜单预览继续直接传坐标给同一个 `Edge` 绘制组件。几何仍由 React Flow 坐标和既有曲线函数派生，
不增加坐标 store、命令或帧调度器。
节点拖动期间，连线暂停装饰性的 SVG 阴影滤镜，减少多条长曲线随坐标变化产生的绘制开销；
颜色、虚线、运行提示、选中高亮和命中路径仍保留。节点拖动独占指针时，同一 viewport 的连线命中路径
暂不参与指针命中，避免曲线从指针下方经过时反复触发悬停更新、挂卸高亮路径和样式计算；命中路径无需卸载或重建。
CSS 直接读取 React Flow 节点的 `dragging` 类，只影响同一 viewport 的连线层；松键或移除拖动节点后
自动恢复悬停与点击。取消立即恢复节点位置；若指针仍按下，则继续暂停连线命中，直到原生拖动结束。
不另建手势状态、逐帧订阅或计时器，也不增加连线更新延迟。其他面板的交互保持独立，
多选拖动沿用实际被拖节点的同一生命周期。

拖动中的位置覆盖只保存在该画布，结束时通过现有 Application 命令提交一次 MoveNodes。
节点设置 `nodeDragThreshold={0}`，让 React Flow 在按下时记录抓取点；若等超过阈值才
记录抓取点，首段位移会丢失并形成后续拖动的固定偏移。未发生位置变化的按下/松开
没有位置预览，不提交 MoveNodes；点击选择和 Details 继续由既有点击入口处理。
未完成 mutation 保留自己的预览；失败后恢复投影，迟到回调不能清除较新手势的预览。
Escape、面板隐藏、保存锁定、关闭图和替换项目都撤销手势；回调在提交前复核物理面板与项目身份。
取消旧面板的选择预览不能改变新面板的 Details 上下文。

普通单击画布节点会更新节点详情并切换、展开右侧 Details 标签；再次点击已选中的节点也会执行该操作。修饰键多选和程序化选择仅同步原有上下文，不触发详情标签切换。

可见分屏画布按自身面板和图路径接收操作；侧栏输入焦点不改变画布交互模式。运行工具栏持续显示，保存时禁用运行，各按钮操作其所属图。

鼠标平移只接受当前有效手势的 viewport 更新；取消后忽略剩余移动，松键时也恢复画布库内部
变换，防止下一次平移跳动。取消后的迟到移动立即恢复 transform，不发布或保存新坐标；
session 的程序化同步不创建或结束鼠标手势。
框选在按下时捕获完整的节点/连线选择，Escape 立即关闭选框并恢复原选择，后续松键不重新提交
框选或触发空白点击。Shift 轻点空白保留选择，普通空白点击清空；框选与节点/连线拖动均不
隐式自动平移。端口命中区域始终隔离节点拖动和平移，包括禁用和 orphan 端口。

Event Graph、Function Graph 和 Mind 统一在框选过程中显示临时选框，松开鼠标后仅保留
节点/连线自身的选中高亮。画布在 pointerup 冒泡阶段清除库的分组外框状态，使外框 DOM
卸载，不保留透明的分组命中区域。Event/Function 仍可通过拖动任一已选节点带动其他已选节点；
选中节点之间的空白区域按普通画布空白处理。指针取消时清理选框并恢复框选前的选择。

普通连接、Ctrl 迁移端口连接、Alt 断开、空白处创建并连接节点和双击连线插入 Reroute，
继续走已有草稿命令与 Rust Resolve。React Flow loose handles 只表达连接锚点，方向和兼容性
来自投影，受损连接仍可显示以供修复。首次挂载和实际尺寸变化统一由 React Flow 共享的
ResizeObserver 批量测量，节点不再各自安排重复的初始强制测量。`GraphFlowNode` 只记录
最近提交的端口布局键；后续端口增删或重排时调用库的 `updateNodeInternals`，即使节点尺寸
未变也重新定位 handle。尺寸与内部坐标仍归原渲染器管理，分屏和重新挂载各自测量。
删除、复制粘贴和撤销重做不使用画布库自建的文档修改或历史。
菜单和操作入口根据后端 `managed` 标记判断复制、创建副本、删除及剪切是否可用，缺失投影时禁用；后端保留最终校验。节点 Details 展示参数、配置、端口、诊断和文档，不展示内部能力字段列表。

viewport 复用既有 group/graph viewport session，缩放、导航定位、侧栏拖入和视图偏好
共享同一坐标系。当前保持全部节点挂载，供 F/Home 与 Problems 定位读取完整节点边界；
不默认启用可见区域裁剪，也不随迁移引入自动布局引擎。

桌面人工验收应使用同一张图比较平移、缩放、单节点和多节点拖动，以及 panel 浮动移动和分屏缩放；
同时检查 Escape 取消、隐藏/保存时中止手势、松键后一次位置提交、F/Home 定位和侧栏拖入的坐标。
数据路径耗时和无浏览器绘制的回归检查不能替代实际桌面帧率与响应性验收。

工作台空白区域的 `WatermarkView` 居中显示 YssBI 和本地化描述，以主题强调色、静态柔光和细分隔线呈现品牌层次；不接收操作命令，也不包含按钮或动画。
