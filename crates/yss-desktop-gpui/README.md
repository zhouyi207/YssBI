# GPUI desktop host

> Status: Current
> Scope: GPUI 原生桌面入口、项目导航、工作台、资源及图表编辑、执行结果、Assistant、模型设置与插件管理
> Canonical owners: Cargo.toml、src/main.rs、src/window_chrome.rs、src/services.rs、src/projects/、src/workbench/、src/canvas/、src/documents/、src/markdown.rs、src/minds/、src/databases/、src/charts/、src/plots/、src/imports/、src/plugins/、src/settings/、src/assistant/、src/file_commands.rs
> Update when: 原生宿主能力、状态所有权、启动方式或验收范围变化时

这是 workspace 的默认原生桌面入口，使用 GPUI Pre 0.3.8 和 GPUI Component 0.7.1。
窗口及画布由 GPU 原生绘制，不启用组件库的 WebView feature。
窗口手势由项目的 `window_chrome` 统一处理，组件依赖直接使用 crates.io 发布版。

基础界面优先复用 `gpui-component`：标题区域使用原窗口图标与主题，菜单使用 `AppMenuBar`，工作台使用 `DockSkin` 与根 `DockArea`，
数据库及结果使用 `Table`，设置导航使用 `Sidebar` / `SidebarMenu`，输入、菜单、按钮、
Markdown 与常规表单使用对应原生控件。主题由 `appearance` 统一设置，不另建基础组件或布局模型。
图、Mind 画布与专用预览保留本模块的绘制和交互；业务状态、校验及异步提交仍归现有 owner。
图、数据库、图表的删除，以及供应商删除和放弃设置，使用 `AlertDialog` 确认，危险操作有明确的危险按钮；
普通编辑表单继续使用 `Dialog`。其他系统确认提示尚未全部替换。

```sh
cargo run
cargo run -- /absolute/path/to/project
cargo run -- /absolute/path/to/project events/example.yssbi-event
cargo run -- /absolute/path/to/project docs/example.md
cargo run -- /absolute/path/to/project minds/example.yssbi-mind
cargo run -- /absolute/path/to/project <database-id>
cargo run -- /absolute/path/to/project charts/example.yssbi-chart
cargo build --release
```

根 Cargo profile 对开发构建的宿主及 GPUI、Naga 着色器编译器、路径细分和布局依赖做定向优化，保留调试信息；
普通 `cargo run` 会直接应用这些配置。WGPU 每次新建窗口都会同步编译着色器，Naga 的定向优化
减少设置等独立窗口打开时的主线程停顿。首次构建受影响依赖会更慢，业务 crate 仍沿用默认开发配置。
帧率验收使用 `cargo run --release`：120Hz 每帧预算约 8.3ms，需在相同图
规模、窗口尺寸和显示器刷新率下实测平移、缩放、节点拖动与连接，不能从 GPU 架构直接推断达标。

五个示例的 catalog 和 Parquet 随源码提供，开发运行不需要下载来源。独立运行或分发时，
从根目录执行下列命令，将生成的 `resources` 目录与对应可执行文件一起保留：

```sh
cargo run -p yss-application --example build_samples -- --check --stage target/debug/resources/samples
# release 构建使用 target/release/resources/samples
```

来源、归属和维护时的输入下载见[示例资产](../../resources/samples/README.md)。此入口只准备资源；
各平台安装包和签名仍待迁移。

未提供目录时显示简洁欢迎页；Ctrl/Cmd+O 直接打开项目目录，Ctrl+Alt+O / Cmd+Option+O 搜索最近项目。
第二个参数可指定图、文档、Mind 相对路径或项目索引中的数据库 ID。
未指定资源时恢复已保存标签，否则优先打开首个 Event 图，再选择首个 Function 图。
项目和图由现有 Application 用例打开，启动读取发生在窗口事件循环之前，后续阻塞操作在
Tokio blocking pool 执行，指针事件不读取磁盘。

## 模块、状态与数据流

- `projects/form`：新建与另存为的未提交名称和目录输入；默认位置由原 registry owner 查询。
  提交复用原生命周期用例，部分写入失败保留已写入目标和恢复入口，不重复创建。
  默认目录只有在父目录尚未被编辑或明确选择时回填；输入后清空也保留为空。目录选择器打开时允许默认查询完成，
  取消选择仍保留默认值，实际选择优先；默认读取失败提示手动选择，不吞掉失败。
- `projects/feedback`：从原 Application 生命周期错误、Project 稳定 code 与 recovery_required 生成安全展示。
  UI 不显示底层诊断正文；忙碌、无效位置/名称、资源冲突、需要恢复及文件事务失败分别使用原本地化键或原生提示。
  部分提交优先使用原回执结果；已有提交回执后打开失败仍明确提示文件已写入。会话刷新错误提示先检查实际项目和目标，
  不把返回失败等同于零写入。worker 交付文案键和原 code，在接纳回执的 UI 阶段本地化；没有 IPC 错误解析或新的错误协议。
  表单展示原恢复目标的完整路径提示与复制按钮，打开已写入项目仍沿用原操作入口。
- `projects/progress`：只展示当前项目操作的阶段及原目标路径，工作台和提交表单共享同一个无输入控件的实体。
  复用原生 Progress 的不确定进度；步骤来自现有 worker 的创建/打开、实际项目读取、最近记录更新和工作区准备，
  不估算百分比。Tokio watch 只保留最新步骤，不阻塞提交；结束或失败后由原 lifecycle 清除显示，迟到步骤只可能到达旧实体。
  保存前置步骤同样显示进度；表单输入保留但暂时隐藏，失败后恢复，已写入目标继续沿用原恢复入口。
  原 Application 生命周期没有取消入口，因此不提供取消按钮；扫描/清理的进度及取消属于已移除的项目库流程。
- `projects/recent`：原 ProjectManagement 登记记录的只读投影，只展示有 last_opened_at 的记录，排序沿用 Rust owner；
  后台读取合并刷新需求，失败保留目录打开入口，捕获的读取代次和完整记录拒绝过期选择。
  `recent/picker` 使用组件 ListState/List 的输入、虚拟列表、焦点及键盘选择，搜索只匹配名称和原路径；
  搜索与列表更新重置选择，弹窗关闭释放输入和列表实体，不把视图记录写成另一份最近项目文件。
  登记读取任务跟随 RecentProjects 实体，不绑定发起弹窗，关闭弹窗不影响完成和后续刷新。
  最近弹窗在读取失败时显示错误与原位重试，即使已有旧记录也不允许选中；重试沿用原读取与当前搜索词。
  错误只保存文案键，在欢迎页和弹窗按当前语言呈现；欢迎页继续使用同一个重试入口。
- `workbench/projects`：目录选择、最近项目弹窗、保存确认和类型化项目命令；新建、打开、另存为、关闭均调用原 Application。
  操作后查询实际激活与索引，成功切换才替换编辑器；同一项目仍保留输入。项目路径精确使用 Rust 返回的入口文件路径。
  宿主 lifecycle 拒绝迟到目录选择、确认和安装，替换期间停止旧交付，保存回执接纳后才继续后续命令。
  关闭项目停止原 watcher 并回到欢迎页；窗口退出复用同一保存确认。近期记录读取不阻塞直接打开目录。
- `workbench/welcome`：空工作台的打开/新建入口及最近六项，一次点击打开捕获记录；只消费原登记投影与已有项目操作。
  欢迎页采用窄幅纵向分组与紧凑整行 ghost 按钮，快捷键提示读取工作台的实际 action binding；最近项目的名称与路径同排，悬停显示完整路径。
  独立项目库选择页与顶栏项目库按钮已移除；收藏、扫描、登记清理和回收站不再作为原生打开流程入口，底层登记服务仍保留。
- `documents`：原生 Markdown 编辑器、可选择的 GFM 预览及文本撤销/重做。输入是未提交 buffer，
  明确 Save 捕获当前 FileVersion，提交原 DocEdit 后调用原 Save；持久化失败保留中间编辑快照和输入。
  项目或版本失效不覆盖当前输入，干净文档可安装同一后端的后续投影；读取/保存期间收到的失效通知合并后重新查询。
  `documents/details` 从同一编辑器读取文件名、路径、保存/读取状态和错误；工作台只选择展示目标，不另建文件状态。
  数学公式复用共享 Markdown 扩展；外部引用预览仍待迁移。
- `markdown`：节点文档、文档预览、Assistant 消息/引用和 Mind 标签共用 `Markdown` TextView 插件。
  后台解析、文本选择、表格横向滚动及代码高亮复用原生组件；Cargo 显式启用 Bash、CSS、HTML、JavaScript、JSON、Python、Rust、SQL、TOML、TSX、TypeScript、YAML grammar。
  `markdown/highlight` 在宿主启动时将 [tree-sitter-r](https://docs.rs/tree-sitter-r/) 与 [arborium-julia](https://docs.rs/arborium-julia/) 的 grammar 和查询注册到组件原有 LanguageRegistry，补齐 R、Julia；`R`、`jl` 共用对应语言配置。
  查询捕获名适配组件已有的主题分类，高亮、缓存与主题更新仍由组件负责，未知语言保持源码；单波浪号语义和脚注导航仍待迁移。
  `markdown/links` 只将无凭据的 HTTP(S) URL 交给平台，在后台调用 [open](https://docs.rs/open/5.4.1/open/fn.that.html)，失败显示本地化通知；不记录 URL 或底层错误正文。
  项目资源导航由调用方提供，同段显示公式拆出的正文继承相同链接处理。
- `markdown/math`：`$…$` 使用行内数学样式与文字基线；`$$…$$` 和 `math` 围栏使用显示样式，宽公式在正文列内横向滚动。
  同一段的顶层 `$$…$$` 拆成公式与正文；嵌套标记、引用式链接和连续跨块选择继续验收。
  通过 [RaTeX](https://github.com/erweixin/RaTeX) 的 parser/layout/svg crates 生成包含字形轮廓的 SVG，GPUI 按字号与缩放绘制，单色公式继承正文颜色。
  `markdown/typesetting` 在后台解析阶段排版，128 项 LRU 按公式与数学样式复用成功和失败；视图渲染不解析 LaTeX，不依赖 WebView 或在线服务。
  无效公式回退为原始源码；公式右键可复制保留分隔符的源码。普通代码和转义美元符号保持字面量；Assistant 的替代公式分隔符仍待迁移。
- `minds`：Project MindSnapshot 的原生树画布。layout 按父子关系、兄弟顺序、折叠状态和内容推导坐标；
  render 绘制有界可见主题、Markdown 标签与合并曲线；input 拥有选择、框选、平移、缩放与取消。
  details 挂载到已有 Details 面板并借用所选主题；父主题候选仅在菜单打开时派生，排除自身和后代，重复选择当前父主题不提交。
  topics 派生结构操作、排序边界和成功后的选择；新增选择新主题并展开父主题，单主题删除选择父主题，迟到回执不覆盖后来选择。
  buffers 只保留捕获版本的未提交主题文本，切换主题保留输入；成功回执确认本次提交且未再编辑的输入，删除分支不遗留已提交脏草稿。
  commands 将当前输入与结构操作组成一次原 MindEdit 批次；保留显式应用/恢复输入，显式 Save 才写文件，过期输入不自动覆盖后端。
  恢复内容只放弃当前主题未应用的文本，读取/保存期间的失效通知合并后重新查询。
  节点坐标不写入文件，节点和群组不可单独拖动。当前高度按内容估算，长 Markdown 的测量仍需完善。
- `file_commands`：Doc/Mind 共用的捕获版本、编辑和保存提交，仍分别调用原类型化 Application 入口。
  写入失败保留已提交编辑的快照，后续保存不会沿用旧版本。
- `charts`：当前 ChartDocument 的未提交配置与已保存内容，类型直接使用原 ChartType；Project 仍拥有文件和资源版本。
  query 在 worker 按项目 publication 读取图表，按数据库资源版本读取元数据、分布或有界列对；新配置取消旧交付，
  较旧目录投影不能覆盖较新读取。匹配来源的不可变元数据由 Details/预览共享，同一数据库版本下更换编码可直接复用；失效列或预览失败不丢弃配置。
  `query/preview` 在查询前核对编码列，区分缺列、数据源删除、无有限坐标与读取失败；视图显示本地化原因、稳定错误码及重试，不展示后端内部错误正文。
  重试刷新项目读取基线并保留脏草稿。首次打开接纳工作台与读取结果中更新的目录，再启动预览；文件版本已变化时才重读配置，删除后的旧交付不能恢复资源。
  commands 显式提交完整配置并沿用 GUI Save 的当前 Rust 基线；已接纳保存之后再排队刷新，保存全部和后续项目导航共享原流程。
  外部修改时保留脏草稿并提示覆盖语义；删除后的旧读取不能恢复已删除文件。Rename/Delete/Copy 仍校验原资源版本。
- `charts/details`：数据源与列菜单在打开时才从共享目录/元数据生成选项，数值轴直接消费后端 Semantic 类型；列清单按 50 项分页。
  `details/columns` 借用已接纳元数据展示列名和等宽类型，完整名称可悬浮查看；缺少元数据和空列均显示原空提示，不新增共用列模型。
  再选当前数据源/图表类型保留编码；实际更换才重置。无变化草稿不安排读取，旧菜单仍由原草稿代次和项目 publication 校验。
- `plots`：独立图表与结果图形共用 GPUI Plot、轴、网格与缓存曲线，直接绘制后端点；直方图使用现有 BarChart 和原分布计数，
  分箱身份按原顺序区分相同显示标签。直方图仅请求所选列分布，由 Runtime 在聚合前投影；绘图范围及像素映射留在视图，不计算统计分布。
  date 使用天、datetime 使用微秒的原算术表示；刻度和悬浮信息保留原日历/钟面字段，不换为本地时区。
  `cartesian/marks` 复用组件 Line/Area 和 PathCaches；ECDF 从零值开始按 StepAfter 绘制，KDE 填充至零基线。
  默认范围包含参考线端点，显式 domain 保留升/降方向，固定概率轴为 [0, 1]；图形裁剪在坐标区内。
  气泡半径按大小平方根映射，零大小不绘制；悬浮显示原坐标和大小。主题来自现有 ActiveTheme。
  `frame` 复用组件轴、网格和文本测量；`matrix` 共用矩阵单元格/图例，相关系数使用 [-1,1]，热力颜色范围来自原矩阵，重复标签仍按行列位置区分。
  `correlogram` 显示原 ACF/PACF、零线与置信带；`distribution` 绘制后端四分位数/须线/异常点和缓存的小提琴轮廓，不估计密度。
  `interval` 共用误差线与系数区间，系数每页 100 行，范围一次准备，悬浮身份随页改变；`nomogram` 仅排序并布局后端刻度，支持滚动查看全部轴。
  `composite` 共用帕累托和组合图的柱/线，复用 Frame 的右轴与缓存曲线；帕累托每页 100 项，右轴固定 0–100%，翻页不重新计算累计比例。
  组合图共轴时范围包含两组值，双轴时折线独立定标；相同标签用位置区分，悬浮保留原词频整数和两组值。
  `wordcloud/layout` 用 GPUI 字体测量按原词序进行有界螺旋排布；数据身份、尺寸和字体不变时复用原排布，主题改变仅重新着色。
  词云保留中文/emoji 与原词频；长词缩小至可用宽度，文本只在展示时折叠空白，提示显示实际排下的词数、原唯一词数和总出现次数。
- `workbench/charts`：图表目录打开、UI intent、Details、标签恢复及脏窗口保护；弱引用表不拥有拓扑。
  图表新建复用原生命名入口，目录右键支持重命名、复制、删除和路径复制；实际目标来自原回执，目录仍重读 Project 索引。
- `imports`：来源选择、原生文件选择、CSV 配置、SQL 连接输入、工作表/表选择与示例目录。
  inputs 将暂态输入转换为现有 DatabaseImportSource；连接配置使用 URL 编码，密码和连接串默认遮蔽。
  返回同一连接表单保留端口；更换引擎时只有原默认端口跟随更新，自定义端口与其余输入继续保留，关闭检查按当前引擎判断脏输入。
  输入控件的 Enter 事件调用当前文件或连接步骤的原提交入口，忙碌期间不重复提交，表选择页仍需明确选择目标。
  discovery 在 worker 调用原 Excel/SQLite/SQL 查询和 SampleCatalog。`imports/selection` 统一渲染虚拟表/工作表列表，
  本地来源展示文件名并悬浮显示路径；远端只展示引擎与服务器地址，不将连接串凭据或查询参数带入提示框。
  `imports/samples` 直接消费原目录，复用本地化名称和说明，显示行列数、KB/MB 大小、空目录与当前导入项进度；
  行回调仅捕获示例 ID 与版本，不复制整项元数据。目录失败提供重试，导入失败保留目录与选择入口。
  `imports/feedback` 将原 SampleError 映射到本地化提示；数据库提交或会话刷新失败仍提示检查实际项目结果后再重试。
  三类来源共用暂态步骤状态，窄窗口下分类横向排列；未实现的 REST API 占位入口不注册原生操作。
  读取与导入期间锁定输入；失败保留原表单，取消时保护未提交的配置。仅确认后提交导入。
- `workbench/imports`：捕获项目与宿主 lifecycle，调用原类型化导入或示例导入入口并发布实际回执；
  读取权威项目索引后打开新数据库，不从回执拼接目录。提交结果不确定时重新读取目录，保留输入并提示检查。
- `databases`：仅持有 Application 元数据、编辑状态及每页 100 行的读取投影，复用原数据库历史与保存 owner。
  query 使用同一资源版本查询元数据、编辑状态与页面；语义变更保留数据修订号相同的已接纳页面，

  读取失败状态由同一编辑器持有，重读开始清除、读取失败设置、成功清除，不从保存或导出错误推断。
  首次读取失败仍安装可重试面板；再次打开失败资源或点击刷新沿原 query 重试，侧栏直接观察该编辑器。

  过期字段菜单和导出选择不能盲目使用新版本；原应用会话在保存后替换，工作台重新绑定事件与图执行投影。
  数据库设置在原 mutation 提交时已写入项目，EditState 的 dirty 表示运行时历史尚未 checkpoint；
  Save 建立检查点并结束该历史，不能将其解释为文本 buffer 的未写入更改。关闭提示明确直接退出会保留已应用的设置。

- `databases/semantic`：对话框拥有未提交的 ColumnSemantic 草稿，按捕获版本读取完整非空去重取值；切换类别语义保留已声明但未出现的值、标签和顺序。

- `workbench/plugins`：项目内使用根 DockArea 的固定插件面板，无项目时使用原生弹层；忙碌状态阻止关闭和项目切换。

- `settings`：左侧使用 Sidebar / SidebarMenu 的 AI/供应商导航，右侧面包屑、固定保存栏、状态提示与独立滚动表单；只缓存原 LanguageModelCatalog。

  `settings/models/provider` 复用 GPUI Combobox 搜索原服务目录，组件持有筛选、键盘选择与焦点；添加直接进入首个预设的编辑页。

  协议与认证使用独立控件，适配器默认值继续来自原预设。凭据可复用范围复用 Contract 判定，由 Application 强制校验。
  列表与默认模型菜单借用目录生成显示项；编辑按钮仅捕获账户 ID，点击时读取当前配置，避免渲染时复制全部模型和使用过期配置。
  `settings/commands` 在 worker 调用原 LanguageModelService，发现使用连接草稿，返回后按模型 ID 自动合并到草稿，

  保存/发现期间禁用输入和导航，失败保留草稿；菜单与确认绑定原页面代次。重新打开刷新目录但不覆盖现有草稿。

  设置窗口关闭后由工作台根实体保留草稿，重新打开继续编辑；窗口/项目操作的保存确认及保存全部覆盖模型设置。

- `assistant`：每个明确 session 的原生会话面板、未提交输入、资源引用、运行选项与待发送队列。

- `assistant/composer`：新会话输入区铺满内容，有历史时固定在底部并提供展开/收起；整体最多占会话高度的 75%，

- `assistant/thread`：会话视图持有已加载历史的起点，首次显示最近 20 轮，每次向前加载 20 轮；新轮次不挤掉已加载历史。

  普通滚动及惯性产生的偏移不被锚点回写。接近底部继续跟随排版后的最新内容，浏览历史时提供“回到最新消息”；到达底部后隐藏该按钮。
  渲染更新后需要校正时在下一帧通知原会话实体，不在事件交付层控制滚动，不增加定时刷新。宽窗口正文每轮及会话级输出最多 768px 并居中。
- `assistant/usage`：输入栏的原生 ProgressCircle 与 Popover 展示本轮 Token 累计和主对话最近请求的输入/容量。
  `assistant/projection/usage` 在原事件归约中增量累计 Manager、Worker 与上下文整理的已报告字段，未知与零分别保留，
  使用整数累计和格式化；缓存包含于输入、推理包含于输出，不重复相加。缺失输入或输出报告时提示统计不完整。
  只有主对话的 Response 报告更新占用；主对话整理完成清除旧占用但保留累计，Worker 整理不清除主对话占用。
  新轮次从空统计开始，重放沿用同一入口和序号去重；弹出层每次读取当前轮次，不扫描输出历史或复制消息，模型标签来自该轮记录。
- `assistant/execution`：轮次、任务和工具共用时长展示；开始、最近进展和结束时间只读事件时间，
  轮次/任务终态结算尚未结束的子项，保留已有结束时间；缺少工具开始事件不虚构耗时。
  消息标题呈现记录中的模型名、供应商提示及该轮 Ask/Write、推理档位；未收到 TurnConfigured 不显示选项，当前草稿不改写历史。
  可见且已连接的运行会话通过窗口元素状态持有一个每秒刷新任务；隐藏、断流、重放或终态后释放，历史消息不各自创建计时器。
  无结束记录且当前不能确认运行时显示“计时待同步”；结束耗时不受本地时钟影响。时间提示在悬停时按系统本地时区格式化，工具详情复用同一格式；原事件时间不转换或持久化。
- `assistant/projection`：消费 [Harness Contract](../yss-harness-contract/README.md) 的 `AssistantEvent`，按事件序号形成输出条目。
  `projection/output` 为 Manager、Worker 与上下文整理共用同一处理路径，保留思考、正文、工具、计划、引用、调用用量、运行状态及工作流事件；
  Worker 输出留在所属任务中，每次续跑保留独立条目。Manager 终态产物按原顺序引用其任务记录，复用资源/结果卡片，不复制产物状态。
  正文撤回按 Unicode 字符计数保留有效前缀，撤回片段可折叠查看；结束事件仅在没有有效流式正文时补入备用回复。
  上下文整理的思考、摘要与用量单独分组，轮次或任务结束结算未完成整理；内部 checkpoint 校验元数据不进入界面。
  `render/output` 共用有序条目渲染，`render/task` 借用 Worker 输出与 Manager 产物，任务外层沿用 `assistant/tasks`。
  思考和上下文整理运行时默认展开，结束后默认收起，用户选择优先；思考正文在有界区域滚动。折叠不删除事实，刷新沿用同一事件入口重建。
  `render/failure` 在消息内呈现本地化失败与可展开的原始技术码，未知码使用通用中断提示；重复交付失败更新原卡片。
  消息复制复用原生 Clipboard 的按点击取值和成功反馈，仅拼接有效正文；运行中的回复不显示复制按钮。Worker 摘要去重直接比较正文片段，不在重绘时拼接全文。
- `assistant/render/plain`：用户消息、思考和失败技术码共用原生只读 Textarea，保留原始标记、空白及换行，支持局部选择、键盘导航和复制。
  可见窗口的元素状态持有控件；只有投影文本变化才更新内容，并保留选区和滚动，隐藏后释放控件状态。用户编辑不改写消息事实。
  回复、Worker 摘要和引用片段使用共享 Markdown。
- `assistant/markdown`：为回复、摘要和来源片段设置代码语言、原生 Clipboard 操作与流式淡入，代码操作保留独立元素身份。
  复制按点击读取所在代码块，保留缩进、空白和最终换行；操作区预留顶部高度，长代码在列内横向滚动。高亮和复制不改写消息投影。
  `yssbi://` 的六类类型身份与相对路径只在激活时从当前共享资源目录解析；严格 UTF-8 百分号解码，相对路径要求唯一匹配。
  打开继续调用原 `open_reference` 与工作台路由，沿用项目核验、打开去重与失败反馈；不另建目录、查询或编辑器状态。
  非资源链接交回共享外链入口；缺失或无效资源显示本地化通知。锚点定位与无效链接的禁用外观继续审查。
- `assistant/tools`：工具调用序列共用 Collapsible 分组，直接借用事件投影计算总数、完成数、失败数及当前工具。
  已连接且运行时默认展开，手动选择优先；断流停止转圈并显示待确认，组收起释放工具详情的窗口状态。
  `assistant/projection/tool` 归约完成、失败、超时、取消、结果未知及图执行结果；调用完成不覆盖已记录的图执行状态。
  缺少开始事件的终态仍保留调用，任务/轮次结束只结算尚未结束的工具，不推断成功或虚构开始时间。
- `assistant/inspect`：可见业务工具行从 ledger 读取目标与详情；控制工具仅在展开时读取控制事件，不为账本缺项扫描全部事件。
  查询在父视图渲染结束后启动；工具事实或会话代次变化使旧查询失效，终态按需重新读取，读取前后校验 Application 会话，回执核对会话/项目/代次。
  展开、查询、重试、复制反馈及技术详情缓存由可见卡片拥有，隐藏后释放；渲染与全局时钟刷新不重复查询。
  `inspect/render` 在对话内展示本地化参数、失败明细、目标、资源/结果与时长；失败码在详情收起时仍可见，详情失败可原位重试。
  复用 Harness Contract 的 `AssistantToolInspection`，参数不复制原请求中的凭据、数据行、正文和内部版本；完整安全投影（含工具输出）只在展开技术详情或复制时序列化，支持分别复制参数和完整详情。
  目标只按当前资源目录中的唯一身份解析，打开复用原工作台入口；目录更新直接接纳，不猜测资源类型。来源片段仍由 `assistant/sources` 按需呈现。
- `workbench/assistant`：独立读取 Rust Assistant Activity 文档并交给共用 ActivityPanel，新建/重命名后重读原目录，
  不从操作回执拼接列表、不为目录订阅完整历史。首次打开立即显示待加载面板并完成面板显示的 UI intent；
  后台挂载保留原侧栏选择，异步读取完成只替换目录内容。原查询负责代次与刷新合并，失败由目录提供重试。
  窗口重新激活重读原目录；会话操作完成使操作前的读取代次失效，再查询当前目录，迟到结果不能恢复旧标题。
  会话缓存只按 ID 查找和保留暂态输入，不持有布局拓扑；
  从目录激活当前可见会话会关闭该面板，草稿与订阅留在同一缓存；重开仍通过原 Application 校验并更新最近打开时间，再复用原面板。
  当前会话从根 DockArea 的活动面板读取，图选择和资源打开只更新项目/节点侧栏，不覆盖会话高亮；关闭不取消运行，项目替换释放旧缓存。
  `assistant/navigation` 由底栏会话开关调用：关闭时从根 DockArea 移除全部会话面板，保留原缓存草稿并记录最后查看的会话 ID。
  重开先沿原查询获取新目录，优先恢复仍在目录中的上次会话，其次打开最近会话，仅空目录才新建；成功打开清除恢复提示。
  恢复提示不保存布局或目录，项目操作开始即清除提示和待打开请求，并使旧目录读取失效；失败保留原项目时重新启用目录查询。
  读取或打开失败显示原助手目录及重试入口；待打开请求和已有会话操作共用忙碌保护。无项目时底栏继续打开临时会话目录。
  `assistant/renaming` 捕获会话 ID 与宿主生命周期，使用共享名称表单提交原 Application 重命名。运行中、失效会话与非法名称保留本地化失败和草稿，成功才更新缓存元信息并关闭。
  项目内当前使用中心标签，无项目时在原生弹层呈现同一个根 DockArea；布局恢复校验持久 session 的项目归属。
  独立 AI 分组、缓存释放和跨重启草稿保存仍待完善，不能以当前基本界面代替这些生命周期验收。
- `main`：命令行参数、执行器、原生资源、窗口及快捷键；执行器存活到窗口循环结束。

  `navigation` 用原行 ID 持有键盘焦点，与当前资源高亮分离；上/下、Home/End 定位并滚动，Enter/空格调用原展开、打开或文档预览入口。

- `workbench/details`：协调当前图的选择、版本与属性表单；参数分组、条件字段及选项来自原编辑器投影。

  渲染借用当前节点投影，名称等显示片段按需取得；资源分支只委派给实际存活的编辑器，没有目标时复用通用未选择提示。

- `workbench/details/diagnostics`：读取当前节点的原始诊断，复用 `text::graph_diagnostic` 格式化；按后端 severity 显示图标、颜色及标签。
  位置显示节点、参数、端口或连线两端名称；参数行提示仍保留，诊断区默认展开且无诊断时隐藏。
  每页最多 50 条，跨页列表在有界区域滚动；同一节点投影或语言刷新保留展开和有效页码，切换节点重置。
  分页与折叠回调受选择代次约束；不再分析图或维护一份诊断事实。
- `workbench/parameters`：节点属性与创建前配置共用参数草稿、分组布局和编辑控件；表单只发出键/值意图，
  Details 提交原图参数事务，创建视图调用原只读表单查询。宿主动态检查目标与忙碌状态，表单代次拒绝旧菜单和旧控件。
  同值投影与语言变化复用输入；本地编辑标记使创建可以接纳尚未应用的输入，同时保留未修改默认值的隐式语义。
- `workbench/parameters/field`：复用稳定 ParameterKey 的草稿与原 Input 事件；单行和列表 Enter 调用同一应用入口，
  失焦不隐式提交，多行换行保留为输入。Escape 或恢复按钮放弃当前字段草稿，默认值按钮先放弃输入再提交原重置事务。
  忙碌或失效控件不提交，重复相同非 Null 值不创建请求；解析失败保留输入，继续编辑清除本地错误。
  `field/choices` 按打开时生成选项并使用原翻译键；常量名称借用 GraphProperties，读取期间禁用选择。
  `field/list` 每页 50 行，按访问页创建输入；排序、分页及增删保留同一草稿，应用时完整解析，整数不经过 f64。
  `field/render` 按当前节点与参数键展示原诊断，复用 Problems 文案格式化；不在视图重做图分析。

- `workbench/parameters/domain`：编码/标签映射使用同一份有序草稿，每页 50 行且滚动区域有界；

  正值随选中行的编码变化和排序移动，删除该行后清空；`domain/positive` 打开菜单时才读取选项，标签优先、编码次之、空编码显示 `∅`。

- `canvas/ports/input/commit` 与 `canvas/commands/worker`：将控件输入接入现有图命令，不建立图草稿或另一份历史。
  指针手势期间延后失焦提交，结束时先提交输入，再执行连线/节点移动等命令；保存及运行也先应用待提交输入。
  每一步只使用上一步实际回执的版本，新操作使用独立 OperationId，外部修改仍由 Application 拒绝。
  多步调用不冒充原子事务：失败时安装最后一次成功回执，只确认已完成的字段；未完成输入继续保留。
  节点/端口/连线菜单与节点选择器等待同一提交任务及在途投影刷新完成，再核对版本、焦点和手势后打开；使用实体通知，不轮询。
  输入计入原保存/关闭检查，普通编辑与运行不隐式保存。控件阻止指针和滚轮冒泡，文本选择不启动画布拖动。
- `canvas/ports/menu`：端口右键使用共享 PopupMenu，不改变节点选择或启动画布平移；断开按原端口连接数量启用。
  重置只清除精确数值/布尔/文本输入的显式字面量，类型能力与 Details 共用，协议默认值和连接保持由原编辑事务处理。
- `canvas/ports/inspection`：输出端口与已连接输入提供查看入口，输入按原连线顺序查询上游输出；查看只查询，不触发运行。
  显式“查看上次成功结果”从匹配语义身份的 stale 摘要捕获完整结果引用，不重新绑定为当前输出。
  worker 校验项目、编辑版本和执行会话，取得 Application 自动租约后交给现有结果标签；画布复用可取消读取任务，
  新交互、隐藏和投影刷新拒绝迟到交付。相同引用复用原标签，新标签取得自己的租约后释放交接持有。
- `canvas/connections`：从当前投影一次派生端口锚点及连线端点，投影替换时重建，不拥有图编辑状态。
  `connections/curve` 为描边、命中、裁剪和运行标记共用一条带方向的三次曲线，输入侧向左出线。
  绘制按控制点包围盒裁剪屏幕外连线，保留端点都在屏幕外但穿过视口的曲线；
  复用现有 PathCache，平移只移动缓存路径，相对几何、方向或描边样式变化才重新细分。
  拖动只叠加暂态位置，网格按尺寸、间距和偏移相位缓存；连接候选按端口索引查询。
  连线从共享 presentation 读取外观：阻断诊断/孤立端口/当前运行失败、目标参与运行、后端缓存状态依次决定线条。
  未运行、过期和错误使用不同虚线，可用结果使用实线；`canvas/ports` 让端口与连线共用当前深色画布的语义类型配色。
  `connections/render` 用 GPUI Animation 在静态曲线上移动标记，仅可见运行连线挂载动画，遵循 reduced motion；动画不重新细分路径。
  `connections/drag` 让手势持有候选查询及捕获版本，取消或替换手势释放交付任务；旧查询不能覆盖新手势。
  端口起手遵循投影的 append/replace/move 能力及 orphan 标识；候选返回后仅淡化所有端口均无效的节点，来源节点保持可见。
  悬停端口复用 GPUI 命中，预览吸附当前目标并显示追加/替换/无效颜色与本地化原因，被替换连线单独突出。
  松键按捕获版本提交原 Connect/MoveConnections；候选失败或已知无效不提交，候选未返回时由原后端事务校验。
  空白松键后的节点菜单沿用同一方向曲线，预览只读取仍匹配当前图和版本的菜单来源。
  `connections/hit` 先检查控制点包围盒，再复用 GPUI 对同一曲线的 12px 描边网格命中；只为包围盒命中的曲线建立网格，平移不重新细分。
  `connections/interaction` 保留画布的连线选择与悬停，诊断定位复用同一选择集合；节点覆盖连线，拖动期间不拾取连线。
  单击选择，Ctrl/Cmd/Shift 切换多选；右键保留当前连线组或改选目标，原生 PopupMenu 提供断开与删除，Delete 也走同一图事务。
  `canvas/menu` 为节点、端口和连线共用 PopupMenu 的定位、释放及焦点恢复；动作核对菜单实体、投影、编辑版本与语言。
  切换标签、刷新或提交关闭旧菜单，旧回调不能操作新投影。
  菜单释放时仅在焦点仍属于该菜单时恢复画布焦点，用户已转移的焦点保持不变。
  双击通过原 InsertReroute 事务插入转接点，失败只在选择仍未改变时恢复单击前的选择；框选取消同样恢复原节点与连线选择，Escape 不清除静态选择。
  框选只在选中集合改变时发布选择，Output 订阅投影和执行事件，避免随画布指针移动刷新。
- `canvas/toolbar`：画布之外的固定操作栏，常用动作使用带提示的图标，局部运行和刷新放入更多菜单。
  指针交互 bounds 只覆盖画布，工具栏不会遮挡节点或触发选择/平移；菜单动作绑定对应画布焦点。
- `canvas/catalog`：打开节点菜单并接收其创建意图；连接候选查询归当前连接手势，兼容节点查询归菜单实体。
- `canvas/palette`：一次打开对应一个暂态实体，拥有搜索输入、分类展开、活动项和可选创建表单。
  `browser` 只保留 Application 行索引，查询/目录/展开变化时重建可见项；`render` 用 GPUI `uniform_list` 只构造可见行。
  检索复用 Catalog 的标题、别名、技术术语、资源名、类型 ID、全拼及首字母文本；搜索期间展开祖先分类，清空查询恢复原折叠状态。
  方向键只选择可用节点并滚动到当前项，Enter 使用原创建描述；输入法组合期间不处理选择或创建。不可用项保留显示并禁用创建。
  `query` 复用普通目录快照或读取兼容目录，保留加载/失败/重试状态；任务按实体、读取代次、语言和图身份/版本接纳，关闭后不交付。
  语言变化保留查询及配置草稿，目录更新重新筛选当前描述。项目或图版本变化阻止旧菜单提交。
  默认快速创建；勾选“创建前配置”复用 `node_creation`，返回保留查询与开关。快速/配置创建共用原图事务，成功关闭菜单并恢复画布焦点，失败保留输入。
- `workbench/node_creation`：复用 Application 的 `node_creation_form` 与共享参数表单；只保存当前未提交值、端口数量和读取代次。
  条件字段与默认值归后端，预览不创建图节点或历史。固定端口只读，派生端口标为自动；成员组仅显示一项数量并提交全部成员。
  `query` 串行校验当前修改，创建前接纳未应用输入并再次校验；`ports` 保留独立数量输入和范围错误，`render` 负责有界滚动与返回/重试/创建。
  语言切换沿用正在校验的值并保留草稿，标题随同一节点目录更新；项目/图版本变化阻止旧表单提交，迟到读取不能恢复已关闭表单。
  成功后由原 Canvas 图事务一次创建节点及可选连接，失败保留表单重试；未显式保存时不写图正文。
- `canvas/commands`：提交现有 Application 图用例，接收完整投影、历史能力和 dirty 状态；
  编辑期间仅保存暂态位置，松键才提交，预览保持到回执返回。
- `canvas/authoring`：签名提交保留原始 before-state 与版本，常量输入在 worker 中解析后进入原编辑事务。
  `canvas/constant_drag` 只持有拖动预览和捕获的图身份；画布接收时拒绝跨图拖动及过期版本。
- `constant_values`：原生常量输入与普通 JSON 的边界适配，不改变 DataValue 的持久化契约。
  复用 serde_json RawValue 与 bigdecimal，保留嵌套整数、小数和指数输入的精确值，不经过 f64；数组/对象不显示 Rust 枚举标签。
  输入转换限制嵌套深度为 128，并在展开指数前检查 65,536 位数字预算；类型、名称、事务、历史和保存仍由原业务 owner 校验。
- `canvas/execution`：捕获与当前编辑投影匹配的后端文档，将同一不可变 `Arc` 直接交给 RunGraphRequest；公共图活动拥有运行事实，
  命令拒绝仅为本地反馈。原生运行读投影按执行会话与 RunId 安装，恢复期间有界暂存通知后重放。
  单节点可选择当前输入或补算依赖，取消复用完整运行身份；退出时请求取消仍在运行的计算。
- `workbench/problems`：只持有当前活动图的 canonical diagnostics 投影；固定标题栏显示总数，区分未打开图与没有问题。
  变高虚拟列表只构造可见行，按后端 severity 呈现图标/颜色，blocking 独立显示；展示代码、消息、位置及关联跳转，不提供手动清空。
  同一投影的选择通知不重建列表；投影或语言替换使行高缓存失效，图切换重置滚动。
  `problems/location` 与 Details 复用节点、参数、端口和连线名称；`problems/navigation` 核验原投影与当前可见编辑器，拒绝过期点击和迟到定位。
  定位等 Dock 展开后的布局绘制，再由 `canvas/navigation` 调整视口与暂态选择：图适应全部节点，端口聚焦对应行，连线高亮并显示两端，Delete 通过原图事务断开。
  参数定位显示 Details，`parameters/reveal` 按字段身份滚动并聚焦现有控件；表单代次与新用户焦点取消迟到请求，不重建输入或提交草稿。
  已知资源复用 `resources/navigation` 的正常打开路径，该入口也供 Assistant 引用使用；缺失资源仍显示身份，不猜测路径或创建资源。
- `workbench/output`：借用当前图语义与执行会话匹配的原运行事件；固定工具栏显示运行状态，清除按钮只在有失败时可用。
  `output/failure` 展示本地化原因、阶段、RunId、稳定错误码及外层到内层分组上下文，空输入单独标为结构探测；
  节点链接使用原 PlanSourceIdentity 的实际图与节点，操作前重验当前失败身份。无图与当前图无失败使用不同提示。
  清除绑定渲染时的完整 RunIdentity，只隐藏该次失败；下一次请求立即隐藏旧失败，不删除 Rust 终态。
  运行 sink 确认 Application 已发布终态后不再重复显示通用命令错误；仍显示同一执行会话和语义图时，失败回执打开 Output，后台图不抢占其他编辑器。
  启动前拒绝沿用 Canvas 本地反馈；原生 RunFailure 没有 IPC 诊断编号，不补造字段。
  执行事件只在结果版本领先当前图投影时请求刷新，恢复相同快照不会形成图刷新与执行恢复循环。
  切换到其他资源或结果标签清除图上下文，Logs、Problems 与 Output 保留各自数据入口。
- `workbench/results`：从当前图的 GraphResultState 和运行投影派生结果目录，区分上次过期结果与等待同步的输出；
  按完整结果引用打开原生结果标签，并支持现有 OpenResult UI intent。
- `workbench/results/window`：结果标签工具栏可在独立原生窗口打开相同结果；窗口复用 ResultPanel、Root 与 window_chrome，
  分页、报告、图形与失败重试仍走原读取。每个窗口创建自己的控件、输入和展示状态，不跨窗口共享带焦点的实体。
  创建和激活延后至原窗口更新结束，排队的重复请求按目标窗口当前结果引用聚焦；报告追加后直接读取面板的新引用，
  窗口登记仅保存原生句柄和面板弱引用，不参与根 DockArea 拓扑，也不保存第二份结果索引。
  交接期间临时共享原 Application 自动租约，新窗口在 worker 取得自己的租约后释放交接持有；关闭来源标签不会使交接结果提前回收。
  关闭窗口使用与标签相同的幂等释放入口，取消交付和报告追加；项目实际替换、执行会话变化及主工作台关闭均清理对应窗口。
  原会话租约继续由 Application 释放；普通图重跑不替换窗口快照，窗口不创建 Tauri 路由、IPC 协议或另一个结果 store。
- `results/reading`：结果面板的初次读取与分页交付；只有成功回执更新显示的页与表标识。
  失败保留原页和原表/偏移的重试目标，返回概览或关闭会拒收旧分页。`render` 和 `toolbar` 只负责内容、失败反馈与控制，
  显示范围和页码取自已接纳页，未知总数采用原 `has_more`；空页统一显示 0 行。语言切换不重新查询或清空展开状态。
  新交接租约可替换尚未取得租约的首次读取，沿用原代次拒绝旧交付；已加载面板和分页继续使用原结果。
- `results/query`：在 blocking worker 内申请并持有原 Application 租约、读取投影或每页 100 行数据。
  失败、取消和实际关闭释放 Application 的自动租约；常规面板释放在 worker 调度，避免回收大结果阻塞界面。
  面板拖动重挂载保留同一租约。普通重跑不替换已打开的结果。
- `results/plot`：worker 将 Application 完整结果投影一次转换为共享图形几何；面板只持有原结果租约、不可变图形和显示开关。
  当前绘制全部二十类 PlotData 结果：九类基础图形，以及相关矩阵、ACF/PACF、箱线/小提琴、误差线/系数、热力、列线图、帕累托、组合与词云。
  `information` 读取原观测/抽样数量、置信水平与预测时点；`render` 负责显示和局部翻页，范围在 worker 准备，词云像素排布在原生字体可用时缓存。
  普通折线的工具栏可展开并切换数据点；ROC 不显示点开关。切换不读取、重新解析或执行结果，语言/主题改变不重置开关。
  载荷无效显示图形格式错误；线性报告的分析和独立图形窗口复用同一绘制。
- `results/report`：结构化统计结果提供默认数值视图与报告视图切换，同一面板租约和报告实体保留折叠、页码及表格状态。
  Application 在 worker 校验原 `report_display`，声明无效仍保留结构化原值；无声明时直接展示原值。
  `section` 复用 Collapsible，首次展开才创建子内容；方程按原纯文本显示并支持复制，不把变量名当 Markdown/LaTeX。
  `page` 继续按原 ResultTablePart 每页 100 行读取；诊断内联数组共用分页和虚拟表格，只创建当前页内容。
  标量或标量记录使用共享虚拟表格，远端嵌套数组按绝对路径继续展开；已截取的页不递归创建分页器。
  普通记录页的列并集超过 64 列时保留折叠字段，避免异构记录膨胀为大量空单元格；声明表格继续受后端 32 列上限约束。
  失败保留已显示页面与范围并提供原请求重试；切换模式/折叠不释放结果，实际关闭释放子实体、交付任务和原租约。
  `plots/stability` 复用共享坐标轴和悬浮，按等比例实部/虚部绘制原根与单位圆；超过一页明确说明只显示当前页。
  当前页绘图范围只是像素映射，根和模值保持后端值；UI 不补算统计量。
- `results/report/linear`：保留 Application 的类型化报告投影，方程、系数表和系数大小图共享一份 200 项系数页；
  首次进入报告才读取，失败保留原页并重试原请求，数值/报告切换不重建实体。系数图保留正负方向与原显著性标记，
  表格显示原系数、标准误、t/p、置信区间及显著性，星号仅格式化原 p 值。模型摘要、ANOVA 和条件数复用原展示投影。
  `linear/equation` 使用原生文本展示符号式/展开式与变量映射，支持水平滚动和复制；变量名称保持文字语义，
  截距来自模型标记和首项位置，不按名称判断。只显示不超过 200 项的完整方程，较大模型明确提示查看系数页。
  `display` 集中数值展示，微小非零数用科学记数法，整数保持精确；语言变化从已接纳数据重建标题，不重读统计结果。
  观测值沿用共享报告页和首次展开加载，每页 100 行、保留后端观测序号。
- `results/report/analysis`：选中的诊断、ACF/PACF、序列及假设检验在章节首次展开时读取原 `analyze_result`，
  后台只转换原值与绘制坐标；折叠和模式切换保留已接纳数据，失败提供原请求重试。诊断分别保留不可用原因，
  其原始数组按 100 行分页；杠杆值密度沿用后端点并从零绘制横轴。ACF 从滞后 0、PACF 从 1 开始，置信带保留原值。
  检验卡片显示原统计量、概率和自由度，H₀/H₁ 保留原文本及复制，不通过变量名替换生成公式。
- `results/report/residual`：拥有未提交的有限范围和高亮比例输入，明确应用后请求最多 2000 点；
  模式切换清空范围，重置范围保留高亮比例，相同已接纳选择复用现有图形。Application 拥有筛选、抽样及全样本排名，
  共享 `plots/cartesian` 只绘制对称残差轴、零线和原高亮，悬浮保留原观测编号；分别显示抽样、匹配与总量。
  单次读取期间禁用提交，失败保留旧图及其轴含义；子实体不另持有租约，随原结果面板关闭释放交付任务。
- `results/report/addition`：只拥有当前报告中未包含内容的选择、滞后阶数、BG 选项和假设输入；
  1–40 阶与 4096 字节假设限制由 Application 命令校验，长参数目录在有界区域滚动，语言变化保留输入。
  `results/addition` 在 worker 调用原生报告用例并准备数值概览，计算期间保留原报告，失败保留表单并显示可重试原因。
  完整读取后由 Application 复核版本，才更新同一面板的结果、租约及数值/报告内容，终止旧分页交付。
  工作台同步结果引用索引，拖动和重新打开定位新引用；关闭或项目切换取消交付，迟到结果自动释放。
- `results/table`：普通数据页显示固定行号和原列类型；`cell` 一次格式化有界值，`render` 复用共享文本，
  绘制数值对齐、只读布尔、空值与完整提示。嵌套列表/记录保留为一个单元格，不由首行猜列；紧凑报告表不增加行号或类型标记。
  列可调宽但不移动，分页仍只持有当前页。空数据页保留列定义与明确空状态。
- `results/value`：概览与按需展开字段；结构化报告的数组只展示后端数据引用，
  点击后按原 ResultTablePart 读取有界页。标量保留空值、布尔值与宽整数，前端不计算统计量。
  线性模型和报告的普通 JSON 元数据复用 Node Kernel 的运行值转换，字段树与表引用保留原结构。
- `workbench/logs`：LogsPanel 持有最多 1,000 条已提交记录的只读投影、筛选输入和原生滚动句柄，日志事实仍归中立 LogRuntime。
  `stream` 调度有界订阅、快照交付和释放；缺口、流替换与慢消费最多连续恢复三次，收到新批次后重置预算，
  存储失败停止交付，手动刷新重新读取 recent snapshot。清空只清显示并保留序列水位，不删除持久记录。
  `entry` 缓存显示文本并按需准备搜索文本，同流快照按原 sequence 复用不可变记录；`filter` 只保存记录索引，
  追加批次仅筛选新增记录，前缀裁剪同步调整索引和视口。领域、五种级别与搜索变化才重新筛选有界集合，计数与列表共用结果。
  `toolbar` 复用原生 Input、Button 和 PopupMenu；搜索覆盖消息、来源、领域、origin、target、event 与结构化字段。
  `render` 只创建可见行，显示领域、来源、级别、计数、连接和截断提示；语言变化更新提示而保留输入与筛选。
  自动滚动仅在已停留底部时跟随新记录；浏览旧记录期间保持视口，重新启用或手动刷新可回到底部。
  `logs/selection` 以 stream/sequence 记录身份选择并显示已有 Details，保留列表键盘焦点；上下键、Home/End、Enter 与 Escape
  只作用于列表本身，不拦截搜索或详情输入。选择旧行不会读取历史或变更图；右键可复制原消息或完整 JSON 记录。
  `logs/details` 只为当前选中的记录创建只读 Input/Textarea 和默认展开的消息/字段区，原始文本不经过 Markdown 解析。
  同一记录复用控件与折叠状态，筛选、刷新和缓冲裁剪保留该不可变检查快照；最多额外持有一条已退出缓冲的选中记录。
  清空显示或 Escape 释放选择，只有仍指向该实体的 Details 才取消日志检查，不清除后来选择的资源或节点。
  字段标签与领域随语言更新，协议值、JSON、文本选择和其他折叠状态保持；复制直接使用原记录或只读正文。
- `services/paths`：保持应用标识和各平台数据/日志目录约定；`YSSBI_APP_DATA_DIR` 可指定绝对路径，
  用于隔离迁移验收的项目注册、Harness、模型设置、插件状态和日志；示例优先使用可执行文件旁的 resources/samples。
- `text`：原生 UI 本地化；assets 中的中文资源取自现有桌面文案，图诊断直接读取 Rust 的原始模板定义，
  校验 code/message key 及所需参数后一次替换。未知模板或缺失参数显示通用提示，不展示原始模板键；
  Problems 按后端 severity 呈现图标和颜色，blocking 仍由后端独立决定。

依赖方向为原生宿主 → Application/共享投影与协议。Application/Project/Graph 不依赖 GPUI。
Project 是 GraphDocument、历史和保存身份的唯一 authority；没有原生图草稿、UI 历史或格式转换。

Details 参数输入是未提交暂态；应用参数只提交变更键，由原 Graph Editor 在匹配版本的事务内合并其他参数。
