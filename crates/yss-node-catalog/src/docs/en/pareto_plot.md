# Pareto Chart

Categories takes a Text series, one category occurrence per row. Empty or missing categories are rejected.

Bars are sorted by descending frequency, with label order breaking ties. The line shows cumulative frequency share on a right-hand 0–100% axis. Counts and cumulative shares use the complete sample.

Open the result output in a workbench result panel or a separate Plot window.

All categories or coefficients are retained in the result. The chart displays 100 entries per page; use Previous and Next to inspect all entries. Cumulative shares always use the complete sample.
