# Violin Plot

Add 1–64 Numeric series with at least two finite observations per group. Groups may have different lengths. Missing values are rejected.

Each group uses a Gaussian KDE with Silverman bandwidth on 128 grid points. The mirrored outline includes the median and interquartile range. KDE uses the complete group sample; width represents within-group density rather than group size.

Open the result output in a workbench result panel or a separate Plot window.
