# ISM 解释结构模型

将 0/1 邻接方阵按列连接到 **criteria**。A(i,j) = 1 表示行 i 指向列 j，
行列须按同一要素顺序。对角线可为 0 或 1；可达关系会包含要素自身。
缺失和非有限数值会报错。

先求完整传递闭包，再将相互可达的要素归为强连通分量。
第 1 层为没有指向其他剩余分量的结果层；逐层移除后得到编号更大的原因层。
环内要素保留在同一层，不遗漏无法按单向关系拆开的要素。

**result** 输出层次和强连通分量。
**indices** 输出要素位置、层号、驱动力与依赖度（均包含自身可达关系）。
**relations** 按来源、目标位置输出完整的 0/1 可达矩阵，可分页查看。
同一层也可能含有互不连接的独立分量。
