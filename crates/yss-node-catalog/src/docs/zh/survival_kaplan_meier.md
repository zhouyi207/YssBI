# Kaplan–Meier 生存估计

连接逐行对齐的 `time` 与 `event` 数列。时间必须有限且严格大于 0，单位保持一致；`event=1`（或 true）表示事件发生，`0`（或 false）表示右删失。缺失值会导致计算失败，不自动删行。假设在给定模型或分组条件下删失独立于事件过程；输入须等长并按当前位置逐项对应，可混合数据库与内存数列。

可选的 `groups` 端口最多连接一个分组数列；省略时计算总体曲线。文本、分类、有序、二元及精确数值标签会保留。此节点无参数，输入不需要预先按时间排序。

## 估计与输出

在不同的观测时点 $t_j$，令 $r_j$ 为风险集人数、$d_j$ 为事件数。同一时点先计事件，再移除删失：
$$\widehat S(t)=\prod_{t_j\le t}(1-d_j/r_j).$$
`result.curves` 包含分组标签、样本量、事件总数、中位生存时间以及所有观测时点（含仅删失的时点）。每个点记录时间、风险集人数、事件数、删失数、生存概率、估计值、标准误及 95% 区间。`estimate` 为生存概率；`cumulative_hazard` 为 Nelson–Aalen 累积和，并非生存概率的负对数。

Greenwood 方差为 $\widehat S(t)^2\sum d_j/[r_j(r_j-d_j)]$，区间使用 log-log 变换。生存概率为 1 或 0 时，区间分别记为 [1,1] 或 [0,0]。中位生存时间取首次生存概率不大于 0.5 的观测时点；未达到时返回 null。全部删失时曲线保持 1，中位数为空。节点不计算组间比较的 p 值，组间比较请使用 Log-rank。

适用于独立个体的右删失数据，不含延迟入组、区间删失或权重。
