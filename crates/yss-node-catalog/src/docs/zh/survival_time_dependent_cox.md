# 时变 Cox 回归

连接 `start`、`stop`、`event`、个体标识 `subjects` 及一个或多个数值 `X₁, X₂, …`。每行表示协变量保持不变的一个时间区间。要求时间有限、$0\le start<stop$；事件状态为 0/1（或 false/true），指区间终点发生事件。行可乱序，个体标签支持精确数值、文本、分类、有序或二元值。

同一个体区间不能重叠，允许首尾相接；间隙表示不在观测中。每个个体最多发生一次终末事件，且只能出现在最后一个区间，不接受事件后的记录。

## 风险集与模型

$$ h_i(t)=h_0(t)\exp[x_i(t)^\top\beta],\qquad
R(t)=\{i:start_i<t\le stop_i\}.$$
左开右闭约定避免在相邻区间边界重复计入风险集。`survival_ties=efron`（默认）或 `breslow` 控制并列事件处理。模型不拟合截距。`max_iterations=500`，要求正整数；`tolerance=0.0000001`，范围为 1e-12 至 0.01。未收敛或信息矩阵奇异时返回错误。自变量必须有限且模型可识别；分类自变量须预先编码为哑变量。

`result` 返回系数、危险比、协方差、逐区间中心化线性预测量、Breslow 基线、偏对数似然和迭代数。`observations` 是区间行数而非个体数；`events` 为终末事件数。基线参考点是区间行的协变量均值。系数检验为 $H_0:\beta_j=0$ 对 $H_1:\beta_j\ne0$，$z=\widehat\beta_j/SE$ 使用标准正态参考分布；95% 系数区间取指数得到危险比区间。

该计数过程形式在比例风险及独立删失假设下支持延迟入组与时变协变量，不包含复发事件或个体聚类稳健协方差。由于未提供未来协变量路径，不输出未来事件概率，也不作为列线图的模型输入。
