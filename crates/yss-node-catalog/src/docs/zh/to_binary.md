# 转二元

将输入标量或数列转换为 Binary。标量输出仍为标量，数列输出保持原有行顺序和对齐。

## 参数

**取值映射**默认为空配置。可配置两个不同原始编码及其正值：正值转为 true，另一个值转为 false。

## 转换规则

没有显式映射时，接受已有布尔值、数值 0/1，以及区分大小写的文本 `true`、`false`、`0`、`1`。已有 Binary 输入按其声明的两值域与正值映射解释；非布尔物理表示的 Binary 输入必须声明正值。

空值保持为空值，不自动转为 false。映射以外的取值和非法值域会失败。输出可继续连接 AND、OR、NOT 等逻辑节点。

## 输出与执行

输出语义固定为 Binary。内存中的输入立即转换；惰性数列在消费时校验实际取值。本节点生成派生结果，不修改源数据集。
