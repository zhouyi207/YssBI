# 题项分析（区分度）

连接至少两个对齐的数值**题项（items）**，每行是一位答题者。
请先处理反向题；缺失值和非有限分值会报错。

**tail_fraction** 默认 0.27，须大于 0 且小于 0.5。
以总分的 p 和 1−p 分位数（type-7 插值）划分低分组与高分组。
两个分界不同时，边界并列总分纳入对应组；分界相同时，只有严格小于或大于分界的观测进入两端组，边界并列值留在中间组。
同一行不会同时进入两组。

**result** 报告分界、实际组人数和共用的信度摘要。
**item_statistics** 包含校正题总相关、删除题项后的 α、两组均值及双侧 Welch t 检验（高分减低分）。
每组至少两人且标准误为正才计算检验，否则相应字段为空。
按总分选出的两端组比较属于题项筛查，不能当作独立的验证性证据或因果效应。

**scores** 保留全部行，包含观测序号、总分、分组编号（−1 低分、0 中间、1 高分）。
不设固定行数上限，执行受内存、取消与期限控制。
