# IV LIML Fit

连接一个因变量、可选的有序外生自变量、一个或多个内生变量，以及一个或多个排除工具变量。各列须对齐、等长且数值有限；常数项由参数控制，不要自行添加。

默认包含截距，协方差默认为 nonrobust（也可选 HC0–HC3），`small` 默认为 false。系数概率及 95% 区间默认采用正态参考分布；`small=true` 应用小样本协方差修正，并采用自由度为 `n-k` 的 Student-t，其中 `n` 为观测数，`k` 包含估计的截距。整体系数检验默认采用卡方，`small=true` 时采用 F，参考分布和自由度保存在 `statistics.modelTest` 中。无法识别、秩不足或系数推断未定义时明确报错。

模型记录 $R^2=1-\mathrm{RSS}/\mathrm{TSS}$ 和 $\bar R^2=1-(1-R^2)(n-c)/(n-k)$；含截距时 $c=1$，否则 $c=0$。RSS 使用结构残差；含截距时 TSS 使用中心化观测的平方和，无截距时使用观测平方和。IV 的负 R² 是合法结果。响应单位变化保留这些比值，总变异未定义时拟合失败。

输出 model、fitted 和结构残差 residuals。模型保留系数、推断统计、kappa 及拟合设计。连接 IV LIML Summary，可选择第一阶段或过度识别分析，这些分析仅在选中后计算。拟合值使用观测到的内生变量。
