# P-P/Q-Q 图

Values 接收至少两个有限 Numeric 观测。参考分布为正态分布；默认 Q-Q 图并从样本估计均值与样本标准差。关闭估计后使用 Reference mean（默认 0）和 Reference standard deviation（默认 1，必须为正）。

排序后第 $i$ 个观测的绘图位置为 $p_i=(i-0.5)/n$，$i=1,\ldots,n$。Q-Q 比较 $F^{-1}(p_i)$ 与样本分位数；P-P 比较 $F(x_{(i)})$ 与 $p_i$。参考线为 $y=x$。估计参考参数时常量样本无法使用；最多展示 2048 点。

结果从输出端口打开，在工作台结果面板或独立绘图窗口中查看。
