# 内容效度（专家 CVI）

每列连接一个数值**题项（items）**，每行是一位专家，各列须对齐。
相关性评分使用整数 1、2、3、4，其中 3、4 分视为相关。
其他评分量表应先明确重编码；缺失值和非有限数值会报错。

**item_statistics** 输出相关专家数 A、I-CVI = A/N、随机一致概率
Pc = 二项分布 Binomial(N, 0.5) 在 A 处的概率，以及修正 kappa = (I-CVI − Pc)/(1 − Pc)。
随机一致概率使用稳定分布计算，专家数较多时不会因直接计算阶乘而溢出。

**result** 输出 I-CVI 的平均值 S-CVI/Ave，以及全部专家均认为相关的题项占比 S-CVI/UA。
两者含义不同，节点不自动判定“通过”或“不通过”。专家相关性证据不等于量表内部结构的证据。
使用全部专家和题项，受执行资源预算控制。
