# McNemar 配对二分类检验

检验同一批对象在两次测量下的成功概率是否相同。

## 输入与参数

`before`、`after` 输入数值 `0/1` 序列，按对象逐项对齐，长度相等且非空。`1` 的含义必须在两次测量中一致；先共同处理缺失值。无配置参数。

至少需要一个不一致配对：`0→1` 或 `1→0`。若所有配对一致，节点不返回检验结果。

## 假设与统计量

$H_0$：两次测量的边际成功概率相等，即两类不一致配对等可能；$H_1$：边际成功概率不同。令 $b$ 为 `0→1` 数量，$c$ 为 `1→0` 数量，$D=b+c$：

$$
X^2=\frac{(b-c)^2}{b+c},\qquad B\mid D\overset{H_0}{\sim}\operatorname{Binomial}(D,1/2),
$$

$$
p=\min\{1,\;2P(B\le\min(b,c))\}.
$$

显示的 $X^2$ 对应渐近 $\chi^2_1$ 统计量，但报告 p 值采用上面的精确二项法。不同对象应独立，同一对象的两次测量保留配对关系。

## 输出与判读

`result` 为结构化结果。`statistic` 为 $X^2$，自由度字段为 `[1]`；`p_value` 与 `details.exact_binomial_p_value` 是精确 p 值。`details.discordant_0_to_1`、`details.discordant_1_to_0` 分别给出 $b,c$，`sample_sizes` 为总配对数。估计值和标准误为空。

$p<\alpha$ 时拒绝边际概率相等；检验只利用不一致配对的信息。
