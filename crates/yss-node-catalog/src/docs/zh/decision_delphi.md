# 德尔菲法（单轮汇总）

**criteria** 每列一个评分指标，每行一位专家，列之间须对齐。
**full_score** 指定量表满分，默认 5；评分须有限且不超过该值，缺失数据会报错。

**items** 输出各指标的均值、样本标准差（分母 n−1）、
变异系数 CV = 标准差/|均值|、type-7 四分位数、中位数、最小值、最大值与满分百分比。
均值为零时 CV 为空，只有一位专家时标准差与 CV 均为空。
满分频率按设定的量表满分计算，不使用样本中碰巧出现的最高分。

**result** 输出专家数、指标数，以及校正并列的 Kendall W 和卡方近似检验。
不足两位专家或两个指标、或所有专家都未区分指标时，W 为空并说明原因。
协调系数结果中的 observations 指指标数，raters 指专家数。

本节点汇总一轮数据。专家选择、匿名反馈、多轮征询和指标去留仍由研究者组织判断。
