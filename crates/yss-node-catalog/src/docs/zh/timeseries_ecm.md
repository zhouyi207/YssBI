# ECM 误差修正模型

对数值 `series` 与一个或多个对齐的 `X₁, X₂, …` 拟合两步单方程 ECM。输入须等间隔、按时间排列、全部有限且无缺失；不设固定行数或自变量数上限。

`ts_lags=0` 为非负整数的滞后差分阶数；`constant=true` 在两个回归中加入截距。滞后后的设计矩阵须列满秩并保留正残差自由度。

$$
y_t=c+\beta' x_t+u_t,\qquad
\Delta y_t=a+\lambda\widehat u_{t-1}+\sum_{j=1}^{L}\psi_j\Delta y_{t-j}+\sum_{j=0}^{L}\delta_j'\Delta x_{t-j}+e_t.
$$

$L$ 即 `ts_lags`，两步均使用 OLS。`long_run` 为水平方程，`long_run.residuals` 为与输入行对齐的完整均衡误差序列；`short_run` 包含差分方程、具名系数、拟合值、残差及条件 OLS 推断。`first_short_run_row=L+1` 是短期方程第一条观测对应的原始行位置，从 0 开始。

调整系数 $\lambda$ 为负与向均衡修正相符，但仍需结合完整滞后动态判断。解读前须确认单整阶数、协整关系及适合的弱外生性设定。协整水平回归不适用普通平稳回归推断，因此长期方程的标准误、t 值、p 值、置信区间及协方差为空。短期系数检验以估计的均衡误差和正确模型设定为条件：$H_0:b_j=0$，$H_1:b_j\ne0$，使用 $t=b_j/SE(b_j)$，残差自由度为 $n_{\mathrm{short}}-k$。这是常规同方差近似，不是协整检验，也未校正生成回归量的不确定性。
