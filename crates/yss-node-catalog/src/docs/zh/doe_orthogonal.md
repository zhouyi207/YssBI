# 正交设计（等水平）

无输入。**result** 输出设计摘要，**design** 输出完整编码表：`run` 与 `factor1`…`factorK`，序号及水平从 1 开始。
因素数改变时，下游选列同步更新。运行顺序为生成顺序，不是随机化的现场试验顺序；请在实际试验中另行安排随机化、重复和区组。

不设置固定行数或因素数上限；整数溢出、浮点整数无法精确表示及运行资源预算会阻止不可执行的设计，不截断结果。

**factors** 默认 3，**levels** 默认 2 且至少 2。质数水平 q 使用有限域线性构造：
选择满足 `(q^m−1)/(q−1) ≥ factors` 的最小 m，生成 q^m 次试验。
例如 3 因素 2 水平生成 L4，4 因素 3 水平生成 L9。不同因素的每种水平对出现次数相同。

非质数水平使用全析因构造，保证同样的平衡条件，但试验次数为 `levels^factors`，并非最小正交表。
报告 `method` 区分两种构造。不提供混合水平表，也不自动分配交互作用列；主效应仍可能与交互作用混杂。
