# 判别分析

输入训练 **Class** 标签和 至少一个 **Training variable** 数值数列，同一行代表同一观测。标签支持可物化的基础标量，按原值精确分组；不能包含缺失值。支持至少两类，每类至少 2 条观测。训练输入可混合数据库与内存数列，须等长并按当前位置逐项对应。

可选 **New variable** 组必须与训练变量数量、顺序和含义相同。新数据可以来自另一行域，但其组内必须对齐；未连接时输出训练集分类。拒绝数值缺失与训练常量变量。

**判别模型** 默认 `linear`，采用各类共同的类内样本协方差；`quadratic` 使用各类专属样本协方差。**类别先验** 默认 `empirical`（训练占比），可选 `equal`。**协方差收缩** 默认 0，范围 0–1；先按全训练集样本标准差标准化变量，再用

$$\Sigma_\alpha=(1-\alpha)\Sigma+\alpha\frac{\operatorname{tr}(\Sigma)}{p}I.$$

收缩后协方差必须正定；不默认用伪逆跳过奇异设计。LDA 假定各类协方差相同，QDA 允许不同；两者使用近似类内多元正态模型。

按以下高斯判别分数选择最大者：

$$\delta_g(x)=-\tfrac12\left[(x-\mu_g)^T\Sigma_g^{-1}(x-\mu_g)+\log|\Sigma_g|\right]+\log\pi_g.$$

$\mu_g$ 为类均值，$\pi_g$ 为先验，$\Sigma_g$ 在 LDA 中共享。分数并列时选择输入中首次出现的类别。本节点用于分类，不构造原假设或 p 值。

**Result** 含原标签、类别数/先验、原单位类均值、训练准确率和混淆矩阵（实际类别×预测类别）。这些训练指标没有交叉验证，不等同于新样本泛化表现。**Predicted class** 保留原标签与语义，是可连接的数列，行顺序对应新数据或训练数据。

参考：[scikit-learn LDA/QDA](https://scikit-learn.org/stable/modules/lda_qda.html)。
