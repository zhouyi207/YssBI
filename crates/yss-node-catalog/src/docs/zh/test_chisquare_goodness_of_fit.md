# 卡方拟合优度检验

比较各类别的观测频数与给定期望频数。

## 输入与参数

`observed`、`expected` 是按相同类别顺序排列的数值序列，长度相等且至少 2 项。观测频数非负，期望频数严格为正，均须有限且无空值。数列须等长并按当前位置逐项对应，可混合数据库与内存数列。无配置参数。

输入应使用频数而非概率；观测频数总和必须为正，并与期望频数总和一致，允许浮点舍入误差。节点不会自动归一化期望值，也不会扣除从数据中估计参数所消耗的自由度。

## 假设与统计量

$H_0$：类别概率符合给定期望频数所指定的分布；$H_1$：至少一个类别概率不符。

$$
X^2=\sum_{i=1}^{k}\frac{(O_i-E_i)^2}{E_i},\qquad
X^2\overset{H_0}{\approx}\chi^2_{k-1}.
$$

$k$ 为类别数，$O_i,E_i$ 是对应观测和期望频数。参考分布假设独立观测以及事先指定的类别概率；稀疏类别会影响近似精度。

## 输出与判读

`result` 为结构化结果。`statistic` 为 $X^2$，`degrees_of_freedom` 固定为 `[k−1]`，`p_value` 为卡方右尾概率，`sample_sizes` 为观测频数总和。`estimate`、`standard_error` 为空。

$p<\alpha$ 表示观测分布与指定分布不符。若期望值由同一数据拟合，不能直接使用未调整的 `k−1` 自由度作结论。
