# Log-rank 检验

连接逐行对齐的 `time` 与 `event` 数列。时间必须有限且严格大于 0，单位保持一致；`event=1`（或 true）表示事件发生，`0`（或 false）表示右删失。缺失值会导致计算失败，不自动删行。假设在给定模型或分组条件下删失独立于事件过程；输入须等长并按当前位置逐项对应，可混合数据库与内存数列。

必须连接 `groups` 分组数列，且至少包含两个实际观测组；原标签会保留。节点无参数，不含协变量。同一时点的事件在删失之前计入。

## 假设与统计量

$H_0$：各组生存函数相同；$H_1$：至少一组不同。事件时点 $t_j$ 的组内风险集占比为 $p_{gj}=r_{gj}/r_j$，总事件数为 $d_j$：

$$
U_g=\sum_j(d_{gj}-d_jp_{gj}),\qquad
V_{gh}=\sum_{j:r_j>1}\frac{d_j(r_j-d_j)}{r_j-1}
(p_{gj}\mathbf1_{g=h}-p_{gj}p_{hj}).
$$

去掉最后一组的冗余分量后计算 $Q=U^\top V^{-1}U$。$G$ 组时渐近参考分布为 $\chi^2_{G-1}$。较小 p 值反对生存函数相同，但不表示效应大小，也不能证明比例风险假设。

`result` 返回原组标签、观测事件数、期望事件数、完整协方差矩阵及 `test`（统计量、自由度、p 值）。没有事件或协方差奇异的比较会报错，不伪造 p=1；各组需要在有效风险集中具有可比较信息。本实现为未加权、未分层的 Log-rank，交叉风险可能降低其检验功效。
