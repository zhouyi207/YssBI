# 单次插补

连接数值型 **series**。输出 **result** 保留原有行数、行顺序与行域，只替换空值。
非有限数值会报错。

**imputation_method** 可选：

- **mean**（默认）：全部已观测值的均值。
- **median**：全部已观测值的精确中位数；偶数样本取中间两值的平均。
- **mode**：频数最高的数值；并列时取最小值。
- **constant**：使用有限的 **fill_value** 常数，默认 0。

前三种方法在非空数列中至少需要一个已观测值；整列为空时会报错。
常数方式可填补整列空值，空数列仍输出空数列。
不设置固定行数上限；关系引擎执行原生计划，节点适配器不把整列收集到内存。

输出采用浮点存储。单次插补不反映缺失值的不确定性，可能改变方差、相关性和检验结果。
预测模型验证应仅用训练数据估计填补值；本节点会使用整个输入，无法自行区分训练集与测试集。
按顺序向前或向后填充可使用现有的对应数列节点。
