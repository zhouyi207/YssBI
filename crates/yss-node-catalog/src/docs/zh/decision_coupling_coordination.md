# 耦合协调度

连接至少两个对齐的数值 **criteria**，分别表示已处于 [0,1] 的子系统指数。
输入须有限且非空，不隐式标准化或添加正数偏移，不设置固定观测行数上限。

可选 **criterion_weights** 按子系统顺序提供独立的非负权重向量，内部归一化；
不连接时等权。权重用于 T，耦合度 C 对各子系统作对称比较。

对于 $m$ 个子系统指数：

$$
C_i=\frac{(\prod_j U_{ij})^{1/m}}{\sum_j U_{ij}/m},\qquad
T_i=\sum_j w_jU_{ij},\qquad D_i=\sqrt{C_iT_i}.
$$

**scores** 逐行输出耦合度 C、协调指数 T 和耦合协调度 D。
几何均值使用对数计算，避免连乘下溢。
某子系统为 0、总体均值为正时 C 为 0；全部子系统均为 0 时 C 无定义，输出空值，
T 为 0，D 使用连续极限 0。**result** 报告 C 无定义的行数，**weights** 返回归一化权重。

C 反映子系统水平的均衡性，全部处于低水平时也可能有较高 C；
D 还考虑发展水平。不自动套用经验分级，也不赋予因果解释。
