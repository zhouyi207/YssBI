# 抽样权重

连接 values 数值列。`input_kind=weights`（默认）接受严格为正的有限抽样权重；`inclusion_probabilities` 接受 (0,1] 内的有限纳入概率，并计算权重 1/概率。缺失、零权重、非有限结果均报错，不自动删除记录。

**result** 报告观测数、原始权重和、最小/最大值、Kish 有效样本量 `(Σw)²/Σw²`、仅由不等权重造成的设计效应 `n/Kish有效样本量`，以及总体分母的权重变异系数。没有假设检验或 p 值；Kish 数量不包含分层与聚类的完整影响。

**weights** 输出通过检查的原权重或纳入概率倒数，保留全部行及与来源数据的对齐关系，可直接连接抽样分析节点。不自动归一化输出，无固定行数上限。

不自动构造分层/整群设计、非响应调整、后分层或 raking 权重。纳入概率是抽样概率，不是倾向得分；抽样权重也不是 WLS 精度权重。
