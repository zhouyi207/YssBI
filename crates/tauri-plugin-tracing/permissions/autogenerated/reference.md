## Default Permission

Submit frontend logs, query the log database and subscribe to committed log batches.

#### This default permission set includes the following:

- `allow-submit-frontend-logs`
- `allow-subscribe-logs`
- `allow-unsubscribe-logs`
- `allow-query-logs`
- `allow-log-statistics`
