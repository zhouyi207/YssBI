# 大结果的长报告与局部修订

使用 `Harness Regression` 图已经保留的回归、汇总和异方差检验结果，创建名为 `Harness Regression Report` 的 Markdown 文档。

先读取多个结果的结构和必要摘要。观测明细表有数千行，只抽取解释结果所需的少量列和行；不要完整搬运表格。用实际结果撰写完整中文分析报告，至少包含研究问题、合成数据说明、OLS 方法、拟合概况、系数解释、异方差诊断、局限、后续验证及附录。报告正文至少 12000 个 Unicode 字符，采用有意义的分析和可复现说明，不要重复段落凑字数。不要编造未执行的统计量，也不要把合成数据当成真实研究数据。

显式保存报告，读取结构和正文总字符数核对。然后只定位“局限”一节，将这一节改为包含明确说明“本报告基于合成数据，不构成实证结论”，保持其他章节原样，再次保存并局部读取核对。最终报告路径、字数、保存状态、局部修订范围和实际引用的结果。不要打开桌面。
