# 原子建图与失败测量

在当前独立项目新建 `Harness Atomic Batch` 事件图。

创建批次包含三个乘法节点 A、B、C，以及一个配置为 OLS、具有 5 个 X Pin 的线性回归节点。初始连接为 A 的 result 到 B 的 left、C 的 result 到 B 的 right。

先在同一个创建批次末尾故意添加一条指向回归节点不存在 Pin `missing_measurement_pin` 的连接，并实际提交。该批次应该被拒绝；重新读取图概览，确认没有留下任何新节点或连接。

然后去掉这条无效连接，将同样的节点、回归配置、Pin 数量和两条有效连接单批提交。核对回执与实际节点/连接；使用一次撤销回到空图，再重做恢复整个成功批次，核对身份。显式保存最终图。

不需要执行这些输入尚未配置完整的节点。不修改其他图，不打开桌面。简短报告预期失败、原子性、Pin 数量和撤销重做的实际证据。
