# 数据库定向行列编辑测量

使用独立测试项目中的 `Synthetic regression` 数据库，实际完成以下工作：

1. 按 x1 > 0 筛选并按 y 降序排序，只读取前 5 行及定位所需列。按返回的稳定 rowId 将这些行的 x5 改为 123.5，重新读取核对。
2. 批量增加两个文本列 `measure_flag` 和 `bad_number`。将所选行的 measure_flag 写为字符串 `1`，bad_number 写为字符串 `not-a-number`。
3. 在一次类型转换批次里将这两列都转为 64 位整数，不允许强制转 null。第二列无法转换，预期整个批次失败。用 schema 和局部行读取确认第一列也没有发生部分转换，两个文本列及其值仍保留。
4. 将两个列批量重命名为 `measured_flag` 和 `measured_bad_number`，核对新名称和行身份；显式保存数据库。

禁止用分页位置代替 rowId。预期失败需要真的调用工具并核对结果。没有实际制造外部并发修改时，请明确说明并发冲突未在本次任务中覆盖，不把普通重读称为并发验收。不运行图或打开桌面，不修改其他资源。
